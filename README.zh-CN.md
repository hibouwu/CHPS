# CHPS 学习笔记

[English](README.md) · **简体中文** · [Français](README.fr.md)

这里整理了我在 CHPS 学习期间记下的课堂笔记、习题解答，以及收集的往年试卷。如果你也在学这些课程，可以按科目查找笔记，或在复习时对照题目和推导。

目前收录的是 M1 的资料。笔记大多是在 Notability 中手写的，主要用法语，夹有一些中文解释。

## 找到你的课程

- [AP](M1/AP/)：课程笔记和习题解答。
- [APD](M1/APD/Note/)：课程笔记和习题解答，包含单独整理的图论笔记。
- BaseMath：[课程与习题笔记](M1/BaseMath/Notes/) · [往年试卷](M1/BaseMath/Examen/)。
- [CN](M1/CN/)：数值计算笔记，包含线性方程组求解、LU/LDLᵀ 分解和迭代方法。
- [ORO](M1/ORO/)：优化与运筹笔记，包含线性规划、单纯形法、大 M 法和分支定界。
- [TM](M1/TM/)：微分方程与数值方法笔记，包含解析方法、有限差分和稳定性分析。

## 怎么读这些笔记

每门课中，文件名里的 `Cours` 是课堂笔记，`TD`、`TDTP` 是习题或实践课笔记。复习时可以先看课程里的定义和推导，再打开对应习题，试着自己做一遍后对照解答。合在一起的笔记会保留多个编号，例如 `TD-02-03`。

如果你在复习 TM，可以从[第一份课程笔记](M1/TM/TM-Cours-01.pdf)里的微分方程和解析方法开始，再看[第二份](M1/TM/TM-Cours-02.pdf)中的有限差分与稳定性分析。第三课我缺席了，所以这里没有那次的课堂笔记。

准备考试时，可以直接打开 [BaseMath 的往年试卷](M1/BaseMath/Examen/)。2024 年的两张图片是同一份试卷的前后两页，需要一起看。

## 关于这份整理

这些是我的个人学习记录，有些题目只写了部分过程，也可能有笔误。遇到与课堂材料不一致的地方，请结合老师的讲义核对；如果发现错误或愿意补充缺失的笔记，也欢迎提 Issue 或 PR。

部分课次是整理时根据内容衔接补上的，未必与老师的正式编号完全一致；CN 的 LU/LDLᵀ 笔记因此直接用了主题名。标为 2025 年的试卷沿用了原文件名，照片本身没有显示年份。

如果这些笔记帮到了你，欢迎给仓库点一颗 Star ⭐。感谢支持！
