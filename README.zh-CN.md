# CHPS 课程资料

个人 CHPS 学习资料归档，收录从 Notability 导出的课程笔记、习题笔记，以及历年试卷。笔记主要为法语手写内容，部分带中文说明；PDF 不一定包含可搜索的文字层。

目前资料集中在 M1，共 53 个文件：50 份 PDF 和 3 张试卷图片。笔记和解答保留个人记录，可能存在遗漏或错误，使用时请结合教师提供的题目与课件核对。

## 文件命名

课程简称沿用原有目录名称。文件名统一使用连字符，课次和题组编号使用两位数字：

```text
AP-Cours-01.pdf
AP-TD-02.pdf
CN-TDTP-04.pdf
APD-Cours-00-graphe.pdf
ORO-TD-02-03.pdf
CN-TDTP-Factorisation-LU-LDLT.pdf
BaseMath-Examen-2024-page-01.png
```

- `Cours` 表示课程笔记，`TD` 表示习题笔记，`TDTP` 保留习题／实践课的合并标记，`Examen` 表示试卷。
- 合并题组保留多个编号，例如 `TD-02-03`；原有的 `00` 编号保持不变。
- 无法确认课次时使用主题名，不根据文件排列顺序补号；课程合辑也不强行添加课次。
- 同一份试卷的多张图片使用 `page-01`、`page-02` 区分，原有版本后缀如 `a` 保留。
- `APD/Note` 与 `BaseMath/Notes` 沿用现有目录结构。

## 已知缺口与编号依据

- **TM**：第三课因缺席暂无笔记，不应把现有 TD 当作第三课。`Cours-02`、`TD-01` 和 `TD-02` 的编号根据内容衔接推定，页面未明确写出课次。两份课程分别涵盖微分方程基础与解析方法，以及二阶 PDE 分类、有限差分和稳定性分析；两份 TD 与这些主题对应。
- **ORO**：`Cours-03` 原名为 `笔记 2026年4月9日.pdf`，内容是大 M 法、分支定界和整数线性规划。编号根据既有课程顺序及内容衔接推定。
- **CN**：`CN-TDTP-04.pdf` 正文明确标注 TD/TP4；`CN-TDTP-Factorisation-LU-LDLT.pdf` 的课次尚未确认，使用主题名。`CN-Cours.pdf` 不指定课次。
- **BaseMath**：2024 年两张照片为同一份试卷的前后页，第一页可见日期为 2024 年 10 月 17 日。2025 年照片中的标题为 `EXAMEN OBHPC`，年份沿用原文件名，尚未由照片正文确认。

## 添加资料

从 Notability 导出 PDF 后，将文件放入对应课程目录，检查首页标题、日期和内容，再按上述规则命名。遇到同名或带 `(2)` 的文件，应先比较内容，确认是续篇、习题还是重复导出，再决定保留方式。

课程 PDF 和试卷图片是本仓库的主要内容，应纳入版本管理。系统生成的隐藏文件、编辑器交换文件及临时转换输出由 `.gitignore` 排除。
