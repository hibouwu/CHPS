# CHPS 学习笔记

[English](README.md) · **简体中文** · [Français](README.fr.md)

这里记录了我在 UVSQ / Université Paris-Saclay 攻读 CHPS 期间的学习内容，包括课堂笔记、课程讲义、习题解答、往年试卷和项目报告。希望这些材料能方便同学查找课程内容、复习考试，也方便我回顾学过的知识。

目前收录 M1 和部分 M2 资料，涵盖数值计算、并行编程、计算机体系结构、操作系统和科学计算。材料以法语为主，部分笔记附有中文解释；既有 Notability 手写笔记，也有 Markdown 文本和 PDF。

## PPN 项目

**[ppn-mnist-neural-network](https://github.com/hibouwu/ppn-mnist-neural-network)** 是我的数值编程项目仓库：从零实现 C++ 神经网络与自动微分，并探索矩阵运算优化和并行训练。项目代码、报告和说明请直接查看该仓库。

其他课程项目的报告与笔记随对应课程存放，例如 CN 的 Poisson 求解、POO 的粒子模拟器、AISE 的 EXPRESSO 和 TOP 的 LBM 流体仿真。

## 如何查找材料

进入课程目录后，可以先看该课程的 README。`Materials/` 中收录讲义、习题、复习材料和项目文档；手写笔记也可能直接放在课程目录或 `Note/Notes` 中。

文件名中的 `Cours` 表示课程，`TD` 表示习题课，`TP` 表示实验，`Examen` 或 `CC` 表示考试。PDF 与同主题的 Markdown 往往是原始材料与文字整理稿，可以对照阅读。

## 关于笔记

这些是个人学习资料，收录范围并不完整，部分解答可能有遗漏或错误。课程讲义与引用材料的作者信息保留在原文件中；遇到疑问时，请结合教师的原始材料核对。部分手写 PDF 没有可搜索的文字层。

欢迎通过 Issue 或 Pull Request 指出错误、讨论题目或补充笔记。如果这些材料对你有帮助，也欢迎给仓库点一颗 Star ⭐。
