# IMMC 阅读索引

## 从哪里开始

1. 初次接触：先读 [课程介绍](CM/中文补充/课程介绍_2026-2027.md)。
2. 跟随本年上课：打开 [本年幻灯片中文对照](CM/中文补充/本年幻灯片_中文对照.md)，按 v3 的 PDF 页码跳到对应章节。
3. 做题：用下方的 TD 稿，先读法语题意，再看中文推导与教师解答。
4. 回听查词：进入 [课堂转写](课堂记录/README.md)。
5. 准备 CC1：先读 [核心概念专讲](CC1核心概念专讲.md)，再做下方历年试题；考场开卷速查可直接带 [CC1 期中开卷小抄表](CC1期中开卷小抄表.md)。
