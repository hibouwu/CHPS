# Annexe A

## Notations

| Symbole | Dénomination |
|---|---|
| $x_i$ | Coordonnées spatiales eulériennes (courante) |
| $X_i$ | Coordonnées spatiales lagrangiennes (initiales) |
| $a$ | Variable scalaire |
| $a(t,M)$ | Champ scalaire fonction du temps et de l'espace |
| $\vec{a}$ | Vecteur (ou tenseur d'ordre 1) |
| $\mathbb{A}$ | Tenseur d'ordre 2 |
| $\mathbb{I}$ | Matrice identité (tenseur d'ordre 2) |
| $\delta_{ij}$ | Symbole de Kronecker (équivalent à la matrice identité) |
| $\varepsilon_{ijk}$ | Symbole de Levi-Civita |
| $\dot{\bullet}$ | Dérivée totale en temps du champ $\bullet$ |
| $\ddot{\bullet}$ | Dérivée double totale en temps du champ $\bullet$ |
| $\frac{\partial\bullet}{\partial t}$ | Dérivée partielle en temps du champ $\bullet$ |
| $\frac{\mathrm{d}\bullet}{\mathrm{d}t}$ | Dérivée particulaire (totale) du champ $\bullet$ |
| $\bullet_{,i}=\frac{\partial\bullet}{\partial x_i}$ | Dérivée partielle du champ $\bullet$ par rapport à la variable spatiale d'indice i |
| $\llbracket\bullet\rrbracket_\Sigma$ | Saut de la quantité $\bullet$ au travers de la frontière $\Sigma$ |
| $\mathbb{A}^{\mathsf{T}}$ | Transposée du tenseur d'ordre 2 $\mathbb{A}$ |
| $\mathbb{A}^{-1}$ | Inverse du tenseur d'ordre 2 $\mathbb{A}$ |
| $\mathbb{A}^{-\mathsf{T}}$ | Transposée inverse du tenseur d'ordre 2 $\mathbb{A}$ |
| $\mathbb{A}\cdot\vec{b}$ | Produit contracté simple du tenseur $\mathbb{A}$ avec le vecteur $\vec{b}$ |
| $\mathbb{A}:\mathbb{B}$ | Produit contracté simple du tenseur $\mathbb{A}$ avec le tenseur $\mathbb{B}$ |
| $\overrightarrow{\operatorname{grad}}\,a=\nabla a$ | Gradient du champ scalaire a |
| $\overline{\overline{\operatorname{grad}}}\,\vec{a}=\nabla\vec{a}$ | Gradient du champ vectoriel $\vec{a}$ |
| $\operatorname{div}\vec{a}=\nabla\cdot\vec{a}$ | Divergence du champ vectoriel $\vec{a}$ |
| $\overrightarrow{\operatorname{div}}\mathbb{A}=\nabla\cdot\mathbb{A}$ | Divergence du champ tensoriel $\mathbb{A}$ |
| $\overrightarrow{\operatorname{rot}}\vec{a}=\nabla\wedge\vec{a}$ | Rotationnel du champ vectoriel $\vec{a}$ |
| $\overline{\overline{\operatorname{rot}}}\mathbb{A}=\nabla\wedge\mathbb{A}$ | Rotationnel du champ tensoriel $\mathbb{A}$ |
| $\Delta a=\nabla^2 a$ | Laplacien du champ scalaire a |
| $\overrightarrow{\Delta}\vec{a}=\nabla^2\vec{a}$ | Laplacien du champ vectoriel $\vec{a}$ |
| $\overline{\overline{\Delta}}\mathbb{A}=\nabla^2\mathbb{A}$ | Laplacien du champ tensoriel $\mathbb{A}$ |
