# 🧮 张量分解与速度场梯度

## 梯度张量的定义

### 速度场梯度

* 速度场是一个向量场
* 对速度场进行空间导数，得到二阶张量（矩阵）
* 该张量称为速度场的梯度张量

## 张量的对称与反对称分解

### 张量分解方法

* 任意二阶张量都可以分解为**对称部分**和**反对称部分**
* **对称部分** = ½ × (张量 + 张量的转置)
* **反对称部分** = ½ × (张量 - 张量的转置)

| 分解类型 | 计算公式 | 说明 |
| --- | --- | --- |
| 对称部分 | $ \frac{1}{2}(T + T^T) $ | 张量与其转置的平均 |
| 反对称部分 | $ \frac{1}{2}(T - T^T) $ | 张量与其转置的差值 |

> 这是对所有二阶张量均适用的通用操作

# ⚙️ 应用与意义

## 速度场梯度张量的物理意义

* 对称部分通常与**变形率**相关
* 反对称部分通常与**旋转率**相关

## 操作的普适性

* 不论张量来源（梯度或其他），均可进行此分解

* 利用向量 $\omega$ 和空间中两点间的向量 $\mathbf{mn}$ 的叉积，可以将点 $m$ 的速度场传递到点 $n$。

\mathbf{v}_n = \mathbf{v}_m + \boldsymbol{\omega} \times \mathbf{mn}
$

### 时间依赖性

* 向量 $\omega$ 和点间向量 $\mathbf{mn}$ 可能随时间变化，因为点会随运动而移动。

* 计算从原点 **O** 到点 **n** 的向量变化。

| 速度场微小变化 | 将时间导数视为速度场的微小变化 |
| 引入原点向量 O | 利用 Challe 关系引入原点向量进行路径分析 |
| 路径等价性 | 从 O 到 n 的路径等价于从 O 出发再返回 n 点的路径 |

> **总结**：通过数学定理和关系，将向量的时间导数转化为速度场的微小变化，并利用原点向量分析路径的等价性。

# 🌀 速度场的拉格朗日与欧拉表示

## 速度场的两种表示方法

* **拉格朗日表示**  
  *定义：跟踪单个粒子的速度随时间变化的描述方式。*
  + 速度依赖于时间
  + 速度的方向可能变化，速度的大小不一定变化
  + 适用于描述粒子运动的具体轨迹
* **欧拉表示**  
  *定义：在空间固定点观察速度场的描述方式。*
  + 速度场可能不依赖时间（时间独立）
  + 适用于描述整体流场的稳定性

## 旋转运动中的速度场特点

| 运动类型 | 拉格朗日表示 | 欧拉表示 |
| --- | --- | --- |
| 旋转运动 | 速度方向随时间变化，速度场依赖时间 | 速度场不随时间变化，时间独立（稳定） |

### 详细说明

* 旋转运动中，单个粒子的速度方向会随时间变化，体现为拉格朗日速度场的时间依赖性。
* 旋转运动整体是周期性且恒定的，因此欧拉速度场表现为时间独立。
* 通过欧拉视角观察，旋转运动的速度场是稳定的；但通过拉格朗日视角，速度场表现出时间变化，无法达到“平稳轨迹”（stationnaire）。

> **总结**：

# 🔄 旋转性与流动性质

## 旋转性 (Rotationnel)

### 旋转性定义

* 判断流动是否**无旋转**（irrotationnel）
* 依据：速度场的旋转算子作用后得到的旋转部分是否为零
* 旋转部分用**旋转算子**提取（需注意矢量的正确表示）

## 流体力学中的层流与湍流

### 层流 (Laminaire)

* *定义*：流体以层状方式流动，没有湍流
* 特点：
  + 流动平稳，层与层之间无混合
  + 无涡流或旋涡产生
  + 速度较低，相对于流体的粘度较适中

### 湍流 (Turbulence)

* *定义*：流动中存在不规则的涡旋和混合
* 产生条件：
  + 流速过高
  + 相对于流体粘度，速度过大导致流动不稳定

| 流动类型 | 特点 | 产生条件 | 结果 |
| --- | --- | --- | --- |
| 层流 | 流动平稳，无涡旋 | 速度较低，粘度适中 | 无湍流，流体分层流动 |
| 湍流 | 存在涡旋和混合 | 速度过高，相对于粘度较大 | 产生湍流，流动不稳定 |

> 流体在速度过高时，湍流和涡旋会被激发，导致流动性质发生根本变化。

# 📝 速度场的表达与理解

## 速度在点M的表达形式

### 速度表达式

* 速度可以写成：**α × 单位向量E1 × (E2与E1的点积)**
* 这里的点积是指向量E2与E1的**内积**

### 速度场的坐标含义

* 取向量OM，与单位向量E2做点积，得到的结果是**坐标x2**
* 这是一种巧妙的方式，将速度场写成依赖于坐标x2的形式

## 速度场的空间特性

### 速度方向

* 速度场仅沿\*\*方向1（水平方向）\*\*定向

### 速度的空间依赖

* 速度大小依赖于空间中的**坐标x2（垂直方向）**
* 换句话说，速度场是一个只随垂直坐标变化的水平速度场

---

> **总结：**  
> 速度场可以看作是一个仅沿水平方向的速度分布，其大小仅依赖于垂直方向的空间坐标x2。通过向量点积的方式，将速度场巧妙地表达为依赖于x2的函数。

# 📝 流动特性

* 这意味着流体粒子沿着流线运动。

# 📝 方程组求解过程

## 方程组描述

* 有三个方程：
  + $ x\_1 = \alpha x\_2 $
  + $ x\_2 = 0 $
  + $ x\_3 = 0 $

## 求解步骤

### 初始条件

* $ x\_1, x\_2, x\_3 $ 是初始坐标
* $ x\_2 $ 和 $ x\_3 $ 是常数，记为 $ c\_3 $

### 解析过程

* 先从最简单的方程开始积分
* 由于 $ x\_2 $ 和 $ x\_3 $ 是常数，可以直接用初始条件代入
* 利用初始条件 $ x\_2(t=0) $ 和 $ x\_3(t=0) $ 确定常数值

> **总结**：通过初始条件确定常数，快速求解三个方程组。

# 📝 关键概念与技巧

| 关键点 | 说明 |
| --- | --- |
| **初始坐标** | $ x\_1, x\_2, x\_3 $ 的初始值 |
| **常数积分** | $ x\_2, x\_3 $ 是常数，积分后为常数 |
| **条件代入** | 利用初始条件代入确定积分常数 |

* *积分常数*：积分过程中出现的未知常数，通过初始条件确定其具体数值。
* *条件初始值*：在 $ t=0 $ 时刻的变量值，用于确定积分常数。

> 通过合理利用初始条件，可以简化方程组的求解过程，提高计算效率。

# 🧮 张量计算与矩阵乘法

## 张量的定义与计算

### 张量的表达式

* **张量**：考察的是**考克斯-格林（Cauchy-Green）膨胀张量**
* 计算方法：
  + 先计算矩阵 **c**
  + 计算方式为矩阵乘积：
    - $ c = f^T \times f $
    - 即先取矩阵 **f** 的转置，再与 **f** 相乘

## 矩阵乘法规则

### 矩阵乘积的具体计算

* 矩阵乘积定义：
  + 若有矩阵 $ a $ 和 $ b $，其乘积元素为：  
$  
    (a \times b)*{ij} = \sum\_k a*{ik} b\_{kj}  
    $
* 文中说明的索引关系：
  + $ a\_{ij} \times b\_{ji} $
  + 这里 $ a $ 取为 $ f^T $，则 $ a\_{ij} = f\_{ji} $
  + 因此乘积可以直接用 $ f\_{ji} $ 替代 $ a\_{ij} $

> **总结**：计算考克斯-格林膨胀张量时，关键是理解矩阵转置与乘法的索引对应关系，确保正确计算 $ c = f^T f $。

  + 是否为**圆周运动**（mouvement circulaire）
  + 是否为**不可压缩运动**（mouvement incompressible）
  + 是否为**必定为直线运动**（mouvement rectiligne）
  + 是否为**无旋运动**（mouvement irrotationnel）

### 相关概念回顾

| 概念 | 定义及说明 |
| --- | --- |
| **定常运动** | *运动的速度场不随时间变化* |
| **不可压缩运动** | *流体密度不变，体积不变，变形张量迹为零* |
| **无旋运动** | *运动中无旋转分量，速度场的旋度为零* |
| **圆周运动** | *质点沿圆轨迹运动，具有角速度* |
| **直线运动** | *质点沿直线路径运动* |

> 变形张量D的迹为零，意味着该运动是**不可压缩的**，即体积保持不变。

## 运动类型的理解与区分

### 运动性质总结

* **迹为零的变形张量D** → 运动**不可压缩**
* **定常运动**与迹为零无必然联系
* **圆周运动**可能有旋转成分，不一定迹为零
* **直线运动**未必迹为零
* **无旋运动**与迹为零无直接关系

### 备注

* 课题中已学习过**圆周运动**和**定常、不可压缩运动**的概念
* 对**直线运动**的深入探讨较少

## 变形的数量级与实际意义

* 1% 的变形量是一个合理的数量级。
* 负1% 表示物体被**压缩**，即变形为负值。
* 讨论是否一个非常强壮的人类能够使金属棒产生1%的变形。

> “当你寻找变形时，你需要去除身份矩阵部分。”

# 🔧 力矩与力的数学表示——力矩偶（torseur）

## 力矩偶的定义

* *力矩偶（torseur）* 是一个**向量场**，即一个依赖于空间位置的向量。
* 该向量场具有**等投影性（équiprojectivité）**。

## 等投影性的含义

* 对空间中任意两点 M 和 N，有：
  > 力矩偶在点 M 的向量与向量 MN 的数量积 = 力矩偶在点 N 的向量与向量 MN 的数量积
* 用数学表达式表示为：

| 点 | 力矩偶向量 | 与向量 MN 的数量积 |
| --- | --- | --- |
| M | $\vec{H}_M$ | $\vec{H}_M \cdot \vec{MN}$ |
| N | $\vec{H}_N$ | $\vec{H}_N \cdot \vec{MN}$ |

* 这说明力矩偶在不同点的向量投影在连接这两点的向量上是相等的。

> **总结**：力矩偶是描述力和力矩分布的数学工具，具有空间依赖性和特殊的投影性质，适用于刚体和连续介质的力学分析。

# 📝 等投影性质与力矩场的定义

## 等投影性质

### 说明

* *等投影*指的是：  
  向量场中，点M在向量MN上的投影与点N在向量MN上的投影相等。
* 数学表达：  
  投影 $ H(M) $ 在 $ MN $ 上 = 投影 $ H(N) $ 在 $ MN $ 上。

## 力矩场与力矩的唯一性

### 力矩场的定义

* 存在一个**唯一向量**，称为**力矩的合力**（**R**），该向量不依赖于力矩场表达的参考点。
* 该向量使得任意两点M和N的向量场满足以下关系：

| 符号 | 含义 |
| --- | --- |
| $ H(N) $ | 点N处的向量场值 |
| $ H(M) $ | 点M处的向量场值 |
| $ \vec{R} $ | 力矩的合力向量 |
| $ \vec{MN} $ | 向量从点M指向点N |

### 关系表达式

$
H(N) = H(M) + \vec{R} \times \vec{MN}
$

* 其中，$ \times $ 表示**向量叉积**。
* 该表达式说明，点N处的向量场可以由点M处的向量场加上合力与两点连线向量的叉积得到。

> **总结**：力矩场的向量值在空间中通过合力向量和位置向量的叉积进行转换，且合力向量是唯一且不依赖参考点的。

| 组成部分 | 说明 |
| --- | --- |

* 合力部分运算简单，力偶矩部分需注意表达点转换。

# 🧮 动力学基本原理

## 基本原理介绍

* 在**伽利略参考系R**中，适用**动力学基本原理**
* 动力学基本原理表达式：
  > 合力之和 = 质量 × 加速度
* 其中，加速度是点M位置的二阶导数（位置的二次微分）

## 数学表达

* 设物质点质量为M，位置向量为OM
* 加速度 $ \vec{a} = \frac{d^2 \vec{OM}}{dt^2} $
* 合力 $ \sum \vec{F} = M \vec{a} $

> **总结**：物质点受力时，只考虑合力，力矩为零；在惯性参考系中，合力等于质量乘以加速度，这是动力学的基本法则。

# 📝 力和力矩的计算

## 力的合成（力的合力）

### 细节

* 要表示作用于刚体的合力矩（torseur résultant），首先需要计算**合力**。
* 合力的计算方法是对作用于刚体的**体积力场**进行积分。
* 体积力是分布在刚体内部的力，积分后得到一个等效的合力。

## 力矩的计算与力臂效应

### 细节

* 力矩的计算不仅仅是积分体积力，还需要计算**局部力矩**，即力对某一点（如点A）产生的转动力矩。
* 计算时需要将力矩“平移”到参考点A。
* 力矩大小与力臂长度有关，力臂越长，产生的力矩越大。
* 举例说明：
  + 如果将一个较重的物体（如笔）拿在某一点A，随着距离点A的距离增加，产生的力矩也会增大。
  + 这体现了**杠杆原理**，即力矩 = 力 × 力臂长度。

| 计算内容 | 说明 |
| --- | --- |
| 合力 | 对体积力场积分得到的总力 |
| 力矩 | 力对参考点的转动力矩，考虑力臂 |
| 力臂效应 | 距离参考点越远，力矩越大 |

> **总结**：计算刚体上的合力和力矩时，必须积分体积力并考虑力臂长度，才能准确描述力的作用效果。

### 细节

> **总结**：集中力和力矩是描述刚体受力状态的重要物理量，力和力矩需统一表达，刚体动力学基础建立在不变形假设和动力学基本方程之上。

# 📝 动力学力矩平衡

## 动力学力矩的定义

* **动力学力矩**是指作用在刚体或物体上的力矩与其产生的加速度之间的关系。
* 计算动力学力矩时，需要考虑物体的质量分布和加速度。

## 力矩计算方法

| 内容 | 说明 |
| --- | --- |
| **力矩平衡条件** | 需要同时考虑力的平衡和力矩的平衡。 |
| **动力学力矩表达式** | 动力学力矩 = 作用于物体的外力矩 |
| **积分计算** | 动力学力矩 = ∫(质量密度 × 点M的局部加速度) |
| **力矩计算点** | 力矩是以点A为参考点，计算从点A到点M的力臂产生的力矩。 |

> 动力学力矩等于作用在物体上的外力矩，且通过积分质量密度与局部加速度的乘积来计算。

# 📝 刚体动力学分析

## 刚体的刚性与体积

* 刚体保持刚性，不发生形变。
* 刚体占据一定的体积，需要对整个体积内的质量和加速度进行积分计算。

## 动力学分析步骤

* 识别刚体的质量分布（质量密度）。
* 计算刚体内每一点的局部加速度。
* 计算整体的动力学力矩，确保力和力矩的平衡。

> 在刚体动力学分析中，必须同时满足力的平衡和力矩的平衡，才能准确描述刚体的运动状态。

# ⚙️ 动力学力矩矢量（torseur dynamique）

## 动力学力矩矢量的组成

### 主要内容

* 动力学力矩矢量表达了**加速度**的所有信息。
* 力矩矢量包括以下几部分的贡献：

| 贡献类型 | 说明 | 符号/表示 |
| --- | --- | --- |
| 体积力贡献 | 体积力场的作用 | $ \mathbf{F}\_V $ (体积力) |
| 表面力贡献 | 表面力的合力及合力矩 | 合力及力矩 |
| 点力贡献 | 单点作用力及其力矩 | 点力及其力矩 |

## 力矩矢量的平衡条件

### 主要内容

* 力矩矢量的平衡分为**合力平衡**和**力矩平衡**两部分。
* 这里的平衡是指\*\*动力学第一定律（PFD）\*\*的应用。
* 所有的等式均在同一点（点A）进行计算。

> 力矩矢量的合力平衡和力矩平衡均在点A处进行，确保所有力和力矩的平衡条件满足。

# 📐 动力学第一定律（PFD）应用

## PFD的两种平衡形式

| 平衡类型 | 说明 | 计算点 |
| --- | --- | --- |
| 合力平衡 | 作用力的合力达到平衡 | 点A |
| 力矩平衡 | 作用力矩达到平衡 | 点A |

## 备注

* PFD的所有等式均需在同一点进行，保证计算的一致性和准确性。

# 📝 质量密度与连续介质力学

## 质量密度（Masse Volumique）

### 定义

* **质量密度**通常表示为每立方米的千克数（kg/m³）。
* 质量密度是物质的质量与其体积的比值。

### 相关说明

* 质量密度用符号 $\rho$ 表示。
* 对于刚性固体，质量密度的定义和应用较为直接。
* 当应用于可变形固体时，相关方程会有所不同。

## 连续介质力学中的变形体（Milieu Continu Déformable）

### 介质类型

* 介质被视为**连续介质**，即物质在宏观上连续分布。
* 介质可以发生**变形**，用符号 $\omega$ 表示其可变形性质。

### 外部作用力的描述

* 研究外部环境对介质的作用力。
* 主要考虑两种简化的力学模型（schématisation）来描述外力。

| 介质类型 | 符号 | 特点 | 作用力描述 |
| --- | --- | --- | --- |
| 刚性固体 | $\rho$ | 不变形 | 质量密度直接应用 |
| 可变形连续介质 | $\omega$ | 可发生变形 | 采用两种简化模型描述外力 |

> **总结**：从刚性固体到可变形连续介质，力学描述和方程需要相应调整，以准确反映介质的物理性质和外部作用。

# 📝 表面力与体积力

## 力的分类

* **表面力**（*efforts surfaciques*）
  + 作用于边界或边界的子部分
  + 通常用符号表示为 $ e $
  + 若为已知数据，添加下标 $ d $，表示这是问题中的已知量（例如 $ e\_d $）
* **体积力**（*efforts volumiques*）
  + 作用于体积内部
  + 通常用符号表示为 $ F\_V $
  + 若为已知数据，添加下标 $ d $，表示这是问题中的已知量（例如 $ F\_D $）

## 备注与应用

| 内容 | 说明 |
| --- | --- |
| 表面力已知情况 | 部分表面力通常是未知的，需要求解 |
| 体积力已知情况 | 99%情况下体积力是已知的，少数情况需重新计算 |
| 问题中的符号约定 | 下标 $ d $ 表示该力为已知数据 |

> 表面力和体积力的符号及下标约定，有助于区分已知和未知的力，便于问题的分析和求解。
