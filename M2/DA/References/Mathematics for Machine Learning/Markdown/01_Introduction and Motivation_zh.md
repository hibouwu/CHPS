# 1 引言与动机

> 来源：[已校对英文稿](<01_Introduction and Motivation.md>) · [本章 PDF](<../PDF/01_Introduction and Motivation.pdf>)。本章中文翻译已覆盖全部正文，并完成逐段复核、数学表达与图片链接检查。

机器学习（machine learning）研究如何设计算法，从数据中自动提取有价值的信息。这里强调的是“自动”：机器学习关注的是能够应用于多种数据集、同时产生有意义结果的通用方法。机器学习的核心包含三个概念：数据、模型和学习。

机器学习本质上由数据驱动，因此数据处于其核心位置。机器学习的目标是设计通用方法，从数据中提取有价值的模式，理想情况下不需要太多特定领域的专业知识。例如，给定大量文档组成的语料库（如许多图书馆中的书籍），可以使用机器学习方法，自动发现不同文档共同涉及的相关主题（Hoffman et al., 2010）。为实现这一目标，我们设计模型；这些模型通常与某种数据生成过程有关，该过程产生的数据与给定数据集相似。例如，在回归（regression）问题中，模型描述一个将输入映射到实数值输出的函数。借用 Mitchell（1997）的表述：如果模型在利用数据后，在某项给定任务上的表现有所改善，就称该模型从数据中进行了学习。我们的目标是找到能够很好地泛化到尚未见过的数据的模型，这些数据可能是我们将来关心的。学习可以理解为通过优化模型参数，自动发现数据中的模式和结构。

虽然机器学习已经取得了许多成功，而且已有软件能够方便地设计和训练表达能力强、灵活性高的机器学习系统，但我们认为，机器学习的数学基础仍然十分重要，因为它有助于理解构建更复杂机器学习系统所依据的基本原理。理解这些原理，有助于创造新的机器学习解决方案、理解和调试现有方法，以及认识所用方法固有的假设与局限。

## 1.1 为直觉找到语言

在机器学习中，我们经常面临一个挑战：概念和词语的含义并不固定，机器学习系统中的同一个组成部分可以抽象为不同的数学概念。例如，在机器学习语境中，“算法”一词至少有两种用法。第一种用法中的“机器学习算法”是指根据输入数据进行预测的系统，我们将这类算法称为预测器（predictor）。第二种用法中，同样的“机器学习算法”一词却指调整预测器某些内部参数的系统，使预测器能够在未来未见过的输入数据上表现良好。这里，我们将这种调整称为系统的训练（training）。

本书不会解决这种歧义问题，但希望一开始就指出：相同表达在不同语境中可能具有不同含义。不过，我们会尽量把语境交代清楚，以减少歧义。

本书第一部分介绍讨论机器学习系统三个主要组成部分——数据、模型和学习——所需的数学概念与基础。这里先简要介绍这三个部分；在讨论了必要的数学概念之后，我们将在第 8 章重新讨论它们。

虽然并非所有数据都是数值型的，但将数据视为数值形式通常很有用。本书假设，数据已经被适当地转换成了适合计算机程序读取的数值表示。因此，我们将数据视为向量（vector）。向量也说明了词语含义的微妙之处：至少可以从三种角度理解向量，即把它看作一个数值数组（计算机科学的视角）、一个具有方向和大小的箭头（物理学的视角），或者一个遵循加法和缩放运算规则的对象（数学的视角）。

模型（model）通常用于描述一个生成数据的过程，其生成的数据与手头的数据集相似。因此，好的模型也可以看作真实但未知的数据生成过程的简化版本，它抓住了对数据建模和提取其中隐藏模式有关的方面。由此，无须开展真实世界中的实验，也可以利用好的模型预测真实世界中会发生什么。

现在讨论问题的核心，即机器学习中的学习部分。假设我们有一个数据集和一个合适的模型。训练模型，就是利用现有数据，根据一个评价模型对训练数据预测效果的效用函数（utility function），优化模型的某些参数。大多数训练方法都可以类比为爬山直至山顶。在这个类比中，山顶对应某个期望性能指标的极大值。然而，在实际中，我们希望模型在未见过的数据上也表现良好。在已经见过的数据（训练数据）上表现良好，可能仅仅意味着我们找到了记住这些数据的好方法。这种方法却可能无法很好地泛化到未见过的数据，而在实际应用中，我们常常需要让机器学习系统处理此前没有遇到过的情形。

下面概括本书涉及的机器学习主要概念：

- 将数据表示为向量。
- 从概率或优化的视角，选择合适的模型。
- 使用数值优化方法从现有数据中学习，目标是让模型在未用于训练的数据上表现良好。

## 1.2 本书的两种阅读方式

理解机器学习所需的数学，可以采取两种策略：

- **自底向上（bottom-up）：** 从基础概念逐步构建更高级的概念。在数学等技术性较强的领域，这通常是首选方式。其优点是，读者始终可以依赖此前学过的概念。遗憾的是，对实践者而言，许多基础概念本身并不特别有趣，缺乏学习动机也使得大多数基础定义很快就被遗忘。

- **自顶向下（top-down）：** 从实际需要逐步追溯到更基础的要求。这种目标驱动方式的优点是，读者始终知道为什么要学习某个概念，而且所需知识的路径清晰。缺点是，知识可能建立在不稳固的基础上，读者不得不记住一组当下无从理解的词语。

我们决定采用模块化方式编写本书，将基础数学概念与应用分开，使本书能够按上述两种方式阅读。全书分为两部分：第一部分奠定数学基础，第二部分将第一部分的概念应用于一组基本机器学习问题。这些问题构成了图 1.1 所示的机器学习四大支柱：回归、降维（dimensionality reduction）、密度估计（density estimation）和分类（classification）。第一部分各章大多建立在前面章节的基础上，但也可以先跳过某一章，必要时再回头补读。第二部分各章之间的联系较为松散，可以按任意顺序阅读。全书两部分之间有许多向前和向后的交叉引用，将数学概念与机器学习算法联系起来。

### 第一部分：数学

本书讨论的机器学习四大支柱（见图 1.1）需要扎实的数学基础，第一部分将介绍这些基础。

我们用向量表示数值数据，用矩阵（matrix）表示由这类数据组成的表格。研究向量和矩阵的学科称为线性代数（linear algebra），我们将在第 2 章介绍，也会讨论如何将一组向量组织成矩阵。

给定两个分别表示真实世界中两个对象的向量，我们希望能够描述它们的相似性。其基本想法是：对于相似的向量，机器学习算法（即预测器）应当预测出相似的输出。为了形式化地表达向量之间的相似性，我们需要引入一些运算：以两个向量为输入，返回一个表示其相似程度的数值。相似性和距离的构造是解析几何（analytic geometry）的核心内容，将在第 3 章讨论。

第 4 章介绍矩阵和矩阵分解（matrix decomposition）的一些基本概念。某些矩阵运算在机器学习中极为有用，能够帮助我们直观地解释数据，并提高学习效率。

我们常常将数据看作对某个潜在真实信号的含噪观测，希望通过机器学习从噪声中识别出信号。这要求我们有一种语言来量化“噪声”的含义。我们通常也希望预测器能够表达某种不确定性，例如，量化我们对某个特定测试数据点的预测值有多大信心。不确定性的量化属于概率论（probability theory）的范畴，将在第 6 章介绍。

为了训练机器学习模型，我们通常需要找到使某个性能指标最大化的参数。许多优化技术需要用到梯度（gradient）的概念，它告诉我们应当沿哪个方向寻找解。第 5 章讨论向量微积分（vector calculus），详细介绍梯度；随后，第 7 章将运用这一概念，讨论如何通过优化寻找函数的极大值和极小值。

### 第二部分：机器学习

本书第二部分介绍图 1.1 所示的机器学习四大支柱，并说明第一部分介绍的数学概念如何为每一根支柱奠定基础。总体而言，各章按难度从低到高排列。

第 8 章用数学语言重新表述机器学习的三个组成部分：数据、模型和参数估计（parameter estimation）。此外，我们还给出一些设计实验的指导原则，避免对机器学习系统作出过于乐观的评价。请记住，我们的目标是构建一个在未见过的数据上表现良好的预测器。

第 9 章深入讨论线性回归（linear regression）。我们的目标是寻找将输入 $\pmb { x } \in \mathbb { R } ^ { D }$ 映射到相应观测函数值 $y \in \mathbb { R }$ 的函数，这些函数值可以解释为相应输入的标签（label）。我们将讨论通过最大似然估计（maximum likelihood estimation）和最大后验估计（maximum a posteriori estimation）进行的经典模型拟合（参数估计），以及贝叶斯线性回归（Bayesian linear regression）。在贝叶斯线性回归中，我们通过积分消去参数，而不是对参数进行优化。

第 10 章利用主成分分析（principal component analysis）讨论降维，即图 1.1 中的第二根支柱。降维的主要目标是为高维数据 $\pmb { x } \in \mathbb { R } ^ { D }$ 寻找紧凑的低维表示，这种表示通常比原始数据更容易分析。与回归不同，降维只关注对数据本身建模，数据点 $\boldsymbol{x}$ 没有对应的标签。

第 11 章讨论第三根支柱：密度估计。密度估计的目标是找到一个描述给定数据集的概率分布。为此，我们将重点讨论高斯混合模型（Gaussian mixture model），以及寻找其参数的迭代方法。与降维一样，数据点 $\pmb { x } \in \mathbb { R } ^ { D }$ 没有对应的标签。不过，我们并不寻求数据的低维表示，而是关注描述数据的密度模型。

第 12 章深入讨论第四根支柱——分类，为全书作结。我们将在支持向量机（support vector machine）的框架下讨论分类。与回归（第 9 章）相似，我们有输入 $\boldsymbol{x}$ 及其对应标签 $y$。不过，回归中的标签是实数值，而分类中的标签是整数，这一点需要特别注意。
