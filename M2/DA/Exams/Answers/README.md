# 参考答案配图

这些图用于六份考试双语阅读版的法语／中文参考答案，原题图片保持原样。

| 文件 | 对应题目 | 性质 |
| --- | --- | --- |
| `2019_diagonal_tree.png` | 2019 第 5 小题 | 数学示意：对角线可分的两类与轴对齐树的阶梯边界 |
| `2021_regression_tree.png` | 2021 第 3 题 a、b | 按原题图估计的形状示意；不声称精确复现 CART 阈值或叶均值 |
| `2021_tree_ensemble.png` | 2021 第 3 题 c | 数学示意：错开台阶的有限树集成平均仍为阶梯函数 |
| `2022_linkage.png` | 2023 年 3 月第 3 题 e | 精确计算：对图中 10、15、20、25、55、60、90、100 用欧氏距离做单连接、全连接、平均连接；同距离合并取一种合法顺序 |
| `2022_regression_tree.png` | 2023 年 3 月第 4 题 a、b | 按原题图估计的形状示意；与 `2021_regression_tree.png` 使用不同阈值和叶值 |

文件名中的 2022 沿用原试卷文件名，实际题面日期为 2023 年 3 月。图由 Matplotlib 绘制；层次聚类树状图使用 SciPy 的 `linkage` 与 `dendrogram` 计算和绘制。正文给出相应公式、合并高度和近似约定。
