## 验证方式与结果

1. **内容核对：** 阅读五份原文转换稿及全部 PDF 页的文本内容；对公式错误、仅含图表的页面和含重要细节的原页进行了图像核对。查看了全部 113 张原转换稿图片的分组预览，并对需要辨认的原页放大检查。
2. **覆盖与引用：** 339 个源页码均映射到中文章节；113 张已有图片全部保留，另补 1 张；中文稿中的图片和本地文件链接均存在，无重复图片引用。
3. **公式渲染：** 以本地 KaTeX 渲染全部 792 处数学表达式，零解析错误、零遗留占位符。浏览器加载五篇预览时无失效图片，无整页横向溢出。
4. **视觉抽查：** 用本地 Chrome 渲染中文 Markdown，查看各篇开头、中段、结尾共 15 个视口，并检查重要公式与表格所在位置。它是 Markdown 渲染抽查，不是对原 PDF 每一页逐像素验收，也不是对所有 Markdown 阅读器的兼容性保证。
5. **数学数值核验：** 对最小二乘梯度、岭回归原始与对偶解、LDA 对数后验比、逻辑回归似然梯度、二次核特征恒等式、截断 SVD 重构误差，以及一个解析可解 SVM 的驻点与互补松弛，共保留 7 项检查，全部通过。最大绝对误差约为 `1.09e-9`，阈值为 `1e-6`。已删除的补充推导所对应的三项核验不再计入当前稿。以上核验用于发现代数、符号和维度错误，不代替定理证明或机器学习实验。

临时核对材料位于 `tmp/course_review/`：`coverage.json` 为页码和图片映射，`math_verification.json` 与 `verify_math.py` 为数值核验，`render/render_report.json` 为渲染检查。HTML 和截图仅用于校对；正式交付为五篇 Markdown 及课程目录。

## 原始材料本身的证据边界

翻译与本地校对已完成，但原课件没有提供的一些条件不能靠翻译补成事实：

- LASSO 的具体风险界、深网 VC 维常数界与若干深度优势、优化结论，原页未列完整假设。中文稿保留其文献线索并限定适用范围；本次没有逐一联网复核原论文。
- Deep Speech 比较表缺少指标名称、单位与完整评测协议，按原表保留数值，不推断为当前产品性能。
- JOLTS、金融、音乐和其他历史图没有配套预处理脚本，图解说明可见内容，不声称复现实验或识别因果。
- 原课件里不完整的讲义网址没有补造，列出的软件与 GitHub 地址没有作为已验证的当前安装方案。

这些是原材料的限制，不是待翻译章节。中文稿已在相应位置明确标识。
