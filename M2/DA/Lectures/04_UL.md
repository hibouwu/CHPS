A. Feature selection: LASSO with optimization methods 

The LASSO for linear models From $\ell _ { 0 }$ to $\ell _ { 1 }$ 

• Consider the LASSO estimation (learning) method: for any $\lambda > 0$ 

$$
\widehat {\beta} _ {\lambda} \in \underset {\beta \in \mathbb {R} ^ {d}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} \beta \| ^ {2} + \lambda \| \beta \| _ {1} \right\}
$$

where the $\ell _ { 1 } { \mathrm { - } } \mathsf { n o r m }$ is: 

$$
\| \beta \| _ {1} = \sum_ {j = 1} ^ {d} | \beta_ {j} |
$$

## Blessings of the LASSO

<sup>•</sup> Approximate solutions via eficient algorithms building the so-called regularization path (find for all values of λ the ${ \widehat { \beta } } ( \lambda ) )$ 

![image](<Images/04_UL/image_003.jpg>)


• Theoretical soundness: it can be shown that (if the real model is linear): as $n , d \to \infty$ 

$$
\frac {1}{n} \mathbb {E} \big (\| \mathbf {X} \beta^ {*} - \mathbf {X} \widehat {\beta} \| ^ {2} \big) \leq C \| \beta^ {*} \| _ {1} \sqrt {\frac {\log d}{n}}
$$

## First algorithm: Least Angle Regression (LARS)

<sup>•</sup> LARS = variant of the incremental stagewise procedure for adding variables in a linear model 

<sup>•</sup> Least Angle Regression paper by Efron-Hastie-Johnstone-Tibshirani (AoS, 2004) 

<sup>•</sup> Previous work by Osborne et al. (2000) on the so-called homotopy method 

<sup>•</sup> Also related to greedy approaches such as Orthogona Matching Pursuit (by Mallat, Zhang (1993), Mallat, Davis, Zhang (1994)) 

<sup>•</sup> Recovers the full regularization path $\lambda \to { \hat { \beta } } ( \lambda )$ of the LASSO 

<sup>•</sup> Success of the procedure based on the fact that LASSO path is piecewise linear. 

<sup>•</sup> Computational eficiency: one ordinary least square computation at each step 

# Least Angle Regression: Pseudocode

1 Start with all coeficients $\beta$ equal to zero. 

2 Find the predictor $x _ { j }$ most correlated with y 

3 Increase the coeficient $\beta _ { j }$ in the direction of the sign of its correlation with y until some other predictor $x _ { k }$ has as much correlation with $\boldsymbol { r } = \boldsymbol { y } - \boldsymbol { \hat { y } }$ as $x _ { j }$ has. 

4 Increase $( \beta _ { j } , \beta _ { k } )$ in their joint least squares direction, until some other predictor $x _ { m }$ has as much correlation with the residual r. 

5 Continue until: all predictors are in the model (corresponding to the solution when λ is small) 

## Second algorithm: Coordinate Descent

<sup>•</sup> Simple idea of one dimensional optimization with cyclic iteration over all variables, until convergence 

<sup>•</sup> Optimization at each step amounts to a one-dimensional LASSO problem 

<sup>•</sup> Solution obtained as a soft thresholding of the one-dimensional ordinary least square estimate.

# Third algorithm: Proximal methods

Parikh-Boyd tutorial paper (2013): ”Much like Newton’s method is a standard tool for solving unconstrained smooth optimization problems of modest size, proximal algorithms can be viewed as an analogous tool for nonsmooth, constrained, large-scale, or distributed versions of these problems.” 

• Early work goes back to Moreau (1960s) then Nemirovski, Yudin (1983) 

<sup>•</sup> Rediscovered around 2005 with applications to signal processing and solving certain optimization problems <sup>•</sup> Applies to a problem of the form: 

$$
\min _ {\beta} \left\{L (\beta) + \psi (\beta) \right\}
$$

when: L is smooth, convex, with ”bounded” gradient, and $\psi$ is continuous, convex, but non-smooth 

<sup>•</sup> The proximal algorithm is a descent algorithm which provides a sequence $\beta _ { t }$ obtained as follows: at each step t, 

$$
\beta_ {t} = \operatorname{prox} \left(\psi , \beta_ {t - 1} - \nabla L \left(\beta_ {t - 1}\right)\right)
$$

where prox is the so-called proximal operator (generalizes the concept of orthogonal projection) 

## Proximal method $( 2 / 4 )$ Definition of proximal operator

<sup>•</sup> Definition of the proximal operator for the nonsmooth term $\psi$ of the objective $L + \psi$ 

$$
\operatorname{prox} \bigl (\psi , z \bigr) = \arg \min _ {\beta} \left\{\frac {1}{2} \| \beta - z \| _ {2} ^ {2} + \psi (\beta) \right\}
$$

<sup>•</sup> Interpretation: The proximal operator finds a point that corresponds to a trade-of between minimizing $\psi$ and being near to the point z. 

## Proximal method (3/4) Application to LASSO

<sup>•</sup> Here: $\begin{array} { r } { L ( \beta ) = \frac { 1 } { 2 } \| X \beta - y \| _ { 2 } ^ { 2 } } \end{array}$ and $\psi ( { \boldsymbol { \beta } } ) = \lambda \| { \boldsymbol { \beta } } \| _ { 1 }$ 

<sup>•</sup> Gradient step relies on the gradient of the smooth term L: 

$$
\nabla L (\beta) = X ^ {T} (X \beta - y)
$$

<sup>•</sup> Proximal operator for the $\ell _ { 1 }$ norm is given by: 

$$
\operatorname{prox} (\lambda \| \cdot \| _ {1}, z) = (z - \lambda) _ {+} - (- z - \lambda) _ {+}
$$

(soft thresholding operator on each component of $z )$ 

• Also called ISTA (for Iterative Shrinkage Thresholding Algorithm) 

<sup>•</sup> Special cases: gradient descent, projected gradient 

<sup>•</sup> Accelerated version: FISTA for Fast Iterative Shrinkage Thresholding Algorithm 

<sup>•</sup> Numerical convergence: from $O ( 1 / t )$ to $O ( 1 / t ^ { 2 } )$

## What all students should know PCA

<sup>•</sup> Motivation: Dimensionality reduction 

• Principle: Find an orthogonal basis to represent (project on) the data, which captures the directions of highest dispersion (variance) of the data 

<sup>•</sup> Underlying assumption: Gaussian, highly correlated data 

![image](<Images/04_UL/image_005.jpg>)


## PCA Classical construction

• Compute the covariance (or correlation) matrix of the data 

• Find the eigen-elements (values/vectors) - eigenvectors being orthogonal - of this matrix 

<sup>•</sup> Principal components are ordered from the larger eigenvalue to the smallest 

• Dimensionality reduction from d to (small) r is performed by projecting the initial data points on the first (principal) r eigenvectors

## A diferent view on PCA

<sup>•</sup> Denote by $X$ the data matrix of size $d \times n$ (assume that the points are centered) and by $\begin{array} { r } { \| M \| _ { F } ^ { 2 } = \sum _ { i , j } M _ { i j } ^ { 2 } } \end{array}$ the square of the Frobenius norm of the matrix $M = ( \bar { M } _ { i j } ) _ { i j }$ 

<sup>•</sup> Solve the minimization problem: 

$$
\min _ {P, Z} \| X - P Z \| _ {F} ^ {2} \text {subject to} P ^ {T} P = I _ {r}
$$

where $P$ is the projection matrix of size $d \times r$ (the matrix whose columns are the first r eigenvectors), and $Z$ is $r \times n$ matrix of the projected points in the r-dimensional subspace. We also have the orthogonality constraint $P ^ { T } P = I _ { r }$ (eigenvectors are orthogonal) 

## A low-rank formulation of PCA

<sup>•</sup> An alternative formulation to the previous optimization problem, by setting: $A = P Z$ , is: 

$$
\min _ {A} \| X - A \| _ {F} ^ {2} \text {   subject   to   } \operatorname{rank} (A) = r
$$

• Theoretical result (Vidal, Ma, Sastry (2016)): an optima solution to this problem is given by: 

$$
A = U _ {r} \Sigma_ {r} V _ {r}
$$

where $U _ { r }$ and $V _ { r }$ have orthogonal columns of size $d \times r$ and $n \times r$ respectively, $\textstyle \sum _ { r }$ diagonal square matrix of size $r \times r$ The matrices $U _ { r } , \ \Sigma _ { r } , \ V _ { r }$ correspond to the reduced singular value decomposition (SVD) of matrix X. 

## Some linear algebra background: SVD decomposition

A generalization of eigenvalues and eigenvectors. 

<sup>•</sup> Definition: σ is a singular value of a rectangular $d \times n$ matrix X if there exist unit two vectors $u \in \mathbb { R } ^ { d }$ and $v \in \mathbb { R } ^ { n }$ such that 

$$
X ^ {T} u = \sigma v \mathrm{and} X v = \sigma u
$$

The vectors u and v are called singular vectors. 

<sup>•</sup> Theorem: For any rectangular matrix, there exist U and V orthogonal matrices of size $d \times d$ and $n \times n$ respectively and a diagonal matrix $\boldsymbol { \Sigma }$ of size $d \times n$ such that: 

$$
X = U \Sigma V ^ {T}
$$

Matrix completion: Recommender Systems Application 

![image](<Images/04_UL/image_021.jpg>)


• Original optimization formulation (kind of ”Ivanov Regularization” with no error on the available matrix entries - our data) 

$$
\min _ {X} \{\operatorname{rank} (X) \} \text {   subject   to   } X _ {i j} = M _ {i j}    , \forall (i, j) \in \Omega
$$

where $\Omega = \{ ( i , j ) : M _ { i j }$ the available data}. 

<sup>•</sup> Key Challenge: Non-convex problem, hard to solve 

Convex Relaxation 

<sup>•</sup> Recall the nuclear norm of X is $\| X \| _ { * } = \sum _ { i = 1 } \sigma _ { i }$ , where $\sigma _ { i }$ are the singular values of X (recall the SVD of X is $X = U \Sigma V ^ { T } )$ 

<sup>•</sup> Convex formulation of the matrix completion problem: 

$$
\min _ {X} \| X \| _ {*} \text {   subject   to   } X _ {i j} = M _ {i j}, \forall (i, j) \in \Omega
$$

where $\Omega = \{ ( i , j ) : M _ { i j }$ the available data}. 

<sup>•</sup> Regularization formulation: Nuclear norm penalty 

$$
\min _ {X} \left\{\frac {1}{2} \sum_ {i j \in \Omega} (X _ {i j} - M _ {i j}) ^ {2} + \lambda \| X \| _ {*} \right\}
$$

• Simplified problem (no mask Ω): 

$$
\min _ {X} \left\{\frac {1}{2} \| X - M \| ^ {2} + \lambda \| X \| _ {*} \right\}
$$

<sup>•</sup> The solution is closed form and given by: 

$$
\operatorname{shrink} (X, \lambda) = U \Sigma (\lambda) V ^ {T}
$$

where $\Sigma ( \lambda ) = \mathrm { d i a g } ( ( \sigma _ { i } - \lambda ) _ { + } )$ 

<sup>•</sup> Note: the solution uses only the singular values that are larger than λ... 

<sup>•</sup> Need a trick to deal with the $\Omega$ 

<sup>•</sup> Use an auxiliary matrix Y which is complete 

<sup>•</sup> Define $\Pi _ { \Omega } ( X )$ the matrix with coeficients $X _ { i j }$ if $( i , j ) \in \Omega$ and zero if $( i , j ) \notin \Omega$ 

<sup>•</sup> Iterative algorithm $\left( \mathsf { c a l l e d } ^ { \prime \prime } \mathsf { S V T } ^ { \prime \prime } \right)$ 

1 Set $\lambda > 0$ and sequence of step sizes $( \delta _ { k } ) _ { k \geq 1 }$ 

2 Start with $Y _ { 0 } = 0$ matrix of size $n \times m$ 

3 At each step $k ,$ compute: 

$$
\left\{ \begin{array}{l l} X _ {k} & = \text { shrink } (Y _ {k - 1}, \lambda) \\ Y _ {k} & = Y _ {k - 1} + \delta_ {k} \Pi_ {\Omega} (M - X _ {k}) \end{array} \right.
$$

## Sparse coding Formulation

• Objective: find both A (the ”features”) and Y that yield to the sparse representation of the data X up to some error ε 

<sup>•</sup> Formulation: 

$$
\min _ {A, Y} \left\{\sum_ {i = 1} ^ {n} \| Y _ {i} \| _ {0} \right\} \text {   subject   to   } \| X - A Y \| _ {2} \leq \varepsilon
$$

<sup>•</sup> But: for fixed $A ,$ , minimization over Y is convex but the joint optimization wrt both A and Y is not convex 

<sup>•</sup> Main strategy for non convex matrix factorization problems: alternating minimization (Douglas-Rachford) or Block coordinate descent

C.3. Compressed sensing 

## A revolution in signal processing

<sup>•</sup> Classical signal representation relies on first measuring then compressing (the information/data - hence ”finding the rules/laws”) 

<sup>•</sup> Take-home message: Sparsity and regularization are the keys for extreme compression 

<sup>•</sup> Technological breakthroughs have been achieved in imaging such as the ”one-pixel camera” 

• Pioneering work by Cand`es-Romberg-Tao (2006) and Donoho (2006) 

<sup>•</sup> Want to recover the signal $\boldsymbol { y } \in \mathbb { R } ^ { d }$ based on few measurements $x _ { i } = z _ { i } ^ { T } y$ for $i = 1 , \ldots , n$ with $\boldsymbol { n } \ll d$ where $z _ { i }$ are random ”directions”. 

<sup>•</sup> Assumption: the signal y has a sparse linear representation, meaning that there exists a sparse vector $\beta$ such that $y = \Psi \beta$ where Ψ is the matrix of basis vectors. 

<sup>•</sup> Compressed sensing can then be formulated as a linear program wrt $\beta \mathbf { : }$ : 

$$
\min _ {\beta \in \mathbb {R} ^ {d}} \| \beta \| _ {1} \text {   subject   to   } X = Z \Psi \beta
$$

where the vector $X \in \mathbb { R } ^ { n }$ contains the observations, and the two matrices $Z$ (design matrix of size $n \times d )$ and $\boldsymbol { \Psi }$ (square matrix $d \times d$ , basis of $\mathbb { R } ^ { d } )$ are fixed and known. 

• Eventually, the signal is recovered (de-compressed) thanks to the relation $y = \Psi \beta$
