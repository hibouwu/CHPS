## 怎样读这组讲义

第一次读，先把输入、预测对象、损失和训练方法对应起来；看到公式时，确认它在定义目标、给出解，还是评价误差。遇到一个定理，不必立即追完所有证明，但要知道它比较什么、需要哪些条件。

导论已按原课件第 1–47 页顺序编排，并从三段课堂转录中提炼重要概念，补入跌倒检测、客户排序、损失代价和两类误差等例子。文末提供课件与转录的对应关系；转录含识别错误与课间谈话，核对课堂说法时应结合原课件。

导论中的 PAC 证明和随机设计方差、第 02 篇的 AIC 推导等可以在主线清楚后回读。第 05 篇前 31 页主要复习分类和线性 SVM，已掌握第 03 篇时可以从核 SVM 进入。第 04 篇的无监督学习主线从 PCA 展开，前面的 LASSO 部分是在补求解工具。

每篇末尾的自检问题要求解释原因或判断条件，适合检查自己是否真正理解。它们是学习辅助，不是原课件题目或考试范围承诺。历史图、外部定理及原文勘误仍保留各自的适用边界。
