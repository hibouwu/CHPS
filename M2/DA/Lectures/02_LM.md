## General setup Notations

<sup>•</sup> Goal of learning: an optimal decision function $h ^ { \ast } : \mathcal { X }  \mathcal { V }$ $\mathcal { X } \mathrm { : }$ : domain set, Y: label set 

<sup>•</sup> Input of learning: 

<sup>•</sup> Training data: a set of labeled data 

$$
D _ {n} = \{(X _ {1}, Y _ {1}), \dots , (X _ {n}, Y _ {n}) \}
$$

of size n, where the $( X , Y ) ^ { \prime } s$ are in $\mathcal { X } \times \mathcal { V }$ 

<sup>•</sup> Hypothesis space: a collection $\mathcal { H }$ of candidate decision functions $h : \mathcal { X }  \mathcal { Y }$ 

<sup>•</sup> Output of learning: an empirical decision function $\widehat { h }$ in the hypothesis space $\mathcal { H }$ estimated from training data $D _ { n }$ 

<sup>•</sup> Reference in $\mathcal { H } \mathrm { : }$ : the best decision function $\bar { h }$ in the class (the more data, the closer $\widehat { h }$ to $\bar { h } )$ 

## The key trade-of in Machine Learning

<sup>•</sup> Denote by $L ( h )$ the error measure for any decision function h 

<sup>•</sup> We have: $L ( \bar { h } ) = \operatorname* { i n f } _ { \mathcal { H } } L$ , and $L ( h ^ { * } ) = \mathsf { i n f } L$ 

<sup>•</sup> Bias-Variance type decomposition of error for any output $\widehat { h }$ : 

$$
L (\widehat {h}) - L (h ^ {*}) = \underbrace {L (\widehat {h}) - L (\bar {h})} _ {\text { estimation   (stochastic)}} + \underbrace {L (\bar {h}) - L (h ^ {*})} _ {\text { approximation   (deterministic)}}
$$

## Reminder on linear models in statistics The regression case

<sup>•</sup> Goal of learning: $h ^ { * } : \mathbb { R } ^ { d }  \mathbb { R }$ 

<sup>•</sup> Observations: IID random pairs $( X _ { i } , Y _ { i } ) \in \mathbb { R } ^ { d } \times \mathbb { R }$ 

$$
Y _ {i} = h ^ {*} (X _ {i}) + \varepsilon_ {i}, \quad i = 1, \dots , n
$$

where $\varepsilon _ { i }$ is a random noise variable independent of $X$ 

<sup>•</sup> We shall use a vector notation as follows: 

$$
\mathbf {Y} = \mathbf {h} ^ {*} + \varepsilon
$$

where the three terms are all in $\mathbb { R } ^ { n }$ 

<sup>•</sup> Elements in $\mathbb { R } ^ { n }$ : 

$$
\mathbf {Y} = \left(Y _ {1}, \dots , Y _ {n}\right) ^ {T},
$$

$$
\varepsilon = \left(\varepsilon_ {1}, \dots , \varepsilon_ {n}\right) ^ {T}
$$

<sup>•</sup> Image vectors: for any $h \in \mathcal H$ , we use the bold characters as 

$$
\mathbf {h} = \left(h (X _ {1}), \dots , h (X _ {n})\right) ^ {T}
$$

<sup>•</sup> The image of data points through elements of $\mathcal { H }$ by 

$$
\mathcal {H} (X) = \left\{\mathbf {h} = \left(h \left(X _ {1}\right), \dots , h \left(X _ {n}\right)\right) ^ {T},: h \in \mathcal {H} \right\}
$$

<sup>•</sup> Norm in $\mathbb { R } ^ { n }$ : 

$$
\forall u = \left(u _ {1}, \ldots , u _ {n}\right) ^ {T} \in \mathbb {R} ^ {n}, \| u \| ^ {2} = \sum_ {i = 1} ^ {n} u _ {i} ^ {2}
$$

<sup>•</sup> Definition of the LSE : 

$$
\widehat {\mathbf {h}} _ {\mathbf {n}} = \underset {\mathbf {h} \in \mathcal {H} (X)} {\arg \min} \frac {1}{n} \| \mathbf {Y} - \mathbf {h} \| ^ {2}
$$

where ${ \mathcal { H } } ( X ) = \{ \boldsymbol { \mathsf { h } } = ( h ( X _ { 1 } ) , \ldots , h ( X _ { n } ) ) ^ { T } , : h \in { \mathcal { H } } \}$ 

• Assuming that the linear model is gaussian (i.e. the noise variables are IID and follow a centered gaussian distribution with fixed and known variance), then the LSE also corresponds to the Maximum Likelihood estimator. 

<sup>•</sup> The hypothesis space $\mathcal { H }$ is the class of linear functions of rank $d$ 

<sup>•</sup> The noise vector $\boldsymbol { \varepsilon } = ( \varepsilon _ { 1 } , \ldots , \varepsilon _ { n } ) ^ { T }$ is a gaussian random vector in $\mathbb { R } ^ { n }$ with distribution ${ \mathcal { N } } _ { n } ( 0 , \sigma ^ { 2 } I _ { n } )$

<sup>•</sup> Linear regression: $\begin{array} { r } { h ( x ) = \sum _ { k = 1 } ^ { d } \beta _ { k } x ^ { ( k ) } } \end{array}$ 

• Basis/frame expansion (Fourier, splines, wavelets, etc.) 

<sup>•</sup> Additive models: $h ( x ) = \sum _ { k = 1 } ^ { d } f _ { k } ( x ^ { ( k ) } )$ 

• Piecewise constant regression (taking into account breakpoints) 

## LSE in linear regression

<sup>•</sup> Denote by $\pmb { \mathsf { X } } \in \mathbb { R } ^ { n \times d }$ the data matrix and $\boldsymbol { \beta } \in \mathbb { R } ^ { d }$ the parameter to estimate 

<sup>•</sup> Assumption: X is of full rank equal to d and assume $d \leq n$ 

<sup>•</sup> Definition of LSE: $\begin{array} { r } { \widehat { \beta } _ { \mathfrak { n } } = \arg \operatorname* { m i n } _ { \beta \in \mathbb { R } ^ { d } } \frac { 1 } { n } \| \pmb { \mathsf { Y } } - \pmb { \mathsf { X } } \beta \| ^ { 2 } } \end{array}$ 

<sup>•</sup> Least square estimate: $\widehat { \mathbf { h } } _ { \mathbf { n } } = \mathbf { X } \widehat { \beta } _ { \mathbf { n } } = \mathbf { X } ( \mathbf { X } ^ { T } \mathbf { X } ) ^ { - 1 } \mathbf { X } ^ { T } \mathbf { Y } = \widehat { \Pi } \mathbf { Y }$

## Proof of the LSE computation in linear models

$$
\widehat {\beta} _ {\mathbf {n}} = \underset {\beta \in \mathbb {R} ^ {d}} {\arg \min} R (\beta) \text {   where   } R (\beta) = \frac {1}{n} \| \mathbf {Y} - \mathbf {X} \beta \| ^ {2}
$$

<sup>•</sup> Gradient computation: 

$$
\frac {d}{d \beta} \left((\mathbf {Y} - \mathbf {X} \beta) ^ {T} (\mathbf {Y} - \mathbf {X} \beta)\right) = - 2 \mathbf {Y} ^ {T} \mathbf {X} + 2 \beta^ {T} \mathbf {X} ^ {T} \mathbf {X} \in \mathbb {R} ^ {1 \times d}
$$

<sup>•</sup> First-order condition for the minimizer of a convex function: 

$$
- \mathbf {Y} ^ {T} + \beta^ {T} \mathbf {X} ^ {T} \mathbf {X} = 0
$$

<sup>•</sup> Final result: $\widehat { \beta } _ { \mathfrak { n } } = ( \mathsf { X } ^ { T } \mathsf { X } ) ^ { - 1 } \mathsf { X } ^ { T } \mathsf { Y }$ 

## Alternate proof based on chain rule

<sup>•</sup> Let: $R ( \beta ) = \ell ( e ( \beta ) )$ where $\ell ( e ) = \| e \| ^ { 2 }$ and $\boldsymbol { e } ( \beta ) = \boldsymbol { \mathsf { Y } } - \boldsymbol { \mathsf { X } } \beta$ 

<sup>•</sup> Chain rule: $\frac { d R } { d \beta } = \frac { \partial \ell } { \partial e } \frac { \partial e } { \partial \beta }$ where the $j \mathrm { - t h }$ element is given by: 

$$
\frac {d R}{d \beta} [ j ] = \sum_ {k = 1} ^ {n} \frac {\partial \ell}{\partial e} [ k ] \frac {\partial e}{\partial \beta} [ k, j ]
$$

<sup>•</sup> Note that: $\frac { \partial \ell } { \partial e } = 2 e ^ { T } \in \mathbb { R } ^ { 1 \times n }$ and $\frac { \partial e } { \partial \beta } = - { \pmb X } \in \mathbb { R } ^ { n \times d }$ 

<sup>•</sup> Finally: $\frac { d R } { d \beta } = - 2 e ^ { T } { \bf X } = - 2 ( \forall - \bf { X } \beta ) ^ { T } { \bf X }$

## Bias-variance decomposition (1/2) Derivation

<sup>•</sup> First note that: $\widehat { \mathbf { h } } _ { \mathbf { n } } = \widehat { \Pi } \mathbf { Y } = \widehat { \Pi } ( \mathbf { h } ^ { * } + \varepsilon )$ and then 

$$
\mathbf {h} ^ {*} - \widehat {\mathbf {h}} _ {\mathfrak {n}} = (I _ {n} - \widehat {\Pi}) \mathbf {h} ^ {*} - \widehat {\Pi} \varepsilon
$$

<sup>•</sup> Note that $\widehat { \Pi } : \mathbb { R } ^ { n } \to \mathbb { R } ^ { n }$ the orthogonal projection onto $\mathcal { H } ( X )$ 

$$
\widehat {\Pi} \circ \widehat {\Pi} = \widehat {\Pi}
$$

<sup>•</sup> By orthogonality of the images of $I _ { n } - { \widehat { \Pi } }$ and $\widehat { \Pi } .$ : 

$$
\begin{array}{r} L (\widehat {h} _ {n}) = \frac {1}{n} \mathbb {E} \big (\| \mathbf {h} ^ {*} - \widehat {\mathbf {h}} _ {\mathbf {n}} \| ^ {2} \big) \\ = \frac {1}{n} \mathbb {E} \big (\| (I _ {n} - \widehat {\Pi}) \mathbf {h} ^ {*} \| ^ {2} + \| \widehat {\Pi} \varepsilon \| ^ {2} \big) \end{array}
$$

## Bias-variance decomposition (2/2) Result

• Using an additional technical result (next slide): 

$$
\begin{array}{r l} & L (\widehat {h} _ {n}) = \frac {1}{n} \mathbb {E} \big (\| \mathbf {h} ^ {*} - \widehat {\mathbf {h}} _ {\mathbf {n}} \| ^ {2} \big) \\ & \quad = \frac {1}{n} \mathbb {E} \big (\| (I _ {n} - \widehat {\Pi}) \mathbf {h} ^ {*} \| ^ {2} + \| \widehat {\Pi} \varepsilon \| ^ {2} \big) \\ & \quad = \underbrace {\frac {1}{n} \mathbb {E} \big (\| (I _ {n} - \widehat {\Pi}) \mathbf {h} ^ {*} \| ^ {2} \big)} _ {\text {bias}} + \underbrace {\sigma^ {2} \frac {d}{n}} _ {\text {variance}} \end{array}
$$

• Used in model selection (e.g. AIC = Akaike Information Criterion) 

## Explanation of the d/n term

Property on the norm of projections of gaussian random vectors: 

<sup>•</sup> Assume $\mathbf { Z }$ is a gaussian random vector $ { \mathcal { N } _ { n } } ( 0 ,  { I _ { n } } )$ in $\mathbb { R } ^ { n }$ , H is a linear subspace of $\mathbb { R } ^ { n }$ and $\Pi : \mathbb { R } ^ { n }  \mathbb { R } ^ { n }$ a linear projection onto $\mathcal { H }$ 

<sup>•</sup> Then: the random vector $\Pi _ { \mathcal { H } } \mathbf { Z }$ has gaussian distribution $\mathcal { N } _ { n } ( 0 , \Pi )$ on $\mathbb { R } ^ { n }$ (linear transformation of a gaussian is a gaussian) 

<sup>•</sup> Furthermore: $\| \boldsymbol { \Pi } \pm \boldsymbol { Z } \| ^ { 2 }$ follows a chi-square distribution with 

$$
\mathbb {E} (\| \Pi \mathbf {Z} \| ^ {2}) = \dim (\mathcal {H})
$$

## The sparse linear regression model

<sup>•</sup> Intuition: what if there are uninformative variables in the model but we do not know which they are? 

<sup>•</sup> Sparsity assumption: Let $\beta ^ { * }$ the true parameter which only a subset of variables (called support) 

$$
m ^ {*} = \{j: \beta_ {j} ^ {*} \neq 0 \} \subset \{1, \dots , d \}
$$

$\ell _ { 0 }$ norm of any β: $\| \beta \| _ { 0 } = \sum _ { j = 1 } ^ { d } \mathbb { I } \{ \beta _ { i } \neq 0 \}$ 

Two possible formulations Constrained vs. Penalized optimization 

1 Ivanov formulation: take k between $0$ and min $\{ n , d \}$ 

$$
\min _ {\beta \in \mathbb {R} ^ {d}} \| \mathbf {Y} - \mathbf {X} \beta \| _ {2} ^ {2} \quad \text { subject   to } \| \beta \| _ {0} \leq k
$$

2 Tikhonov formulation: take $\lambda > 0$ 

$$
\min _ {\beta \in \mathbb {R} ^ {d}} \left\{\| \mathbf {Y} - \mathbf {X} \beta \| _ {2} ^ {2} + \lambda \| \beta \| _ {0} \right\}
$$

<sup>•</sup> Tikhonov looks as a Lagrange formulation of Ivanov 

<sup>•</sup> But here the two formulations are NOT equivalent due to the lack of smoothness of the $\ell _ { 0 }$ norm 

<sup>•</sup> Ivanov with $\ell _ { 0 }$ constraint is known as the Best Subset Selection problem for which there are algorithms based on heuristics (e.g. Forward Stagewise Regression) which work ok up to $k \simeq 3 5$ . Recent advances: check Mixed Integer Optimization (MIO) formulation by Bertsimas et al. (2016).

## Model selection in linear models

<sup>•</sup> Consider the set $\mathcal { M }$ of subsets m of the variables among indices $\{ 1 , \ldots , d \}$ . There are $2 ^ { d }$ such sets m. 

<sup>•</sup> For every $m \in { \mathcal { M } }$ , there is a standard linear regression model with dimension $| m |$ . In other words, for those $j \notin m _ { \cdot }$ , we have $\theta _ { j } ^ { * } = 0$ 

<sup>•</sup> Denote by $\mathsf { X } _ { m }$ the submatrix of X of size $n \times | m |$ which contains only the columns whose index belongs to m 

<sup>•</sup> For each model $m \in { \mathcal { M } }$ , compute the constrained Least Square Estimator $\widehat { \theta } _ { n } ^ { ( m ) } = ( \mathsf { X } _ { m } ^ { T } \mathsf { X } _ { m } ) ^ { - 1 } \mathsf { X } _ { m } ^ { T } \mathsf { Y } \in \mathbb { R } ^ { | m | }$ 

<sup>•</sup> The final estimator is the ”best” among ${ \widehat { \theta } } _ { n } ^ { ( m ) }$ over all $m \in { \mathcal { M } }$ 

<sup>•</sup> Denote by $\mathsf { X } _ { m }$ the data matrix of size $n \times | m |$ 

<sup>•</sup> Risk of the predictor: $r _ { m } = \frac { 1 } { n } \mathbb { E } \big ( \| \mathbf { X } \theta ^ { * } - \mathbf { X } _ { m } \widehat { \theta } _ { n } ^ { ( m ) } \| ^ { 2 } \big )$ 

• Best theoretical estimator (called oracle): 

$$
\widehat {\theta} _ {n} ^ {(\overline {{m}})} \quad \text {where} \quad \overline {{m}} = \underset {m \in \mathcal {M}} {\arg \min} r _ {m}
$$

• Penalized LS with Akaike Information Criterion (AIC) 

$$
\widehat {m} = \underset {m \in \mathcal {M}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} + 2 | m | \sigma^ {2} \right\}
$$

(can be computed from data assuming $\sigma ^ { 2 }$ is known)

## Bias-variance decomposition (1/2) Derivation

<sup>•</sup> Note that $\widehat { \Pi } _ { m } : \mathbb { R } ^ { n }  \mathbb { R } ^ { n }$ is the orthogonal projection onto the space generated by the directions in m: 

$$
\widehat {\Pi} _ {m} \circ \widehat {\Pi} _ {m} = \widehat {\Pi} _ {m}
$$

<sup>•</sup> We have: $\begin{array} { r } { \pmb { \chi } _ { m } \widehat { \theta } _ { n } ^ { ( m ) } = \widehat { \Pi } _ { m } \pmb { \Upsilon } = \widehat { \Pi } _ { m } ( \pmb { \Upsilon } \theta ^ { \ast } + \pmb { \varepsilon } ) } \end{array}$ and then 

$$
\mathbf {X} \theta^ {*} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} = (I _ {n} - \widehat {\Pi} _ {m}) \mathbf {X} \theta^ {*} - \widehat {\Pi} _ {m} \varepsilon
$$

<sup>•</sup> Property of the projector: images of $I _ { n } - \widehat { \Pi }$ and $\widehat { \Pi }$ are orthogonal 

<sup>•</sup> Therefore: 

$$
\begin{array}{r l} {r _ {m}} & {= \frac {1}{n} \mathbb {E} \left(\| (I _ {n} - \widehat {\Pi} _ {m}) \mathbf {X} \theta^ {*} \| ^ {2} + \| \widehat {\Pi} _ {m} \varepsilon \| ^ {2}\right)} \\ & {= \frac {1}{n} \mathbb {E} \left(\| (I _ {n} - \widehat {\Pi} _ {m}) \mathbf {X} \theta^ {*} \| ^ {2}\right) + \sigma^ {2} \frac {| m |}{n}} \end{array}
$$

since $\| \widehat { \Pi } _ { m } \varepsilon \| ^ { 2 }$ follows a chi-square distribution with $| m |$ degrees of freedom (property of projections of multivariate gaussian vectors). 

## Akaike Information Criterion (1/2) Derivation

<sup>•</sup> Similarly, we can derive: 

$$
\frac {1}{n} \mathbb {E} \big (\| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} \big) = \frac {1}{n} \mathbb {E} \big (\| (I _ {n} - \widehat {\Pi} _ {m}) \mathbf {X} \theta^ {*} \| ^ {2} \big) + \sigma^ {2} \frac {(n - | m |)}{n}
$$

Indeed: $\begin{array} { r } { \mathsf { \pmb { Y } } - \mathsf { \pmb { X } } _ { m } \widehat { \theta } _ { n } ^ { ( m ) } = \big ( I _ { n } - \widehat { \Pi } _ { m } \big ) ( \mathsf { \pmb { X } } \theta ^ { * } + \varepsilon ) } \end{array}$ and $\| I _ { n } - \widehat { \Pi } _ { m } \varepsilon \| ^ { 2 }$ follows a chi-square distribution with $n - | m |$ degrees of freedom 

<sup>•</sup> Combining the two identities, prediction error can be related to risk: 

$$
\frac {1}{n} \mathbb {E} \big (\| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} \big) = r _ {m} + \sigma^ {2} \frac {(n - 2 | m |)}{n}
$$

## Akaike Information Criterion (2/2) Empirical estimator of the error

<sup>•</sup> We have obtained that: 

$$
r _ {m} = \frac {1}{n} \mathbb {E} \big (\| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} \big) + \sigma^ {2} \frac {(2 | m | - n)}{n}
$$

• Unbiased estimator of the error (assuming known variance): 

$$
\widehat {r} _ {m} = \frac {1}{n} \| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} + \sigma^ {2} \frac {(2 | m | - n)}{n}
$$

<sup>•</sup> Akaike Information Criterion 

$$
\widehat {m} = \underset {m \in \mathcal {M}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} _ {m} \widehat {\theta} _ {n} ^ {(m)} \| ^ {2} + 2 | m | \sigma^ {2} \right\}
$$

## Solving the computation burden The power of convexity

<sup>•</sup> Answer is yes at the cost of the so-called relaxation of the non-convex formulation with the $\ell _ { 0 }$ penalty to a convexified problem with an $\ell _ { 1 }$ penalty. 

## The LASSO for linear models From $\ell _ { 0 }$ to $\ell _ { 1 }$

<sup>•</sup> Consider the relaxation of the previous problem replacing the $\ell _ { 0 } - \mathsf { n o r m }$ by the $\ell _ { 1 } { \mathrm { - } } \mathsf { n o r m }$ 

$$
\| \beta \| _ {1} = \sum_ {j = 1} ^ {d} | \beta_ {j} |
$$

<sup>•</sup> The new estimator is called the ${ \mathsf { L } } { \mathsf { A } } { \mathsf { S } } { \mathsf { S } } { \mathsf { O } }$ : for any $\lambda > 0$ 

$$
\widehat {\beta} _ {\lambda} \in \underset {\beta \in \mathbb {R} ^ {d}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} \beta \| ^ {2} + \lambda \| \beta \| _ {1} \right\}
$$

<sup>•</sup> Approximate solutions via eficient algorithms building the so-called regularization paths $\lambda  \widehat { \beta } _ { \lambda }$

# Ill-posed problem in statistics High dimensional least square regression

<sup>•</sup> Assume d larger than n 

<sup>•</sup> Then when solving the least square optimization problem, we observe that we have less equations than variables: this is the case of an underdetermined linear system. 

<sup>•</sup> Another way to put this is to observe that $\mathbf { x } ^ { \tau } \mathbf { x }$ is not ful rank, hence it is not invertible and there is an infinity of solutions. 

## The oldest regularizer in statistics Ridge regression

<sup>•</sup> The Ridge estimator is the solution of the following penalized optimization problem: for any $\lambda > 0$ 

$$
\widehat {\beta} _ {\lambda} \in \underset {\beta \in \mathbb {R} ^ {d}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} \beta \| ^ {2} + \lambda \| \beta \| _ {2} ^ {2} \right\}
$$

## Derivation of ridge regression estimator

<sup>•</sup> We denote the objective function: 

$$
F (\beta) = \left(\mathbf {Y} - \mathbf {X} \beta\right) ^ {T} \left(\mathbf {Y} - \mathbf {X} \beta\right) + \lambda \beta^ {T} \beta
$$

<sup>•</sup> Thanks to convexity and diferentiability of F, we obtain the solution by solving 

$$
\nabla F (\beta) = 2 \mathbf {X} ^ {T} (\mathbf {X} \beta - \mathbf {Y}) + 2 \lambda \beta = 0
$$

<sup>•</sup> Solution: 

$$
\widehat {\beta} _ {\lambda} = \left(\mathbf {X} ^ {T} \mathbf {X} + \lambda I _ {d}\right) ^ {- 1} \mathbf {X} ^ {T} \mathbf {Y}
$$

because ${ \pmb { \times } } ^ { T } { \pmb { \times } } + \lambda I _ { d }$ always invertible. 

<sup>•</sup> Computation still painful for d very large... 

## Dual optimization problem Formulation and KKT conditions

<sup>•</sup> Equivalent formulation of ridge regression optimization: 

$$
\min _ {\beta \in \mathbb {R} ^ {d}, r \in \mathbb {R} ^ {n}} \left\{\frac {1}{2} \| r \| ^ {2} + \frac {\lambda}{2} \| \beta \| ^ {2} \right\} \quad \text { subject   to } r = \mathbf {X} \beta - \mathbf {Y}
$$

<sup>•</sup> Lagrange formulation with multiplier vector $\alpha$ 

$$
\mathcal {L} (\beta , r, \alpha) = \frac {1}{2} \| r \| ^ {2} + \frac {\lambda}{2} \| \beta \| ^ {2} + \alpha^ {T} (r - \mathbf {X} \beta + \mathbf {Y})
$$

<sup>•</sup> Karush-Kuhn-Tucker conditions: zeroing gradient wrt primal variables $\beta , r ,$ , leads to: 

$$
\beta (\alpha) = \frac {1}{\lambda} \mathbf {X} ^ {T} \alpha \quad \mathrm{and} \quad r (\alpha) = - \alpha
$$

## Dual optimization problem Resolution

<sup>•</sup> Then, an equivalent formulation of ridge regression optimization is given by: 

$$
\mathcal {L} (\beta (\alpha), r (\alpha), \alpha) = \frac {1}{2} \| \alpha \| ^ {2} + \frac {1}{2 \lambda} \| \mathbf {X} ^ {T} \alpha \| + \alpha^ {T} \left(- \alpha - \frac {1}{\lambda} \mathbf {X X} ^ {T} \alpha + \mathbf {Y}\right)
$$

<sup>•</sup> Solution: 

$$
\widehat {\alpha} = \lambda \left(\mathbf {X X} ^ {T} + \lambda I _ {n}\right) ^ {- 1} \mathbf {Y} \quad \text { and } \quad \widehat {\beta} = \frac {1}{\lambda} \mathbf {X} ^ {T} \widehat {\alpha}
$$

## Dual optimization problem Interpretation of the result

<sup>•</sup> The prediction on $x \in \mathbb { R } ^ { d }$ can be expressed in terms of α 

$$
x ^ {T} \widehat {\beta} = \frac {1}{\lambda} x ^ {T} \mathbf {X} ^ {T} \widehat {\alpha} = \frac {1}{\lambda} \sum_ {i = 1} ^ {n} \widehat {\alpha} _ {i} x ^ {T} X _ {i}
$$

<sup>•</sup> We can use the identity: 

$\pmb { \mathsf { X } } ^ { T } \left( \pmb { \mathsf { X } } \pmb { \mathsf { X } } ^ { T } + \lambda \pmb { I } _ { n } \right) ^ { - 1 } = \left( \pmb { \mathsf { X } } ^ { T } \pmb { \mathsf { X } } + \lambda \pmb { I } _ { d } \right) ^ { - 1 } \pmb { \mathsf { X } } ^ { T }$ to check the solutions are the same. 

<sup>•</sup> Important observation! Optimization and function evaluation only require the pairwise scalar product between $x ^ { \prime } s$ and data points $X _ { i } ^ { \prime } s$ 

## Elastic Net The best of LASSO and Ridge?

• Rationale (from [Zou and Hastie, 2005]) 

(a) In the $p > n { \mathrm { ~ c a s e } }$ , the lasso selects at most n variables before it saturates, because of the nature of the convex optimization problem. This seems to be a limiting feature for a variable selection method. Moreover, the lasso is not well defined unless the bound on the $L _ { \mathrm { l } } \mathrm { - n o r m }$ of the coefficients is smaller than a certain value 

(b) If there is a group of variables among which the pairwise correlations are very high, then the lasso tends to select only one variable from the group and does not care which one i selected. See Section 2.3. 

(c) For usual $n > p$ situations, if there are high correlations between predictors, it has been empirically observed that the prediction performance of the lasso is dominated by ridge regression (Tibshirani, 1996) 

<sup>•</sup> Combination of $\ell _ { 1 }$ and $\ell _ { 2 }$ penalties 

$$
\widehat {\beta} _ {\lambda} \in \underset {\beta \in \mathbb {R} ^ {d}} {\arg \min} \left\{\| \mathbf {Y} - \mathbf {X} \beta \| ^ {2} + \lambda \| \beta \| _ {1} + \mu \| \beta \| _ {2} ^ {2} \right\}
$$

## From nonlinear to linear Polynomial regression example

<sup>•</sup> Consider a polynomial regression in dimension $d = 2$ : this corresponds to a linear model of dimension $d ^ { \prime } = 7$ with feature vector: 

$$
\Phi (x _ {1}, x _ {2}) = \left(1, \sqrt {2} x _ {1}, \sqrt {2} x _ {2}, \sqrt {2} x _ {1} x _ {2}, x _ {1} ^ {2}, x _ {2} ^ {2}\right) ^ {T}
$$

<sup>•</sup> Note that: 

$$
\Phi (x) ^ {T} \Phi (x ^ {\prime}) = (x ^ {T} x ^ {\prime} + 1) ^ {2}
$$

<sup>•</sup> We call $K ( x , x ^ { \prime } ) = ( x ^ { T } x ^ { \prime } + 1 ) ^ { 2 }$ a polynomial kernel. A kernel has the property to be represented as a scalar product in a high dimensional feature space. The feature space is the image of the original input space of dimension d through Φ. The feature space can be of huge dimension. 

## The magic of kernels Kernel ridge regression

<sup>•</sup> In the linear case of ridge regression, we have seen that the only data-dependent quantities that matter in both problem formulation and evaluation of predictions are the pairwise scalar products of $X _ { i } ^ { T } X _ { j }$ and $x ^ { T } X _ { i }$ 

<sup>•</sup> We can basically replace any scalar product by the kernel evaluation of the considered pair without changing at all the algorithmic complexity of resolution. We are then able to estimate the parameters $\alpha _ { i }$ of nonlinear functions of the form: 

$$
f (x) = \sum_ {i = 1} ^ {n} \alpha_ {i} K (x, X _ {i})
$$
