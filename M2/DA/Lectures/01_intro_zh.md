## 课程导论

<a id="classroom-reading"></a>

**这门课要求你会解释什么**

理解一种方法，需要说清楚：它解决什么任务、输入和输出是什么、核心原理是什么、依赖哪些条件，以及什么时候不能信任结果。只会运行程序或得到一个数值，还不足以判断方法是否适用。形式化记号用于把这些问题说准确，实验则用于把抽象规则变成可观察的结果。

阅读下面的内容时，可以先用一个具体问题理解对象，再回来看符号。例如，先把“图像 → 是否有行人”对应清楚，再读“从输入空间到标签空间的函数”。不必在第一次遇到公式时就掌握全部证明，但要知道公式中的对象和条件分别是什么。

## 数据科学：信息、处理流程与决策

- 为什么？信息 → 数据 → 预测、决策、知识……
- 怎样做？构建从传感器到决策的处理流程。
- 为谁服务？为人服务！人可以参与流程，也可以不参与……

<a id="classroom-data-decisions"></a>

**从传感器读数到真正有用的决策**

**信息、数据和决策是三个不同环节。** 现实中发生的现象先经过测量，成为可保存和计算的数据；算法从这些数据中作出预测，预测再服务于行动或知识积累。测量可能有噪声，采样可能漏掉两次观测之间的变化，记录中也可能缺少理解信号所需的时间或背景信息。因此，“已有很多数据”并不等于“已有解决问题所需的信息”。

以养老院的跌倒检测为例：地板中的压力传感器产生信号，微控制器处理信号，模型判断是否跌倒，护理人员接收警报并决定是否前去查看。电子工程师、算法开发者、机构工作人员和销售人员关注的约束不同；若各环节没有沟通，局部技术指标再好，也可能得不到有用的系统。

| 系统的判断与现实 | 直接后果 | 为什么也要计入目标 |
|---|---|---|
| 实际跌倒，系统没有报警 | 援助延迟，可能造成进一步伤害 | 漏检的代价很高 |
| 没有跌倒，系统却报警 | 护理人员反复无效出动 | 持续误报会削弱信任，使后续真实警报被忽视 |

设想一个系统每小时误报 50 次：即使第 51 次警报对应真实跌倒，也可能因先前的反复误报而被忽视。这就是警报疲劳。这里的次数是情境假设，不是实测数据。两种错误的代价不同，但不能把其中一种当作完全无害。后面学习[损失函数](#classroom-loss-cost)时，就是把“什么错误更值得避免”写进数学目标。

目标还决定时间尺度：跌倒检测服务于即时行动；长期随访研究可能希望在十年、二十年后积累对某类人群的知识。算法输出可以是检测、预测或知识线索，最终行动也可能由人来决定。

<details>
<summary>课堂案例：数据湖、医院排班与“有数据却用不上”</summary>

转录记录的数据湖案例有一个共同问题：项目投入了存储、索引、数据库和访问架构，却在集中收集数据之后才考虑用途。具体困难包括：缺少目标需要的字段；数据虽在库中，却难以提取；或者大量数据没有明确的使用目标。

在转录所述的疫情期间案例中，有医院需要判断次日护理或影像服务能否运行，员工请假等信息虽然存在于信息系统中，却不能及时以合适格式汇总，因而无法支持眼前的预测与安排。这个例子说明，数据是否可用取决于具体问题、时间要求和访问流程，而不仅是存储容量。

另一个例子是监护设备：屏幕能显示读数，不代表医院保存了原始信号。厂商可能保有较细的数据，却缺乏病人在院期间和出院后的情境；医护人员了解事件和病程，却未必掌握相应的细粒度记录。信息分散在不同主体手里，会妨碍事件对齐和后续学习。这些案例反映了数据衔接的问题，不能推广成所有设备或医院的共同现状。

“要测量什么”和“要获得什么知识”可以不同：视频中的变化可以作为提取生理信号的线索，长期人群观察则可能用于研究治疗效果或药物的不同用途。原转录提到的药物名称 Ozempic、Viagra 及具体用途属于口头旁例，本讲不据此给出药理、适应证或因果结论。

<summary>课堂讨论：数据访问、人是否参与、谁对结果负责</summary>

数据来源可以是互联网，也可以是连接计算机的物理传感器。公开可见、技术上可取得和有权使用是不同问题；还需要考虑个人数据、访问权限和数据盗取，不能把“能下载”视作充分条件。

## 数据科学的三个支柱

1. 硬件：传感器、计算能力、通信、接口。
2. 软件环境：用于设计、测试和运行。
3. 数学建模与算法：高维统计、降维、机器学习、网络科学、时间序列等。

<a id="classroom-representation"></a>

**一行数据为什么是一个点，坐标为什么不能随意混排**

对 20 个人各测量 50 个变量，得到一个 **20 行、50 列** 的表。每行代表一个人，每列代表一种属性；于是共有 20 个样本，每个样本位于 50 维特征空间中。这里的“维度”是描述一个样本需要多少个数，不是班级有多少人，也不是物理空间有多少个方向。

我们无法直接画出这个 50 维点云，但仍能计算距离、做预测或降维。把 50 维表示变成 5 维表示，是用较少变量保留某些所关心的结构；保留什么必须由任务和方法决定。从平均成绩到招聘评价，把多项信息压成一个分数，都包含权重和目标选择；考试成绩、知识、协作等维度不一定在不同任务中同样重要。

还要区分“变量存在”与“变量之间的结构”。

| 数据 | 例子 | 应保留的结构 |
|---|---|---|
| 属性表 | 信贷申请中的收入、透支情况等 | 每列的语义和单位；列顺序变更时要同步修改解释与模型输入 |
| 时间序列 | 账户余额逐月正负交替 | 时间顺序；把正数全放前面、负数全放后面，会把规律性收支变成“最近连续透支” |
| 图像 | 像素网格及 RGB 通道 | 像素位置、空间邻接和通道关系 |
| 关系数据 | 网络中的对象及其连接 | 哪些对象相连，以及连接的含义 |

**补充说明：** 图像按固定、可逆的顺序展平为向量，本身不会丢失像素信息；已知宽高和排列规则就能还原。问题在于丢失位置映射，或使用的算法没有利用空间邻接结构。“打乱坐标会破坏图像”应在这个意义上理解。同样，普通属性表也不能在预测时随意交换列而不通知模型。

<details>
<summary>补充理解：三个支柱怎样分工，为什么“能算出来”还不够</summary>

硬件不仅是计算机，还包括传感器、通信和人机接口；软件环境分别支持设计、校准、测试和部署，生产运行与规模化又有专门工具，例如 MLOps 工具。算法则可以先用伪代码表达，再用编程语言实现并部署。写出一个预测程序与证明它在某些条件下可靠，是两项不同的工作。

高斯模型可以说明假设的作用：钟形分布便于推导和计算，但数据若有更重的尾部或由多个不同群体混合而成，原先依赖分布假设的解释和保证就需要重查。**补充说明：** 这不表示任何偏离高斯的数据都会让所有方法完全失效；应区分算法能否计算、哪些结论依赖高斯性，以及偏离假设后的实际表现。

考试成绩被用作钟形分布的直觉例子，但有界成绩不严格服从取值无界的高斯分布。转录中关于人脑可处理“16 个变量”或“5、6 个变量”的数字，也只是帮助说明高维可视化困难的口头表述，不作为认知能力的定量结论。实践中评估自用或采购的方法，都应追问任务、原理、假设、局限，而不是只看演示结果。

</details>

**先看输出和已有标签，再确定问题类型**

在银行例子里，一个客户的资料是输入，历史上“是否按约还款”是标签。监督学习使用这样的输入—标签对，学习预测新客户的结果。标签不是自动包含在输入里的：必须定义它、获取它，并确认它与要解决的任务一致。

<a id="classroom-rules"></a>

**从“人写规则”到“用数据估计规则”**

符号式方法由人显式规定处理规则，再把新输入交给程序；例如，网购反欺诈规则可以检查交易地点、金额及同一张卡前几笔操作是否符合预设的异常模式。这里用的是规则系统这一机制，不据此判断某家支付平台当前使用什么架构。

学习式方法则先提供历史输入和标签，通过训练得到预测规则，再对新客户或新图像使用这个规则。这里所谓“电脑写出了程序”，指的是数据驱动地产生决策函数，不一定指生成一份新的源代码。人仍然决定任务、可用输入、候选函数类型和评价标准。

两类方式可以在一个系统中结合。机器学习规则有时难以解释，并且在远离训练数据的输入上可能给出不可靠预测；学习到了规律，不等于获得了对所有新情境都正确的知识。可解释程度取决于具体模型，不能把所有学习方法都一概视为无法解释。

## 机器学习的目标

### 寻找一个函数

- 例子：通过摄像机视频检测行人。

![image](<Images/01_intro/image_004.jpg>)

- 这样的函数应当在哪个空间中搜索？

<a id="classroom-function"></a>

**一张图像、一个标签与一个决策函数**

视频由连续图像组成。先把自动驾驶场景缩小为一个子任务：输入一张图像，输出“有行人／无行人”。交通灯、其他车辆、自行车等是更完整系统需要处理的其他目标，不能因为解决了这个二分类子任务，就认为已经解决自动驾驶。

一张 RGB 图像含有许多个颜色数值。**补充例子：** 若图像只有 $2\times2$ 个像素、每个像素 3 个通道，那么它可以表示为 $x\in\mathbb R^{12}$。一整张图像是特征空间中的一个点；标签 $y\in\{0,1\}$ 为这个点指定类别。图中的“红点／黑点”表示样本标签，不是原照片里像素的颜色；示意图上的两条坐标轴也不等于照片的宽和高。

学习要得到函数 $h$：给定新的 $x$，返回预测 $h(x)$。在二分类的几何图像里，这相当于把输入空间分成两个判定区域，边界可能是直线、曲线或更高维的曲面。搜索空间 $\mathcal H$ 则规定允许哪些函数成为答案。

所以应依次问：**允许找哪一类函数？在这一类里，怎样比较两个候选函数？** 线性模型、神经网络、随机森林等提供不同的表示方式；线性模型虽有限制，却便于看清通用原理。网络也由所选架构限定候选函数，并非“想表达什么都可以”。语言模型逐步生成文本也可用学习函数的形式理解，但它的输出空间与这里的二分类不同。

## 机器学习的技巧

### 解决“偏差—方差”权衡

- 学习方法给出的解与最优解（函数）之间的距离：近似误差与估计误差之和。

假设类 H

![image](<Images/01_intro/image_005.jpg>)

- 学习一个函数相当于：

(a) 选择一个搜索空间（设计过程）；

(b) 估计这个空间中的最佳函数（训练过程）。

<a id="classroom-three-functions"></a>

**先分清三个函数，再读两种误差**

沿着图中的三个对象读，会比直接记“偏差—方差”更清楚。

| 对象 | 它回答什么问题 | 对训练数据的依赖 |
|---|---|---|
| $h^*$ | 如果知道真实数据规律，在所有允许决策中什么最好？ | 是理论参照，通常未知 |
| $\bar h$ | 限定在当前函数类 $\mathcal H$ 中，真实表现最好的是什么？ | 在分布和函数类固定时是理论参照 |
| $\widehat h$ | 这一次用有限训练集实际学到了什么？ | 换一批训练数据，通常会改变 |

如果只允许直线，而理想边界是弯曲的，那么即使数据很多，最好的直线也可能有局限，这对应**近似误差**。即使最好的直线已经确定，有限样本还可能让我们选到另一条直线，这对应**估计误差**。

增加数据主要帮助我们在给定函数类中辨别好坏；扩大函数类则提供更丰富的候选答案。后者可能降低近似误差，却也给有限样本带来更多选择机会，容易选中“碰巧适合这一批数据”的函数。设计阶段选择表示方式与约束，训练阶段依据数据估计参数；两者不能混成一个步骤。

**补充说明：** 图中随机的估计误差被类比为“方差”，但它不是一般意义下直接计算出的方差；只有特定平方误差设定才有后面的严格偏差—方差恒等式。转录中“候选多，寻找时间长”的比喻也不准确：计算耗时与统计估计误差是不同问题。更多同分布数据有助于学习，是在适当条件下的趋势，不保证每次加一个样本误差都单调下降；扩大函数类也不保证任一算法的估计误差必然增大。

<details>
<summary>补充例子：用三个风险数值读懂图中的两段距离</summary>

假设同一损失下，$L(h^*)=0.08$、$L(\bar h)=0.12$、$L(\widehat h)=0.17$。那么相对理想最优规则的额外风险为 $0.17-0.08=0.09$，其中 $0.17-0.12=0.05$ 是类内估计差距，$0.12-0.08=0.04$ 是当前函数类的近似差距。这里比较的是风险数值，不是画面上三点之间的欧氏距离。

这些数字是整理者的示例，不是课堂实验结果。$h^*$ 也可能属于 $\mathcal H$，此时近似误差可以为零；有噪声时，即使使用 $h^*$，绝对风险也未必为零。

</details>

## 机器学习算法的三个家族

### 1. 局部方法：基于分组和局部投票（或平均）

- k 近邻。
- 核规则。
- 决策树。

<a id="classroom-local"></a>

**局部方法先决定“谁和谁接近”**

局部方法先找到待预测点附近的样本，或把输入落到某个局部区域，再用区域内的标签投票、用数值平均。例如，若最近的 5 个已标注样本中有 4 个属于类别 1，多数投票就给出类别 1；这是整理者用于说明机制的小例子。

关键不只在投票，还在“近”如何定义。特征单位、尺度、距离及划分方式都会改变邻居。决策树通过逐步划分形成区域，也可作为集成方法的基础。转录中“过时”的说法属于口头评价，不能据此判定局部方法普遍无效；树方法及其组合的价值仍取决于具体任务。

*来源：[转录 3](01_part3.md) 第 17–25 行。*

### 2. 全局方法：基于函数优化

- 正则化回归（Ridge、LASSO 等）。
- 支持向量机。
- Boosting。
- 前馈神经网络。

<a id="classroom-global"></a>

**在函数上优化，实际通常是在参数上优化**

若候选函数写成 $h_\theta$，一次参数选择就确定一个候选规则。训练把所有训练样本上的表现汇总为目标，再调整 $\theta$。例如线性模型调整系数，前馈网络调整权重；这种写法把抽象的函数选择变成可实现的数值计算。

这里的“全局”描述用一个整体目标评价候选函数，不保证数值算法能找到全局最优解，也不表示所有学习方法都只有有限维参数。参数维数可以很大，但优化始终是方法的实现环节，不能替代函数类和目标的选择。

*来源：[转录 3](01_part3.md) 第 26–31 行。*

### 3. 集成方法：基于重采样与聚合

- Bagging。
- Boosting。
- 随机森林。

<a id="classroom-ensemble"></a>

**集成是在学习算法之上再加一层组织**

集成方法把一个基础学习过程多次运行，产生多个预测器，再对它们的输出进行投票或平均。改变训练数据、训练多条规则再让它们投票，相当于在基础学习过程上增加一层组织，因此它可以看作元方法：输入不仅是数据，还包含一个已经可用的学习算法。

树经常作为基础模型。在某些规模较小的数据任务上，这种组合可能比复杂网络更合适，而且实施较简单；这是一种需要用具体数据验证的选择，不是所有任务上的性能排序。**补充说明：** 课件把 Boosting 同时列在全局与集成方法中，并不矛盾：一种算法可以既组合多个模型，又对应某个整体优化目标；三个家族不是严格互斥分类。

*来源：[转录 3](01_part3.md) 第 32–43 行。*

<a id="shallow-deep"></a>

- 浅层学习：通常与 Tikhonov 正则化有关。

$$
\min _ {h \in \mathcal {H}} \left(\frac {1}{n} \sum_ {i = 1} ^ {n} \ell (h (X _ {i}), Y _ {i}) + \lambda_ {n} \cdot \mathrm{pen} (h, n)\right)
$$

- 惩罚项控制方差项（奥卡姆剃刀原则）。
- 它也可以使函数具有所希望的结构，例如稀疏性。
- 深度学习：
- 通用逼近器（零偏差）。
- 优化中没有惩罚项，但实现中有许多技巧，它们起到隐式正则化的作用。

> **译注：** 以上是原课件对深度学习的概括。“零偏差”指逼近能力的理想化表述，不保证有限网络、有限样本训练达到零误差；深度学习也可以显式使用惩罚项。

<a id="classroom-regularization"></a>

**惩罚项为什么会改变我们选中的函数**

上面的目标由两部分组成：第一项要求预测贴合训练数据，第二项提高某些复杂或不符合结构要求的函数的代价。参数 $\lambda_n$ 调节这种代价的权重。因此，正则化并不是训练结束后评价一句“模型太复杂”，而是会改变训练时的选择。

以多项式次数为例：常数函数灵活性低，复杂度代价小；二次多项式能弯曲，可能贴合更多变化；高次多项式甚至能穿过所有训练点，但这并不保证新位置上的预测可靠。如果把次数作为惩罚，就要同时衡量训练误差减少多少、复杂度代价增加多少。

惩罚还可以偏好某种结构，例如稀疏系数或与问题约束相容的函数。奥卡姆剃刀在这里表达“拟合相当时偏好简单解释”的建模取向，并不保证简单模型永远正确。在某些统计设定与一致性条件下，数据增多后可以逐渐减弱正则化；这并不要求所有问题的惩罚项都随样本增加而自动趋零。

<details>
<summary>补充例子：训练误差更低，为什么仍可能不被选中</summary>

只为展示目标如何比较，设某个常数模型的经验损失为 0.40、次数为 0；某个二次模型的经验损失为 0.10、次数为 2。取 $\lambda=0.2$ 且用次数作惩罚，则目标分别为 $0.40+0.2\times0=0.40$ 与 $0.10+0.2\times2=0.50$，常数模型被偏好；若改成 $\lambda=0.05$，二次模型的目标为 0.20，它就更有利。这里的损失数值是整理者设定的，不是普遍表现。

“50 个点用 50 次多项式通过所有点”还需要补足条件。精确地说，对于 50 个互异的横坐标，总存在次数至多为 49 的插值多项式；允许更高次数也可插值。若同一个横坐标出现不同标签，则不能用单值函数同时精确通过。插值能力、泛化能力和是否适合用次数惩罚，是三个不同的问题。

</details>

<details>
<summary>课堂延伸：深度学习为什么不能仅靠“没有惩罚项”来理解</summary>

通用逼近能力与良好泛化之间仍有需要解释的距离：表示能力很强的网络为什么没有总是如简单直觉预想的那样失控？具体实现中的训练方式和设计选择也会起到正则化作用，其中未显式写成目标惩罚项的作用通常称为隐式正则化。选择参数、做实验和调节方案需要实践经验，理论解释机制不等于提供了对每个问题都有效的参数配方。

**补充说明：** 通用逼近定理有函数类、定义域、激活与网络容量等前提，不能解释为任意固定网络已经零偏差；深度学习也能使用显式惩罚。转录中的“神经网络通常用最小二乘”和“$x_i$ 减标签”不是一般定义：损失由任务决定，平方误差比较的是预测 $h(x_i)$ 与标签 $y_i$。课件原句及相邻译注均保留，以上解释避免把教学对比读成排他规则。

</details>

## 监督机器学习：学习与信息

<a id="questions-game"></a>

### 像“二十问”游戏一样学习

- 假设自然界从 K 个函数中选取了一个，我们希望找出这个函数。
- 假设存在一个预言机：当我们就这个函数提出问题时，它回答“是”或“否”。
- 为找到这个未知函数，最优的提问次数 n 是多少？

<a id="classroom-twenty-questions"></a>

**用 1 到 100 的猜数游戏理解信息量**

设想要猜一个 1 到 100 的整数，每次提问只能得到“是／否”作为回答。逐个问“是 1 吗、是 2 吗”时，一个“不是”通常只排除一个候选；问“是否大于 50”则可一次排除约一半，随后继续对剩余区间二分。候选数约按 $100\to50\to25\to13\to7\to4\to2\to1$ 缩小，所以最多 7 个适当问题就够。

这里控制效率的是一次回答能区分多少候选，而不只是问题数量。$n$ 个二进制回答最多有 $2^n$ 种不同回答序列；要区分 K 个对象，至少要使 $2^n\ge K$。这是下面出现 $\lceil\log_2 K\rceil$ 的原因。

**补充说明：** 这说的是允许恰当二分问题时的最坏情况保证，不应把转录中的“平均 log 100 次”照搬为任意提问策略的期望值。逐个枚举可在剩最后一个候选时停止，不必再多问；课堂中的 100／1000 等口误也不影响二分思想。

*来源：[转录 3](01_part3.md) 第 203–220 行。*

<a id="finite-questions"></a>

### 穷举学习：有限情形

- 问题：为了从 K 个函数中找到那个函数，需要向预言机提出多少个答案为“是”或“否”的问题？
- 策略：递归地把函数集合分为两组，询问目标函数是否位于第一组，并移除不包含目标函数的那一组。这样大约经过 log K 次提问，就能识别目标函数。
- 答案：提问次数为 $n = \left\lceil { \frac { \log K } { \log 2 } } \right\rceil = \lceil \log _ { 2 } K \rceil$。
- 注意：这个量表示在 K 个函数的集合中确定一个函数所需的信息比特数。

<a id="information-theory"></a>

### Shannon 信息论：log $\boldsymbol { K }$ 的由来

- 对一个包含 K 个函数的集合进行编码所需的比特数，其中各函数出现的概率为 $P ( k )$。

![image](<Images/01_intro/image_007.jpg>)

- 信息论中，分布 $P$ 的熵为：

$$
H (P) = - \sum_ {k = 1} ^ {K} P (k) \log_ {2} P (k) \leq \log_ {2} K
$$

<a id="classroom-entropy"></a>

**固定长度编码与熵分别在量什么**

若有 8 个候选对象，可以给它们分配 000 到 111 共 8 个三位编码。这样，“确定一个对象需要几次二元回答”和“给一个对象编号需要多少比特”就联系起来了。对 K 个对象的固定长度编码，所需位数是 $\lceil\log_2 K\rceil$。

当对象出现概率不同，有些结果比其他结果更常见，熵就把不同结果的信息量按概率平均。均匀分布时最难预先猜中，熵达到 $\log_2 K$；分布越集中，平均不确定性可以越低。

<details>
<summary>补充推算：8 个等可能对象的熵</summary>

对每个对象，$P(k)=1/8$，所以单个结果的信息量为 $-\log_2(1/8)=3$ 比特，平均仍为 $H(P)=-8\times(1/8)\log_2(1/8)=3$ 比特。

## 从提问到数据

a. 零误差情形下的穷举搜索。

b. 零误差情形下的 PAC 学习。

c. 一般情形下的 PAC 学习。

PAC = Probably Approximately Correct，即“以高概率近似正确”。

L. Valiant（1984）. A theory of the learnable（可学习性理论）. Communications of the ACM.

<a id="classroom-pac-meaning"></a>

**一个带标签的样本，相当于回答了什么问题**

在图像分类中，$x_i$ 是给候选函数的输入，$y_i$ 是这个输入的已知正确标签。若某个候选函数预测 $f(x_i)\ne y_i$，在无噪声、目标确实属于候选类的设定下，就可以把它排除。于是，猜数中的“候选数字”对应候选函数，问题及答案对应带标签的样本。

但真实学习通常不要求精确识别唯一目标：两个函数可能只在极少出现的输入上不同，而含噪数据甚至不允许任何函数总是正确。PAC 因而把目标分成两层：允许所选规则的真实误差略大，同时要求选出这种好规则的成功概率足够高。这就是“近似正确”和“以高概率”分别修饰什么。

标签翻转是一种直观的噪声例子：原本有人行人的图像被标成无行人。它说明“所有样本必须与某个完美函数一致”的设定可能不成立，而不是说噪声只能来自人为篡改。PAC 的历史意义在于把“什么能够被学到”变成可以讨论的形式化问题；原课件给出的 Valiant 文献保留，课堂对页数或引用排名的随口描述不作为知识点。

<a id="zero-error"></a>

### a. 零误差情形（1/2）

- 记号：定义域空间 X，标签空间 $\mathcal { Y } = \{ 0 , 1 \}$。
- 零误差设定：考虑有限个指示函数

$$
f _ {k}: \mathcal {X} \to \{0, 1 \}, \quad k = 1, \dots , K
$$

以及一组数据点 $\left( x _ { i } , y _ { i } \right)$，使得总存在某个 k，对任意索引 i 都满足 $y _ { i } = f _ { k } ( x _ { i } )$。

- 最坏情形：数据点集合 $x _ { i } \in { \mathcal { X } }$ 使向量集合 $\{ ( f _ { 1 } ( x _ { i } ) , \ldots , f _ { K } ( x _ { i } ) ) : i \geq 1 \}$ 的基数达到最大值，等于 $2 ^ { K }$。
- 问题：需要多少个样本 $( x _ { i } , y _ { i } ) \in \mathcal { X } \times \{ 0 , 1 \}$，才能从 K 个可能的指示函数 $f _ { k } : \mathcal { X } \to \{ 0 , 1 \} , k = 1 , \ldots , K \ ?$ 中找到未知的那个？
- 答案相同：样本数为 $n = \left\lceil { \frac { \log K } { \log 2 } } \right\rceil$。

策略：找到一个向量 $x _ { i }$，使一半函数在该点取值 1，另一半取值 0；询问预言机目标函数在这个向量上取值 1 还是 0，并排除取相反值的函数。将这一过程执行 n 次。

> **译注：** 此处使用可主动选择查询点、实现候选函数近似均分的理想设定，不是任意随机样本都能以这个数量识别目标函数。

<a id="classroom-query-limit"></a>

**为什么猜数能二分，任意数据未必能**

要按上面的策略淘汰一半函数，必须找到一个输入 x，使当前候选里约一半预测 0、另一半预测 1，再获得真实标签。数字区间总能挑出合适的中点，但任意函数集合未必提供这种可查询的 x，而且寻找它本身也可能很难。

**补充例子：** 若两个候选函数在所有已采集的图像上都预测相同，它们无论各预测了多少遍，都还没有被这些数据区分开；需要出现使二者预测不同的输入，才可能借标签判断。这解释了为什么样本数量与样本的信息价值不是同一件事。

转录第 275 行的中文“需要 $2^n$ 个样本”不符合相邻法文和课件公式；这里需要的是约 $\log_2 K$ 次理想查询，$2^n$ 是 n 个二元回答最多能区分的候选数。另外，分类标签空间是集合 $\{0,1\}$，不是包含任意实数的区间 $[0,1]$。

*来源：[转录 3](01_part3.md) 第 263–281 行。*

<a id="pac-zero"></a>

### b. 零误差情形下的 PAC

- 备注：要找到一个 $x _ { j }$，使每个候选函数子集都被平分成两部分，可能很困难。
- 采样：假设 $X _ { 1 } , \ldots , X _ { n }$ 是独立同分布样本。
- 问题：在零误差设定下，需要多少个样本 $( X _ { i } , Y _ { i } )$，才能从有限个指示函数 $f : \mathcal { X }  \{ 0 , 1 \}$ 中，以概率 $1 - \delta ?$ 找到一个错误概率与零相差不超过 ε 的函数？
- 答案：样本数为

$$
n = \left\lceil \frac {\log K + \log (1 / \delta)}{\varepsilon} \right\rceil
$$

（证明留作练习。）

<a id="classroom-epsilon-delta"></a>

**ε 管规则的误差，δ 管训练抽样失败的概率**

把训练想成可以重复做的实验：每次重新抽取 n 个样本、重新训练，得到的规则可能不同。

- $\varepsilon$ 控制一次成功训练所得规则的真实误差上限；在一般情形中，通常控制相对某个最优参照的额外风险。
- $\delta$ 控制抽到不利训练集、使保证失败的概率。外层成功概率至少是 $1-\delta$。

**补充例子：** 在可实现设定下，$\varepsilon=0.05$、$\delta=0.01$ 的含义是：以至少 99% 的训练抽样概率，所选分类器在目标分布上的错误率不超过 5%。它不表示每个输入都以 99% 概率被正确分类，也不表示每批训练样本恰好错 5%。

<details>
<summary>补充推导：为什么可实现情形出现 1/ε</summary>

对一个真实错误率大于 $\varepsilon$ 的固定候选函数，在 n 个独立同分布训练样本上碰巧一次也不出错的概率，不超过 $(1-\varepsilon)^n\le e^{-n\varepsilon}$。K 个候选中，只要存在一个这样的坏函数却与全部训练标签相容，学习就有选错的可能；并集界把该概率上界为 $K e^{-n\varepsilon}$。

令这个上界不超过 $\delta$，得到

$$
n\ge\frac{\log K+\log(1/\delta)}{\varepsilon}.
$$

这补全了原课件留作练习的证明思路。这里使用有限、预先固定的候选类、独立同分布样本、真实目标可实现，以及选择训练上零误差函数等条件；不是从任意随机数据都能精确恢复目标的证明。

</details>

*来源：[转录 3](01_part3.md) 第 278–287 行；[转录 3](01_part3.md) 第 335–362 行。*

<a id="pac-general"></a>

- 假设：K 个函数中，没有任何一个在样本 $\{ ( X _ { i } , Y _ { i } ) : i \geq 1 \}$ 上达到零误差。
- 问题与前面相同。
- 答案：平均而言，样本数为

$$
n = \left\lceil \frac {\log K + \log (1 / \delta)}{2 \varepsilon^ {2}} \right\rceil
$$

对 K 的依赖关系相同，变化仅在常数上。

> **译注：** 原页写作“平均而言”，但 PAC 保证通常以概率至少 $1-\delta$ 陈述。一般情形比较的是候选类中最优风险与所学风险，不应理解为含噪时仍能把真实错误率压到零。原页样本量公式照录；使用 Hoeffding 界推导 ERM 超额风险时，需要检查单侧／双侧偏差及由两次偏差引入的常数。

<a id="classroom-sample-scaling"></a>

**怎样读样本量界，而不误读成万能配方**

在有限函数类里，候选数增加的代价通过 $\log K$ 出现；要求更小误差或更高置信度，则需要更多数据。一般有噪声情形中，典型有限类界对精度的依赖从 $1/\varepsilon$ 变为 $1/\varepsilon^2$，但精确常数取决于界控制的是单侧偏差、双侧偏差还是 ERM 的超额风险，不能只凭口头公式互换。

$\varepsilon$ 和 $\delta$ 并非理论上不能同时变小：在这些条件下，可以通过增加样本量让两者都变小；困难是在**固定样本预算**下同时提高精度和置信度。$\delta\to0$ 时，$\log(1/\delta)\to+\infty$；这表示该类充分样本界在置信度趋于 1 时增大，并不是所有特殊问题都不可能在有限样本下得到确定保证。

实验招募和观测患者都需要成本，因此“需要多少患者”也是数据采集中的现实问题。这里的学习界用于理解样本量与任务难度的关系，不应直接当作临床研究样本量公式；实际规划还取决于研究设计、效应及其他假设。对无限函数类，不能直接把 $K=\infty$ 代入计数界，需要用适当的复杂度刻画代替简单计数。

## 一般情形的 PAC 界：证明概要

- Hoeffding 不等式：
- 设 $Z _ { 1 } , \ldots , Z _ { n }$ 是取值于 [0,1] 的独立同分布随机变量，且 $\overline { { Z } } _ { n } = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } Z _ { i }$。
- 对任意 $t > 0$，有：

$$
\mathbb {P} \{\overline {{Z}} _ {n} - \mathbb {E} (Z _ {1}) > \varepsilon \} \leq \exp (- 2 n \varepsilon^ {2})
$$

- 并集界：对任意两个可测集合 A、B，有：

$$
\mathbb {P} \{A \cup B \} \leq \mathbb {P} \{A \} + \mathbb {P} \{B \}
$$

<a id="classroom-probability-proof"></a>

**先控制一个函数，再控制所有候选**

对固定函数，训练误差是样本损失的平均值，真实风险是其期望。Hoeffding 不等式控制二者偏离较大的概率；并集界则把“一个候选可能偏离”扩展到“所有候选中有没有任何一个偏离”。只有同时控制所有候选，才能在看过数据、选出函数之后继续使用这个保证。

<details>
<summary>补充推导：把双侧一致偏差换成 ERM 的风险保证</summary>

设每个损失都在 $[0,1]$ 中，样本独立同分布，候选类预先固定且大小为 K。对所有候选同时控制双侧偏差，可得

$$
\mathbb P\left(\sup_{h\in\mathcal H}|\widehat L_n(h)-L(h)|>t\right)\le 2K e^{-2nt^2}.
$$

若这项一致偏差不超过 t，且 $\widehat h$ 确实最小化经验风险，那么先从真实风险走到经验风险，利用经验最优性，再走回真实风险，得到

$$
L(\widehat h)\le\widehat L_n(\widehat h)+t
\le\widehat L_n(\bar h)+t
\le L(\bar h)+2t.
$$

因此要使类内超额风险不超过 $\varepsilon$，可以取 $t=\varepsilon/2$，得到一个充分条件 $n\ge 2\log(2K/\delta)/\varepsilon^2$。这是整理者补充的一个标准推导形式，用来解释原译注为何提醒检查常数，并未替换原课件公式。若优化只达到近似最优，还需要加入优化误差；无界平方损失也不能不加条件就套用上述有界损失版本。

</details>

<a id="classroom-sampling"></a>

**概率来自重复采样，主动学习则改变采样方式**

眼前的数据文件已经固定，但它并不是世界上唯一可能产生的数据集。以考试成绩为例：准备程度、既有知识以外，睡眠、健康、题目表达等未记录因素也会让结果变化。概率模型描述的是在同一机制下可能得到不同观测，而不是否认眼前记录的数值已经确定。

一次训练集可能恰好不具代表性，即使算法认真训练，也会在其他数据上表现不佳。这是 PAC 要容许一个抽样失败概率的原因。只问针对大于 70 的候选的问题，就无法有效区分更小的候选，这说明查询可能没有提供需要的信息；转录里出现了超出 0—100 范围的“344”，不沿用这个矛盾数字。

**主动学习**进一步问：如果能选择哪些样本值得标注，能不能更有效地使用预算？这与接收一个已给定训练集的被动设定不同；选择查询有机会提高效率，但收益仍依赖数据、可查询范围和学习目标。

<details>
<summary>课堂应用：昂贵仿真、代理模型与序贯学习</summary>

如果物理仿真运行很慢，无法在每次需要快速预测时完整执行，可以先运行部分输入设置，收集输入—输出对，再训练一个较便宜的代理模型。既然实验或仿真的输入由我们决定，就可以优先查询能减少不确定性的参数位置，而不是盲目堆积同样价值不高的样本。主动查询仍需注意代理模型覆盖范围，以及仿真与实际目标的差别。

另一种序贯学习设定是：不假设样本来自固定概率分布，而是允许一个“对手”选择数据，让预测尽可能困难，从而研究在这种条件下仍可靠的策略。**补充说明：** 序贯或在线学习并不都等于对抗学习；课堂这里举的是其中一种建模框架。它与主动选择查询、独立同分布随机抽样的假设不同，不能混用保证。

</details>

## 监督机器学习：机器学习中的偏差—方差分解

<a id="hypothesis-space"></a>

### 一般设定与记号

- 学习目标：最优决策函数 $h ^ { * } : \mathcal { X } \to \mathcal { Y }$。$\mathcal { X }$ 是定义域集合，Y 是标签集合。
- 学习的输入：
- 训练数据：一组带标签的数据

$$
D _ {n} = \{(X _ {1}, Y _ {1}), \dots , (X _ {n}, Y _ {n}) \}
$$

其大小为 n，其中各 $( X , Y ) ^ { \prime }$ 属于 $\mathcal { X } \times \mathcal { V }$。

- 假设空间：候选决策函数 $h : \mathcal { X }  \mathcal { Y }$ 的集合 $\mathcal { H }$。
- 学习的输出：利用训练数据 $D _ { n }$ 估计得到、位于假设空间 $\mathcal { H }$ 中的经验决策函数 $\widehat { h }$。
- $\mathcal { H }$ 中的参照：该类中的最佳决策函数 $\bar { h }$（数据越多，$\widehat { h }$ 越接近 $\hat { h } )$）。

<a id="classroom-notation"></a>

**符号中的“帽子”“横线”和“星号”各自提醒什么**

$D_n$ 是这次用于训练的样本集合；$\mathcal H$ 是候选函数的集合；$h$ 是集合中的一个候选。也可以用 f 表示同类对象，字母变化不代表问题变了。分类标签可以是 0／1，回归标签可以是实数，而输入 $x_i$ 仍可以是高维向量。

$\widehat h$ 的“帽子”提醒我们：它是从数据估计出来的，换训练集就可能改变。$\bar h$ 的“横线”在这里表示当前函数类中真实风险最优的参照，**不是**对 $\widehat h$ 取平均；$h^*$ 的“星号”表示不受当前候选类限制的理想最优规则。把 $\bar h$ 理解为“无限数据下能达到的函数”时，必须注意它是理想参照；实际学习算法是否达到它还需要一致性和优化方面的条件。

**补充说明：** 上面译文中“$\widehat h$ 越接近 $\hat h$”重复了同一对象，按课堂解释与该行上下文应为趋近 $\bar h$；这里标出辨析，保留原译句以便核对。$h^*$ 也并非必须在 $\mathcal H$ 之外；若它属于该类，两个理想参照可以一致。

$$

## 所有学生都（应该）知道的内容：统计推断中的偏差—方差权衡

<a id="parametric-estimation"></a>

### 参数估计的情形

$\Theta$ 是参数集合，是 $\mathbb { R } ^ { p }$ 的子集。

$P _ { \theta }$（其中 $\theta \in \Theta$）构成一个参数化分布族。

对某个 $\theta ^ { \ast } \in \Theta$，$P _ { \theta ^ { * } }$ 是数据的真实分布（假设）。

$\widehat { \theta } _ { n }$ 是基于大小为 n 的样本对 $\theta ^ { * }$ 作出的估计量。

- 均方误差分解：

$$
\begin{array}{r l} & {\mathbb {E} \left(\| \widehat {\theta} _ {n} - \theta^ {*} \| ^ {2}\right) =} \\ & {\qquad \mathbb {E} \left(\left((\widehat {\theta} _ {n} - \mathbb {E} (\widehat {\theta} _ {n})) (\widehat {\theta} _ {n} - \mathbb {E} (\widehat {\theta} _ {n})) ^ {T}\right)\right) + \| \mathbb {E} (\widehat {\theta} _ {n}) - \theta^ {*} \| ^ {2}} \end{array}
$$

**练习：计算回归中 OLS 与 Ridge 回归的均方误差（MSE）。**

> **译注：** 原式右侧第一项是协方差矩阵，左侧是标量；向量参数的正确恒等式为 $\mathbb E\|\widehat\theta_n-\theta^*\|^2=\operatorname{tr}\operatorname{Cov}(\widehat\theta_n)+\|\mathbb E\widehat\theta_n-\theta^*\|^2$。上式按原页保留。

<a id="classroom-parameter-mse"></a>

**为什么要对“重新抽样得到的估计量”取平均**

若用一个高斯分布族描述观测，均值和方差决定族中具体是哪一个分布。真实参数 $\theta^*$ 未知，从 n 个样本算出的 $\widehat\theta_n$ 是它的估计。这里的期望不是“对一张已经固定的数据表再平均一次”，而是想象反复抽取大小为 n 的数据集，每次都重新计算估计量，再观察这些估计结果的平均表现。

偏差比较“这些估计的平均值”和真实参数；方差描述各次估计围绕其平均值的波动。某个方法平均位置很准，却每次都大幅波动，仍可能有较大均方误差；另一个方法略有系统偏移，却更稳定，均方误差反而可能更小。这也解释了为什么允许适度偏差的正则化值得考虑。

<details>
<summary>课堂推导展开：交叉项为什么为零</summary>

先考虑标量参数，记 $\mu=\mathbb E[\widehat\theta_n]$。加上再减去同一个数 $\mu$：

$$
\widehat\theta_n-\theta^*=(\widehat\theta_n-\mu)+(\mu-\theta^*).
$$

平方后取期望，用 $(a+b)^2=a^2+b^2+2ab$，得到

$$
\mathbb E[(\widehat\theta_n-\theta^*)^2]
=\mathbb E[(\widehat\theta_n-\mu)^2]
+(\mu-\theta^*)^2
+2(\mu-\theta^*)\mathbb E[\widehat\theta_n-\mu].
$$

最后一项等于零，因为 $\mu-\theta^*$ 是固定数，而 $\mathbb E[\widehat\theta_n-\mu]=0$。剩下的就是方差加平方偏差。这里要求相关二阶矩存在。

对向量使用平方欧氏范数时，各坐标方差相加得到 $\operatorname{tr}\operatorname{Cov}(\widehat\theta_n)$，不能直接拿协方差矩阵与标量均方误差相等；这正是原式旁译注指出的问题。课堂的成绩分布仍只是参数化分布的直觉例子，不是断言有界成绩严格服从高斯分布。

</details>

### 机器学习中预测误差的情形

- 观测：标量 Y，以及 d 维协变量向量 X。
- 回归模型：$Y = h ^ { \ast } ( X ) + \varepsilon$。
- 随机噪声：ε 与 X 独立。
- 基于样本的预测器 $\widehat { h } _ { n }$。
- 在固定点 $\left( x , y \right)$ 处的均方误差：

$$
\mathbb {E} _ {n} \left((y - \widehat {h} _ {n} (x)) ^ {2}\right) = \left(\mathbb {E} _ {n} (\widehat {h} _ {n} (x)) - h ^ {*} (x)\right) ^ {2} + \mathbb {V} _ {n} \left(\widehat {h} _ {n} (x)\right) + \varepsilon^ {2}
$$

> **译注：** 固定 $y$ 时，上式通常不成立。对独立新观测 $Y=h^*(x)+\varepsilon$，若噪声条件均值为零、条件方差为 $\sigma^2$，再对新噪声与训练样本取期望，得到 $\mathbb E[(Y-\widehat h_n(x))^2\mid X=x]=(\mathbb E_n\widehat h_n(x)-h^*(x))^2+\operatorname{Var}_n(\widehat h_n(x))+\sigma^2$。

（$( \mathbb { E } _ { n } , \mathbb { V } _ { n }$：相对于训练样本计算的期望和方差。）

均方误差 = 平方偏差项 + 预测值的方差 + Bayes 误差。

<a id="classroom-prediction-noise"></a>

**预测误差为什么比参数误差多一项噪声**

估计参数时，我们比较估计值与固定的真实参数；预测新观测时，即使已知理想回归函数，新观测本身仍可能波动。模型 $Y=h^*(X)+\varepsilon$ 中，$h^*(X)$ 描述可由当前输入解释的部分，$\varepsilon$ 表示模型中剩余的随机变化。

**补充说明：** 在平方损失、噪声条件均值为零，并且训练数据与待预测的新噪声独立等条件下，预测误差可以分成平方偏差、训练抽样造成的预测方差，以及新观测的噪声方差。这个噪声项不会仅靠把同一问题的参数估计得更精确就消失。“不可约”是相对于当前输入信息和建模设定而言，不意味着增加有效观测信息也永远无用。

三份转录末尾只预告将把该分解具体应用到回归与线性模型；下方详细矩阵公式来自原课件，不能把它们都说成三份转录里已经完整推导过的课堂内容。

### 线性模型的情形

- 真实模型：$h ^ { \ast } ( x ) = x ^ { T } \theta ^ { \ast }$，其中 $\theta ^ { * } \in \mathbb { R } ^ { d }$。
- 线性模型：$h ( x ) = x ^ { T } \theta$，其中 $\boldsymbol { \theta } \in \mathbb { R } ^ { d }$。
- 矩阵／向量记号：$\mathsf { X } \in \mathbb { R } ^ { n \times d } , \mathsf { Y } \in \mathbb { R } ^ { d } , \varepsilon \in \mathbb { R } ^ { n }$。

> **译注：** 原页把 $\mathbf Y$ 写为 $\mathbb R^d$ 中的向量；与 $\mathbf X\in\mathbb R^{n\times d}$ 一致的响应向量应属于 $\mathbb R^n$。

- 假设：X 满秩。
- 最大似然估计：$\widehat { \theta } _ { n } ^ { \mathrm { M L E } } = ( \mathsf { X } ^ { T } \mathsf { X } ) ^ { - 1 } \mathsf { X } ^ { T } \mathsf { Y }$。
- 代入式预测器：$\widehat { h } _ { n } ( x ) = x ^ { T } \widehat { \theta } _ { n } ^ { \mathrm { M L E } }$。
- 计算：对固定的 (x,y)。
- 偏差项：$x ^ { T } \mathbb { E } _ { n } ( \widehat { \theta } _ { n } ^ { \mathrm { M L E } } - \theta ^ { * } ) = 0$。
- 方差项：$\mathbb { E } _ { n } \left( ( x ^ { T } ( \mathsf { X } ^ { T } \mathsf { X } ) ^ { - 1 } \mathsf { X } ^ { T } \varepsilon ) ^ { 2 } \right)$。

理论结论：根据 Gauss–Markov 定理，最大似然估计是方差最小的无偏估计量……但未必是均方误差最小的估计量。

> **译注：** Gauss–Markov 定理的最小方差结论限定在线性无偏估计量中；最小二乘与最大似然的对应还需要高斯误差等条件。

<a id="variance-computation"></a>

- 假设：$\varepsilon \sim \mathcal { N } _ { n } ( 0 , \sigma ^ { 2 } I _ { n } )$，即 n 维多元高斯分布。
- 方差项：对任意 x，

$$
\begin{array}{r l} \mathbb {E} _ {y | x} \mathbb {V} _ {n} (x ^ {T} \widehat {\theta} _ {n}) & = \mathbb {E} _ {y | x} \mathbb {E} _ {n} ((x ^ {T} (\mathsf {X} ^ {T} \mathsf {X}) ^ {- 1} \mathsf {X} ^ {T} \boldsymbol {\varepsilon}) ^ {2}) \\ & = x ^ {T} \mathbb {E} _ {n} ((\mathsf {X} ^ {T} \mathsf {X}) ^ {- 1} \mathsf {X} ^ {T} \mathbb {E} _ {y | x} (\boldsymbol {\varepsilon} \boldsymbol {\varepsilon} ^ {T}) \mathsf {X} ((\mathsf {X} ^ {T} \mathsf {X}) ^ {- 1}) ^ {T} x) \\ & = \sigma^ {2} x ^ {T} \mathbb {E} _ {n} ((\mathsf {X} ^ {T} \mathsf {X}) ^ {- 1}) x \end{array}
$$

- 假设：随机设计 $x , x _ { i } \sim \mathcal { N } ( 0 , 1 )$，独立同分布。

$$
\mathbb E_x\mathbb E_{y\mid x}\mathbb V_n(x^T\widehat\theta_n)=\sigma^2\frac dn.
$$

> **译注：** 原页此处把不同预测风险混在一起。固定设计的训练点均值预测风险中，方差项为 $\sigma^2d/n$；若训练行与独立新输入均服从 $\mathcal N_d(0,I_d)$、不另加截距且 $n>d+1$，新输入上的 OLS 方差期望为 $\sigma^2d/(n-d-1)$。

一般论证依赖 Cochran 定理（高斯情形）。

<a id="projection"></a>

### $d / n$ 项的解释

高斯随机向量投影的范数性质：

- 假设 $\textsf { Z }$ 是 $\mathbb { R } ^ { n }$ 中服从 $ { \mathcal { N } } _ { n } ( 0 , I _ { n } )$ 的高斯随机向量，$\mathcal { H }$ 是 $\mathbb { R } ^ { n }$ 的线性子空间，$\Pi : \mathbb { R } ^ { n }  \mathbb { R } ^ { n }$ 是到 $\mathcal { H }$ 的线性投影。
- 则随机向量 $\Pi _ { \mathcal { H } } Z$ 在 $\mathbb { R } ^ { n }$ 上服从高斯分布 $\mathcal { N } _ { n } ( 0 , \Pi )$（高斯随机向量的线性变换仍为高斯随机向量）。
- 此外，$\| \Pi Z \| ^ { 2 }$ 服从卡方分布，并且

$$
\mathbb {E} (\| \Pi Z \| ^ {2}) = \dim (\mathcal {H})
$$

> **译注：** 这组分布与期望结论要求正交投影，不能仅假设任意线性投影。

## 监督机器学习：经验风险最小化（ERM）

- 损失函数：$\ell : \mathcal { V } \times \mathcal { V }  [ 0 , + \infty ]$。
- 决策规则 h 的经验风险：这是一个依赖于数据的泛函。

$$
\widehat {L} _ {n} (h) = \frac {1}{n} \sum_ {i = 1} ^ {n} \ell (h (X _ {i}), Y _ {i})
$$

- ERM = Empirical Risk Minimization，即经验风险最小化。

从训练数据中学习，相当于求解下面的优化问题：

$$
\widehat {h} _ {n} = \underset {h \in \mathcal {H}} {\arg \min} \widehat {L} _ {n} (h)
$$

其中最小化限制在假设空间之内。

<a id="classroom-erm"></a>

**从每次预测付出的代价，到选出一条规则**

0/1 损失可以理解为：预测正确付 0，预测错误付 1。对同一个候选规则，把训练集上这些代价加起来再除以 n，就得到经验风险。若 10 个样本中错 2 个，经验风险为 $2/10=0.2$；这是整理者补充的算例。

注意优化变量是规则 h，而不是某一个样本的标签。训练在 $\mathcal H$ 中比较候选规则各自的平均损失，选择经验风险最小者。原公式只写拟合项；若加上前面介绍的惩罚，比较的就变成拟合误差与复杂度代价之和。

这个结果首先说明它适合当前训练集，并未证明它在未见数据上最好。函数类、正则化以及独立评价共同处理这个差距。若两个候选的训练损失相同，还需要明确如何选择；若数值优化没达到最小值，也不能不加说明就把输出等同于精确 ERM。

## 真实误差的概念

- 假设：

$( X , Y )$ 是一对联合分布为 P 的随机变量。

- 决策规则 h 的真实误差：这是一个依赖于分布的泛函。

$$
L (h) = \mathbb {E} (\ell (h (X), Y)) = \int \ell (h (x), y) d P (x, y)
$$

<a id="classroom-population-risk"></a>

**经验平均与真实期望的区别**

经验风险平均的是已收集的 n 个样本；真实风险平均的是目标分布可能产生的所有输入—标签对，并按它们出现的概率加权。前者能直接算，后者通常未知，因而要用独立评价数据或理论界研究它。

“真实”不是说训练记录不真实，而是说评价对象从这一份有限数据扩展到数据产生机制。若部署环境的分布改变了，风险所依据的 P 也变了，昨天的低风险不自动保证明天的低风险。这与前面[上线后的监控](#classroom-pipeline)是同一个问题的数学表达。

## 任务／问题示例

- 二分类问题：Y 取 0、1 两个值。

$$
\ell (y, y ^ {\prime}) = \mathbb {I} \{y \neq y ^ {\prime} \} \quad \text{且} \quad L (h) = \mathbb {P} \left\{h (X) \neq Y \right\}
$$

- 回归：Y 在实数集 R 中取值。

$$
\ell (y, y ^ {\prime}) = \left(y - y ^ {\prime}\right) ^ {2} \quad \text{且} \quad L (h) = \mathbb {E} \big ((Y - h (X)) ^ {2} \big)
$$

<a id="classroom-loss-cost"></a>

**两种错误代价不同时，最小化错误次数可能选错目标**

在行人检测的代价模型中，可以设定：漏检付 2 欧元，误报付 0.5 欧元，正确判断付 0。金额只是用于说明目标的假设数值。此时损失不再是“错一次都记 1”，而要区分实际标签与预测的组合。

| 真实情况 | 模型预测 | 示例损失 |
|---|---|---:|
| 有行人 | 有行人 | 0 |
| 有行人 | 无行人 | 2 |
| 无行人 | 有行人 | 0.5 |
| 无行人 | 无行人 | 0 |

**补充例子：** 在同一批 100 个样本上，模型 A 漏检 1 次、误报 4 次，共错 5 次，总代价为 $1\times2+4\times0.5=4$；模型 B 漏检 3 次、误报 1 次，共错 4 次，总代价为 $3\times2+1\times0.5=6.5$。B 的错误次数更少，但按上述损失，A 更合适。平均损失分别为 0.04 和 0.065。

所以，定义损失不是公式推导之前的随意准备步骤，而是在明确“什么叫表现更好”。下方 Bayes 规则的最优性也必须相对于指定的损失和分布理解，换损失可能就换了最优决策。

## 最优解、一致性与界

- Bayes 规则 $h ^ { * }$ 和 Bayes 误差 $L ^ { * }$。

$$
h ^ {*} = \underset {h} {\arg \min} L (h) \quad \text{且} \quad L ^ {*} = L (h ^ {*})
$$

- 推断原则 $\widehat { h } _ { n }$ 的（强）一致性。

$$
L (\widehat {h} _ {n}) \to L ^ {*}
$$

几乎必然成立。

- 非渐近界的“黄金国”：

$$
L (\widehat {h} _ {n}) - L ^ {*} \leq U (n, \mathcal {H}) \quad \text{以高概率}
$$

在以下两种情形中，求出最优解 $h ^ { * }$ 和 $L ^ { * }$：

- 二分类问题：Y 取 0、1 两个值。

\ell (y, y ^ {\prime}) = \mathbb {I} \{y \neq y ^ {\prime} \} \quad \text{且} \quad L (h) = \mathbb {P} \left\{h (X) \neq Y \right\}
$$

## 估计误差与近似误差：偏差—方差分解的推广

- 证明思路：加上再减去 $\widehat { L } ( \widehat { h } _ { n } ) \ , \ \widehat { L } ( \overline { { h } } ) , \ L ( \overline { { h } } )$，然后利用 ERM 的定义对总和取上界。$L$ 与 $\widehat { L }$ 的差会出现两次。
- 有：

$$
L (\widehat {h} _ {n}) - L ^ {*} \leq \underbrace {2 \sup _ {h \in \mathcal {H}} | L (h) - \widehat {L} _ {n} (h) |} _ {\text{估计误差（随机）}} + \underbrace {L (\overline {{h}}) - L ^ {*}} _ {\text{近似误差（确定性）}}
$$

<a id="finite-class-bound"></a>

- 假设决策函数的假设类 $\mathcal { H }$ 是有限的，并且 $h ^ { \ast } \notin \mathcal { H }$。
- 则对任意 $\delta ,$，以至少 $1 - \delta$ 的概率，有：

$$
\forall h \in \mathcal {H}, L (h) \leq \widehat {L} _ {n} (h) + \sqrt {\frac {\log | \mathcal {H} | + \log \left(\frac {1}{\delta}\right)}{2 n}}
$$

- log $| \mathcal { H } | = \log K $：看，这正是导论中的结论！

<a id="section-23"></a>

## 有限假设类：证明概要

- Hoeffding 不等式：
- 设 $Z _ { 1 } , \ldots , Z _ { n }$ 是取值于 [0,1] 的独立同分布随机变量，且 $\overline { { Z } } _ { n } = \frac { 1 } { n } \sum _ { i = 1 } ^ { n } Z _ { i }$。
- 对任意 $t > 0$，有：

$$
\mathbb {P} \{\overline {{Z}} _ {n} - \mathbb {E} (Z _ {1}) > \varepsilon \} \leq \exp (- 2 n \varepsilon^ {2})
$$

- 并集界：对任意两个可测集合 A、B，有：

$$
\mathbb {P} \{A \cup B \} \leq \mathbb {P} \{A \} + \mathbb {P} \{B \}
$$
