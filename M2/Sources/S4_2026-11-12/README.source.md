## 文件组织

- Cours：课程讲义或课程页面。
- TD_TP：练习、实验包及代码。CoA 的网页归档放在这里；代码包同时保留了解包版本。
- Projets：项目题目、阅读论文和项目要求。
- Examens：考试资料；需先看说明中的题面年份。
- Archives：往年参考资料；PPCS 这里保存的是完整仓库 TAR 快照，不能只凭文件夹名称判断年份。
- PPCS/Ressources_depot：14 个仓库的完整解包内容，讲义与配套代码按原仓库结构保留。

## 阅读提示

1. 每门课先读 ASSESSMENT.md，再看 RESOURCES.md。
2. 网页归档 .webarchive 可用 Safari 打开；网页中的在线教学视频没有离线下载。
3. 原始代码和实验包只进行了保存和解包，没有安装或运行。
4. 教师通知、转发通知、同学讨论和题面证据在考核说明中分别注明。
5. 这是已检索并成功保存的资料档案，不代表学校全部资料或最新正式考试细则。失效链接和未保存项目明确列于 MISSING.md。
