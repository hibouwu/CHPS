## 来源与完整性

- [原总说明](README.source.md)、[原缺失与待确认事项](MISSING.md)、[原文件清单](MANIFEST.csv)、[原网页快照](README.webarchive)按原字节保存。
- [本次归档映射与 SHA-256](IMPORT_MANIFEST.csv)逐一记录压缩包成员、实际保存位置、字节数及与既有文件的重复关系；[校验报告](IMPORT_REPORT.json)记录原压缩包 SHA-256 和核对结果。
- 445 个资料文件全部保存，跳过 544 个 macOS 元数据文件。20 个文件与既有资料字节相同，为保留这批材料的独立结构仍保留副本；没有覆盖既有文件。原清单中的 426 项均已核对 SHA-256；其中 RGPD 注释版 PDF 在 ZIP 中的名称乱码，归档副本已更正为 `RGPD-annoté.pdf`，原路径保留在映射清单中。
- 每门课的 `S4/` 保留原来的 Cours、TD_TP、Archives 等结构。PPCS 的 14 个仓库快照及解包源码、CoA 的 Lab 代码和 ISM 的实验数据均随包保存。
- PPCS 示例中的 4 个 SSH 私钥及含有这些私钥的 4 个 TAR 原包仅在本地保存，权限设为 600，并已加入仓库 `.gitignore`。这些路径记录在导入报告中；分享仓库时不会包含这些文件。

## 使用与缺口

先从各课程资源索引查找讲义、练习和考试。CoA 的 `.webarchive` 是原网页快照，本仓库另有可直接阅读的 [HTML、Markdown 和 PDF](../../COA/Course/README.md)。

考核说明、失效链接与缺失记录均来自原包，本次只做本地归档和校验，没有重新核实在线通知；其中的往届日期、比例和资料限制不能直接当作 2026–2027 规定。原包已记录 AOC 附件、ISM 过期 TP 链接、CoA 后续理论网页及视频的缺口。
