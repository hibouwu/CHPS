# APM 期中笔试复习资料

按课堂照片中 **2026 年 10 月 22 日上午 DST** 的安排整理。先复习考试前的 CM1-CM3、TD1、TD2 和 TP1；往年优化练习用于拓展。课表没有给出正式的逐项考试范围，也没有说明考试时长、题型和允许携带的资料。

## 维护

`sections/` 保存同步编排的章节源文件，链接以组装后的讲义所在目录为基准。日常阅读使用上方两份总讲义。修改时成对更新相应语言文件，再执行：

```sh
python3 tools/build_documents.py
```

生成需要 Pandoc、XeLaTeX、DejaVu Serif、Liberation Mono 和 Noto Sans CJK。字体路径在脚本中显式指定，以保证本机中文、法语重音和代码能正常输出。只生成 Markdown 可加 `--markdown-only`。
