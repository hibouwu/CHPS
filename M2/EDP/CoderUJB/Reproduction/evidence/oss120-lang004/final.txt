Here is a concise, production‑ready implementation of **`deleteFirst(String)`** that follows the behaviour of the rest of the `StrBuilder` API (null/empty input is ignored, the first occurrence is removed, and the builder itself is returned for chaining).

```java
/**
 * Deletes the first occurrence of the given string in the builder.
 *
 * @param str  the string to delete, {@code null} or empty causes no action
 * @return this, to enable chaining
 */
public StrBuilder deleteFirst(final String str) {
    // Guard against a null or empty argument – nothing to delete.
    if (str == null || str.isEmpty()) {
        return this;
    }

    // Find the first index of the substring.
    final int idx = indexOf(str);
    // If the substring is present, remove it.
    if (idx >= 0) {
        // delete(start, end) removes characters in the half‑open interval [start, end)
        delete(idx, idx + str.length());
    }
    // Return the builder to allow method‑chaining.
    return this;
}
```

### Why this works
* **Null / empty handling** – matches the contract of other delete methods (`deleteAll`, `deleteFirst(char)`, etc.).
* **Search** – uses the existing `indexOf(String)` implementation to locate the first occurrence.
* **Deletion** – delegates to the already‑tested `delete(int start, int end)` method, which takes care of range validation and buffer manipulation.
* **Fluent API** – returns `this` so calls can be chained (`builder.deleteFirst("foo").append("bar")`).
