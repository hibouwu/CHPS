The missing logic is the early termination check for `_allowMultipleMatches == false`. It must run **before reading buffered tokens or advancing the delegate**.

Add this at the beginning of `nextToken()`, before `TokenFilterContext ctxt = _exposedContext;`:

```java
// Stop after a completed match when multiple matches are disabled.
// Do not stop while buffered path tokens still need to be exposed.
if (!_allowMultipleMatches
        && (_currToken != null)
        && (_exposedContext == null)) {
    if (_currToken.isStructEnd()) {
        if (_headContext.isStartHandled()) {
            return (_currToken = null);
        }
    } else if (_currToken.isScalarValue()) {
        if (!_headContext.isStartHandled()
                && !_includePath
                && (_itemFilter == TokenFilter.INCLUDE_ALL)) {
            return (_currToken = null);
        }
    }
}
```
