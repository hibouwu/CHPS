The bug is in the tolerance scale used by `initializeStep`: it includes only absolute tolerance, ignoring relative tolerance and the magnitude of the initial state. This can produce an inappropriate initial step size, particularly when absolute tolerances are very small or zero.

Replace the existing `if (firstTime)` block with:

```java
if (firstTime) {
  final double[] scale = new double[y0.length];

  if (vecAbsoluteTolerance == null) {
    for (int j = 0; j < scale.length; ++j) {
      scale[j] = scalAbsoluteTolerance
               + scalRelativeTolerance * Math.abs(y[j]);
    }
  } else {
    for (int j = 0; j < scale.length; ++j) {
      scale[j] = vecAbsoluteTolerance[j]
               + vecRelativeTolerance[j] * Math.abs(y[j]);
    }
  }

  hNew = initializeStep(equations, forward, getOrder(), scale,
                        stepStart, y, yDotK[0], yTmp, yDotK[1]);
  firstTime = false;
}
```

This uses the appropriate component-wise scale:

```text
absoluteTolerance + relativeTolerance × |initialState|
```

A separate array also ensures the configured vector tolerances are not modified. The remainder of the function can stay unchanged.
