**Test case – `supportsBOMinFiles`**

```java
package org.jsoup.integration;

import org.jsoup.Jsoup;
import org.jsoup.nodes.Document;
import org.junit.Test;

import java.io.IOException;
import java.io.OutputStream;
import java.nio.file.Files;
import java.nio.file.Path;

/**
 * Test for Jsoup‑695 – UTF‑16 streams that start with a BOM must be
 * recognised as UTF‑16, not as UTF‑8.
 *
 * The test creates a temporary file that contains a UTF‑16LE BOM followed
 * by a short piece of text that contains non‑ASCII characters.  The file
 * is then parsed with {@code Jsoup.parse(File, null)} (null = let Jsoup
 * auto‑detect the charset).  If the BOM handling is correct the parsed
 * document text must be identical to the original string; if Jsoup
 * mistakenly treats the stream as UTF‑8 the result will be garbled.
 */
public class BomDetectionTest {

    @Test
    public void supportsBOMinFiles() throws IOException {
        // -----------------------------------------------------------------
        // 1️⃣  Prepare a UTF‑16LE file with a BOM
        // -----------------------------------------------------------------
        // Text that contains characters outside the ASCII range – this will
        // make any mis‑interpretation of the encoding obvious.
        final String original = "Привет, мир! こんにちは世界";

        // UTF‑16LE BOM (0xFF, 0xFE)
        final byte[] bom = new byte[] {(byte)0xFF, (byte)0xFE};

        // Encode the string in UTF‑16LE (the same endianness as the BOM)
        final byte[] encoded = original.getBytes("UTF-16LE");

        // Write BOM + encoded text to a temporary file
        Path tmpFile = Files.createTempFile("jsoup-bom-", ".html");
        try (OutputStream out = Files.newOutputStream(tmpFile)) {
            out.write(bom);          // write the BOM first
            out.write(encoded);      // then the UTF‑16LE payload
        }

        // -----------------------------------------------------------------
        // 2️⃣  Parse the file with Jsoup – let Jsoup auto‑detect the charset
        // -----------------------------------------------------------------
        Document doc = Jsoup.parse(tmpFile.toFile(), null); // charset = null → auto‑detect

        // -----------------------------------------------------------------
        // 3️⃣  Verify that the parsed text matches the original string
        // -----------------------------------------------------------------
        // The body text is the most straightforward way to get the raw
        // character data without any HTML tags interfering.
        String parsed = doc.body().text();

        // If Jsoup had treated the stream as UTF‑8 the result would be a
        // completely different (garbled) string.  The assertion therefore
        // guarantees that the UTF‑16 BOM was honoured.
        org.junit.Assert.assertEquals(
                "The document should be parsed using UTF‑16 (BOM detected)",
                original,
                parsed
        );

        // Clean‑up – delete the temporary file (best‑effort, ignore failures)
        try {
            Files.deleteIfExists(tmpFile);
        } catch (IOException ignored) { }
    }
}
```

### Why this test validates the fix

* **UTF‑16 BOM present** – the file starts with the exact byte sequence `0xFF 0xFE`, which is the UTF‑16LE BOM.  
* **Non‑ASCII payload** – the string contains Cyrillic and Japanese characters; if the stream were interpreted as UTF‑8 the characters would become nonsense, causing the assertion to fail.  
* **Auto‑detect mode** – `Jsoup.parse(File, null)` forces Jsoup to rely on its internal charset‑detection logic (the code path that previously mis‑identified the BOM as UTF‑8).  
* **Assertion** – a direct equality check between the original Unicode string and the parsed text guarantees that Jsoup correctly recognised the UTF‑16 BOM and decoded the file accordingly.

If the bug described in **Jsoup‑695** is still present, the test will fail, exposing the incorrect UTF‑8 assumption. Once the fix is applied (checking the raw BOM bytes before converting to characters), the test will pass.
