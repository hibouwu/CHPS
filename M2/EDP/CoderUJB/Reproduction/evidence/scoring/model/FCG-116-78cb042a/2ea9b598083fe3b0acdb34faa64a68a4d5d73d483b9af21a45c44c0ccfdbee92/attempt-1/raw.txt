**Implemented `parseSimpleToken`**

Below is a complete implementation of the `parseSimpleToken` method that follows the behaviour described in the Javadoc and matches the way the original Apache Commons CSV lexer works.

```java
/**
 * Parses a simple token.
 * <p/>
 * Simple token are tokens which are not surrounded by encapsulators. A simple token might contain escaped
 * delimiters (as \, or \;). The token is finished when one of the following conditions become true:
 * <ul>
 * <li>end of line has been reached (EORECORD)</li>
 * <li>end of stream has been reached (EOF)</li>
 * <li>an unescaped delimiter has been reached (TOKEN)</li>
 * </ul>
 *
 * @param token the current token
 * @param ch    the current character (already read from the underlying {@link ExtendedBufferedReader})
 * @return the filled token
 * @throws IOException on stream access error
 */
private Token parseSimpleToken(final Token token, int ch) throws IOException {
    // The token content is stored in a mutable StringBuilder that lives inside the Token.
    final StringBuilder buffer = token.getContent();

    // -----------------------------------------------------------------
    // Main loop – read characters until the token is finished.
    // -----------------------------------------------------------------
    while (true) {
        // -----------------------------------------------------------------
        // 1) End‑of‑stream / end‑of‑file
        // -----------------------------------------------------------------
        if (ch == END_OF_STREAM || isEndOfFile(ch)) {
            token.setType(EOF);
            break;
        }

        // -----------------------------------------------------------------
        // 2) End‑of‑record (line break)
        // -----------------------------------------------------------------
        if (readEndOfLine(ch)) {
            token.setType(EORECORD);
            break;
        }

        // -----------------------------------------------------------------
        // 3) Delimiter – the token ends *before* the delimiter, the delimiter
        //    itself will be processed by the caller.
        // -----------------------------------------------------------------
        if (isDelimiter(ch)) {
            token.setType(TOKEN);
            break;
        }

        // -----------------------------------------------------------------
        // 4) Comment – a comment token starts with the comment character and
        //    must be the first character of the token.
        // -----------------------------------------------------------------
        if (isCommentStart(ch) && buffer.length() == 0) {
            token.setType(COMMENT);
            // Consume the rest of the line (the comment text) but do not treat the
            // line‑break as part of the comment – the lexer will handle it on the
            // next iteration.
            while ((ch = reader.read()) != END_OF_STREAM && !readEndOfLine(ch)) {
                buffer.append((char) ch);
            }
            // If we stopped because of a line‑break, the caller will see the
            // EORECORD token on the next call, therefore we break here.
            break;
        }

        // -----------------------------------------------------------------
        // 5) Escape sequence – the next character is taken literally.
        // -----------------------------------------------------------------
        if (isEscape(ch)) {
            final int escaped = readEscape();          // may return END_OF_STREAM
            if (escaped == END_OF_STREAM) {
                token.setType(EOF);
                break;
            }
            buffer.append((char) escaped);
            // Continue reading after the escaped character.
            ch = reader.read();
            continue;
        }

        // -----------------------------------------------------------------
        // 6) Normal character – just append it.
        // -----------------------------------------------------------------
        buffer.append((char) ch);
        ch = reader.read(); // advance to the next character
    }

    // -----------------------------------------------------------------
    // Post‑processing: trim surrounding spaces if the format requests it.
    // -----------------------------------------------------------------
    if (ignoreSurroundingSpaces && token.getType() == TOKEN) {
        // Leading spaces are removed by moving the start index; trailing spaces
        // are removed by the dedicated helper.
        int start = 0;
        while (start < buffer.length() && isWhitespace(buffer.charAt(start))) {
            start++;
        }
        if (start > 0) {
            buffer.delete(0, start);
        }
        trimTrailingSpaces(buffer);
    }

    return token;
}
```

### Explanation of the implementation

| Step | What the code does | Reason |
|------|--------------------|--------|
| **Initialisation** | Retrieves the mutable `StringBuilder` that belongs to the supplied `Token`. | All characters that belong to the token are accumulated here. |
| **End‑of‑stream / EOF** | Detects `END_OF_STREAM` or a character that the lexer treats as EOF and marks the token as `EOF`. | The lexer must stop when the underlying stream ends. |
| **End‑of‑record** | Calls `readEndOfLine(ch)` – this method recognises `\r`, `\n`, `\r\n` etc. – and sets the token type to `EORECORD`. | A line break ends the current record. |
| **Delimiter** | When an unescaped delimiter is encountered the token type becomes `TOKEN` and the loop ends. The delimiter itself is **not** consumed; the caller will handle it on the next iteration. | Delimiters separate fields but are not part of the field value. |
| **Comment** | If the first character of a token is the comment start character, the token type becomes `COMMENT`. The rest of the line is read into the buffer (excluding the line‑break). | Allows whole‑line comments as defined by the CSV format. |
| **Escape handling** | When the escape character is seen, `readEscape()` reads the next character (handling escaped line‑breaks, escaped delimiters, etc.) and appends it verbatim. | Enables escaped delimiters (`\;`), escaped quotes, escaped line‑breaks, etc. |
| **Normal characters** | All other characters are appended directly. | Regular field content. |
| **Trailing‑space trimming** | If `ignoreSurroundingSpaces` is true and the token is a normal field (`TOKEN`), leading spaces are stripped manually and trailing spaces are removed via the existing helper `trimTrailingSpaces`. | Mirrors the behaviour of `CSVFormat.withIgnoreSurroundingSpaces(true)`. |
| **Return** | Returns the now‑filled token. | Allows the caller to continue parsing. |

The method uses only the public / package‑private helpers already present in `Lexer` (`isDelimiter`, `isEscape`, `readEscape`, `readEndOfLine`, `trimTrailingSpaces`, etc.) and therefore integrates cleanly with the rest of the class.
