Here is a faithful implementation of **`nextString()`** that follows the behaviour of the original Gson `JsonReader`.  
It:

* Peeks ahead when necessary (`doPeek()`),  
* Handles every token type that can be represented as a string (quoted, un‑quoted, buffered, long, number, and name tokens),  
* Returns the string value, clears the peeked state and updates the path‑tracking information, and  
* Throws an `IllegalStateException` for any other token type.

```java
/**
 * Returns the {@link com.google.gson.stream.JsonToken#STRING string} value of the next token,
 * consuming it. If the next token is a number, this method will return its
 * string form.
 *
 * @throws IllegalStateException if the next token is not a string or if
 *     this reader is closed.
 */
public String nextString() throws IOException {
    // If we have not yet peeked, do it now.
    int p = peeked;
    if (p == PEEKED_NONE) {
        p = doPeek();
    }

    String result;

    switch (p) {
        case PEEKED_UNQUOTED:               // an unquoted literal (e.g. true, false, null, or a bare string)
            result = peekedString;
            break;

        case PEEKED_SINGLE_QUOTED:          // a single‑quoted string
            result = nextQuotedValue('\'');
            break;

        case PEEKED_DOUBLE_QUOTED:          // a double‑quoted string
            result = nextQuotedValue('\"');
            break;

        case PEEKED_BUFFERED:               // a value that was already buffered as a string
            result = peekedString;
            break;

        case PEEKED_LONG:                   // a long value that was parsed as a number
            result = Long.toString(peekedLong);
            break;

        case PEEKED_NUMBER:                 // a number that is still in the character buffer
            result = new String(buffer, pos, peekedNumberLength);
            pos += peekedNumberLength;      // consume the number characters
            break;

        case PEEKED_UNQUOTED_NAME:          // a name token that we treat as a string value
            result = peekedString;
            break;

        default:
            // Anything else (BEGIN_OBJECT, END_ARRAY, BOOLEAN, NULL, etc.) is illegal here.
            throw new IllegalStateException(
                    "Expected a string but was " + peek() + locationString());
    }

    // Reset the peeked state so the next call will re‑peek.
    peeked = PEEKED_NONE;

    // Update the path information – the index of the current array element.
    if (stackSize > 0) {
        pathIndices[stackSize - 1]++;
    }

    return result;
}
```

### How it works

1. **Peeking** – If no token has been examined yet (`peeked == PEEKED_NONE`), we call `doPeek()` to fill `peeked` and related fields.
2. **Token handling** – A `switch` covers every token that can be represented as a string:
   * **Quoted values** – Delegated to `nextQuotedValue(char)` which also deals with escape sequences.
   * **Unquoted literals** – Already stored in `peekedString`.
   * **Buffered values** – Directly returned from `peekedString`.
   * **Numbers** – Either a pre‑parsed `long` (`PEEKED_LONG`) or a raw numeric token (`PEEKED_NUMBER`) that we turn into a `String`.
   * **Names** – When a name token is requested as a value (`PEEKED_UNQUOTED_NAME`), we return the stored name.
3. **State reset** – After extracting the value we clear `peeked` so the next read starts fresh.
4. **Path tracking** – The `pathIndices` array mirrors Gson’s internal bookkeeping for array positions; we increment the current level’s index.
5. **Error handling** – For any token that cannot be represented as a string, we throw an `IllegalStateException` with a helpful message that includes the current token (`peek()`) and location (`locationString()`).

This implementation integrates cleanly with the rest of the `JsonReader` class and reproduces the semantics of the original Gson library.
