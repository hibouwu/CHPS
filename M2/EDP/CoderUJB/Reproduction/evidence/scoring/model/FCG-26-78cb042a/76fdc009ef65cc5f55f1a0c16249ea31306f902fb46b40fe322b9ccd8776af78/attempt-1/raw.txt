Below is a faithful implementation of **`splitText(int offset)`** that follows the behaviour of the original *jsoup* `TextNode`.  
The method

* validates the supplied offset,  
* splits the current node’s text into a *head* (kept in the current node) and a *tail* (moved to a newly‑created sibling),  
* creates the new `TextNode` with the same base‑URI as the original,  
* inserts the new node directly after the current one (if the current node already has a parent), and  
* returns the newly‑created node.

```java
package org.jsoup.nodes;

import org.jsoup.helper.Validate;
import java.io.IOException;

/**
 * Split this text node into two nodes at the specified string offset. After splitting, this node will contain the
 * original text up to the offset, and will have a new text node sibling containing the text after the offset.
 *
 * @param offset string offset point to split node at.
 * @return the newly created text node containing the text after the offset.
 */
public TextNode splitText(int offset) {
    // -----------------------------------------------------------------
    // 1️⃣  Validate the offset – it must be inside the current text.
    // -----------------------------------------------------------------
    String current = text();                     // the whole text of this node
    int length = current.length();

    // jsoup throws an IllegalArgumentException when the offset is illegal.
    Validate.isTrue(offset >= 0 && offset <= length,
            "Split offset must be between 0 and %d (inclusive); got %d", length, offset);

    // -----------------------------------------------------------------
    // 2️⃣  Split the string.
    // -----------------------------------------------------------------
    String head = current.substring(0, offset); // text that stays in this node
    String tail = current.substring(offset);    // text that will go to the new node

    // Update the current node with the head part.
    text(head);

    // -----------------------------------------------------------------
    // 3️⃣  Create the sibling node that holds the tail part.
    // -----------------------------------------------------------------
    // The new node must keep the same base URI as the original node.
    TextNode tailNode = new TextNode(tail, baseUri());

    // -----------------------------------------------------------------
    // 4️⃣  Insert the new node directly after this one (if we have a parent).
    // -----------------------------------------------------------------
    // If this node is not attached to a parent yet, we simply return the
    // newly‑created node – the caller can attach it later.
    if (parent() != null) {
        // Node provides the `after(Node)` helper that inserts the argument
        // right after the current node in the parent's child list.
        this.after(tailNode);
    }

    // -----------------------------------------------------------------
    // 5️⃣  Return the newly created node.
    // -----------------------------------------------------------------
    return tailNode;
}
```

### Why this implementation works

| Step | Reasoning |
|------|------------|
| **Validation** | Mirrors jsoup’s `Validate.isTrue` usage, guaranteeing a clear `IllegalArgumentException` when the offset is out of range. |
| **String split** | `String.substring` is used exactly as jsoup does: the left part (`0 … offset`) stays, the right part (`offset … end`) moves. |
| **Base‑URI preservation** | `new TextNode(tail, baseUri())` ensures the new node inherits the same base URI as the original, which is required for relative URL resolution. |
| **Insertion** | `after(Node)` inserts the new node as the immediate sibling, preserving document order. If the node has no parent (e.g., it was created but not yet attached), we simply return the new node without inserting – this matches the original library’s behaviour. |
| **Return value** | The method returns the newly created `TextNode`, allowing callers to further manipulate it if needed. |

You can drop this method straight into the `TextNode` class; all referenced helpers (`text()`, `baseUri()`, `parent()`, `after(Node)`) already exist in the surrounding jsoup hierarchy.
