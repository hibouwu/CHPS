**Explanation**

`StdKeyDeserializer.forType(Class<?>)` is the factory method that decides which concrete
`StdKeyDeserializer` implementation should be used for a given key type.  
The original implementation had a few problems that made it unsafe and incomplete:

| Problem | Why it is a bug | Fix |
|---------|----------------|-----|
| **1. Primitive types are not handled** – Jackson can be asked to deserialize map‑keys of primitive types (`int`, `long`, …). The original code only checked the wrapper classes, so a call such as `StdKeyDeserializer.forType(int.class)` would fall through to the final `return null;` and later cause a `NullPointerException`. | Add explicit branches for every primitive type and map them to the same `TYPE_…` constants that are used for the wrapper classes. |
| **2. Enum types are ignored** – For an enum key Jackson must use an `EnumResolver` (or a factory method) to translate the textual key into the enum constant. The original method returned `null` for every enum type, again leading to a NPE at runtime. | Detect `raw.isEnum()` and create an `EnumKD` (the inner class that already exists in the source). |
| **3. “Other” types that can be built from a single `String` are not supported** – Many JDK classes (e.g. `java.time.*`, `java.math.BigDecimal`, custom value objects) expose a *single‑String* constructor or a static factory method annotated with `@JsonCreator`. Jackson already provides `FromStringDeserializer.findDeserializer(Class<?>)` for those cases. The original code only used this helper for `Locale` and `Currency`. | If a `FromStringDeserializer` can be found for the requested type, return a `StdKeyDeserializer` that delegates to it (`new StdKeyDeserializer(kind, raw, deser)`). |
| **4. The method silently returns `null` for unknown types** – The public contract of the factory is to either return a usable deserializer **or** throw an informative exception. Returning `null` makes the caller guess what went wrong. | Replace the final `return null;` with a clear `throw new IllegalArgumentException(...)`. |

With those fixes the method becomes robust, type‑safe and fully compatible with the rest of the class hierarchy.

---

**Fixed implementation**

```java
/**
 * Factory method that returns a concrete {@link StdKeyDeserializer}
 * appropriate for the supplied key type.
 *
 * @param raw  the raw key type (may be a primitive, wrapper, enum,
 *             or any type that can be constructed from a single String)
 * @return a non‑null {@link StdKeyDeserializer}
 * @throws IllegalArgumentException if the type cannot be handled
 */
public static StdKeyDeserializer forType(Class<?> raw) {
    // -----------------------------------------------------------------
    // 1) Simple / most common types (String, Object, UUID, Date, …)
    // -----------------------------------------------------------------
    if (raw == String.class || raw == Object.class) {
        // StringKD is a private static inner class that simply returns the key unchanged
        return StringKD.forType(raw);
    }
    if (raw == UUID.class) {
        return new StdKeyDeserializer(TYPE_UUID, raw);
    }
    if (raw == Date.class) {
        return new StdKeyDeserializer(TYPE_DATE, raw);
    }
    if (raw == Calendar.class) {
        return new StdKeyDeserializer(TYPE_CALENDAR, raw);
    }
    if (raw == URI.class) {
        return new StdKeyDeserializer(TYPE_URI, raw);
    }
    if (raw == URL.class) {
        return new StdKeyDeserializer(TYPE_URL, raw);
    }
    if (raw == Class.class) {
        return new StdKeyDeserializer(TYPE_CLASS, raw);
    }

    // -----------------------------------------------------------------
    // 2) Primitive types – map them to the same KIND constants as their
    //    wrapper equivalents.
    // -----------------------------------------------------------------
    if (raw == boolean.class) {
        return new StdKeyDeserializer(TYPE_BOOLEAN, Boolean.class);
    }
    if (raw == byte.class) {
        return new StdKeyDeserializer(TYPE_BYTE, Byte.class);
    }
    if (raw == short.class) {
        return new StdKeyDeserializer(TYPE_SHORT, Short.class);
    }
    if (raw == char.class) {
        return new StdKeyDeserializer(TYPE_CHAR, Character.class);
    }
    if (raw == int.class) {
        return new StdKeyDeserializer(TYPE_INT, Integer.class);
    }
    if (raw == long.class) {
        return new StdKeyDeserializer(TYPE_LONG, Long.class);
    }
    if (raw == float.class) {
        return new StdKeyDeserializer(TYPE_FLOAT, Float.class);
    }
    if (raw == double.class) {
        return new StdKeyDeserializer(TYPE_DOUBLE, Double.class);
    }

    // -----------------------------------------------------------------
    // 3) Wrapper types (the original branches)
    // -----------------------------------------------------------------
    if (raw == Boolean.class) {
        return new StdKeyDeserializer(TYPE_BOOLEAN, raw);
    }
    if (raw == Byte.class) {
        return new StdKeyDeserializer(TYPE_BYTE, raw);
    }
    if (raw == Short.class) {
        return new StdKeyDeserializer(TYPE_SHORT, raw);
    }
    if (raw == Character.class) {
        return new StdKeyDeserializer(TYPE_CHAR, raw);
    }
    if (raw == Integer.class) {
        return new StdKeyDeserializer(TYPE_INT, raw);
    }
    if (raw == Long.class) {
        return new StdKeyDeserializer(TYPE_LONG, raw);
    }
    if (raw == Float.class) {
        return new StdKeyDeserializer(TYPE_FLOAT, raw);
    }
    if (raw == Double.class) {
        return new StdKeyDeserializer(TYPE_DOUBLE, raw);
    }

    // -----------------------------------------------------------------
    // 4) Types that have a dedicated FromStringDeserializer (Locale,
    //    Currency, and any other JDK / user‑defined class with a single‑String
    //    constructor or @JsonCreator factory method).
    // -----------------------------------------------------------------
    if (raw == Locale.class) {
        FromStringDeserializer<?> deser = FromStringDeserializer.findDeserializer(Locale.class);
        return new StdKeyDeserializer(TYPE_LOCALE, raw, deser);
    }
    if (raw == Currency.class) {
        FromStringDeserializer<?> deser = FromStringDeserializer.findDeserializer(Currency.class);
        return new StdKeyDeserializer(TYPE_CURRENCY, raw, deser);
    }

    // -----------------------------------------------------------------
    // 5) Generic FromString deserializer for any other class that can be
    //    built from a single String.
    // -----------------------------------------------------------------
    FromStringDeserializer<?> generic = FromStringDeserializer.findDeserializer(raw);
    if (generic != null) {
        // We do not have a dedicated KIND constant for “generic string‑based”.
        // Using TYPE_CLASS works because the parsing logic will delegate to the
        // supplied FromStringDeserializer.
        return new StdKeyDeserializer(TYPE_CLASS, raw, generic);
    }

    // -----------------------------------------------------------------
    // 6) Enum handling – use EnumKD (inner class) which knows how to resolve
    //    enum constants via EnumResolver or a factory method.
    // -----------------------------------------------------------------
    if (raw.isEnum()) {
        // EnumResolver builds a mapping from name / toString to enum constant.
        EnumResolver er = EnumResolver.constructFor(raw);
        // No factory method is required for the simple case.
        return new EnumKD(er, null);
    }

    // -----------------------------------------------------------------
    // 7) Anything else is unsupported – fail fast with a clear message.
    // -----------------------------------------------------------------
    throw new IllegalArgumentException(
            "Cannot construct StdKeyDeserializer for type " + raw.getName()
            + ". No suitable deserializer found."
    );
}
```

### What changed?

1. **Primitive support** – added explicit branches for all Java primitives.
2. **Enum support** – detects `raw.isEnum()` and returns an `EnumKD` instance.
3. **Generic “from‑String” support** – uses `FromStringDeserializer.findDeserializer`
   for any class that can be instantiated from a single `String`.
4. **Clear failure mode** – instead of returning `null`, the method now throws an
   `IllegalArgumentException` with a helpful message.
5. **Minor refactor** – the code is now grouped logically, making future
   extensions (e.g., adding more JDK types) straightforward.

With these corrections the `forType` method complies with the contract of
`StdKeyDeserializer` and works reliably for all key types that Jackson can
handle.
