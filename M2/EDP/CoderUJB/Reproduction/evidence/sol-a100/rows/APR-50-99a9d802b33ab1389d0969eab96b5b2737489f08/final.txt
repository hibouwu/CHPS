The method incorrectly enables chunking, adding CRLF separators. For a standard Base64 string, disable chunking and update the Javadoc accordingly.

```java
/**
 * Encodes binary data using the Base64 algorithm without chunking.
 *
 * @param binaryData
 *            binary data to encode
 * @return String containing Base64 characters.
 * @since 1.4
 */
public static String encodeBase64String(byte[] binaryData) {
    return StringUtils.newStringUtf8(encodeBase64(binaryData, false));
}
```
