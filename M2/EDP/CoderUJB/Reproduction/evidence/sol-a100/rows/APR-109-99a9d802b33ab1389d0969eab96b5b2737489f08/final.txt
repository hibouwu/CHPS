The finiteness check should respect `lenient` mode. It should also run before `writeDeferredName()` so an invalid value does not partially modify the output or writer state.

```java
/**
 * Encodes {@code value}.
 *
 * @param value a finite value unless this writer is lenient
 * @return this writer
 */
public JsonWriter value(double value) throws IOException {
  if (!lenient && (Double.isNaN(value) || Double.isInfinite(value))) {
    throw new IllegalArgumentException(
        "Numeric values must be finite, but was " + value);
  }
  writeDeferredName();
  beforeValue();
  out.append(Double.toString(value));
  return this;
}
```
