The argument placeholder should default to `DEFAULT_ARG_NAME` when the argument name is `null`. An explicitly empty argument name should suppress the placeholder rather than print `<>`.

```java
private static void appendOption(final StringBuffer buff,
                                 final Option option,
                                 final boolean required)
{
    if (!required)
    {
        buff.append("[");
    }

    if (option.getOpt() != null)
    {
        buff.append("-").append(option.getOpt());
    }
    else
    {
        buff.append("--").append(option.getLongOpt());
    }

    if (option.hasArg())
    {
        final String argName = option.getArgName();

        if (argName == null || argName.length() != 0)
        {
            buff.append(" <")
                .append(argName == null ? DEFAULT_ARG_NAME : argName)
                .append(">");
        }
    }

    if (!required)
    {
        buff.append("]");
    }
}
```
