/**
 * Converts an old style id to a new style id.

 * @param id  the old style id

private static synchronized String getConvertedId(String id) {
    // Defensive check – a null argument cannot be converted.
    if (id == null) {
        return null;

    /*

2. **Lazy initialisation** – The static `cZoneIdConversion` map is created the first time the method is invoked.

3. **Thread‑safety** – The method is declared `synchronized`, guaranteeing that only one thread can initialise or read the map at a time.
4. **Lookup** – The method simply returns the value associated with the supplied old‑style ID, or `null` if no mapping exists, exactly as the Javadoc specifies.
