**Implemented `Soundex` class**

Below is a complete, self‑contained implementation of the `Soundex` class that matches the
signature you supplied.  
The most important part – the `soundex(String)` method – follows the classic
American Soundex algorithm:

1. Keep the first letter of the word (upper‑cased).  
2. Convert every subsequent letter to a digit using the mapping table.  
3. Suppress consecutive duplicate digits **and** digits that map to `0` (vowels, `H`,
   `W`, `Y`).  
4. Stop when the result reaches the configured maximum length (default = 4).  
5. Pad the result with `'0'` characters if it is shorter than the maximum length.  

All other public methods (`encode`, `difference`, getters / setters, constructors,
etc.) are also supplied so the class can be used exactly like the original Apache
Commons‑Codec implementation.

```java
package org.apache.commons.codec.language;

import java.util.Locale;
import org.apache.commons.codec.EncoderException;
import org.apache.commons.codec.StringEncoder;

/**
 * Soundex implementation compatible with Apache Commons‑Codec.
 *
 * <p>The algorithm implemented here is the classic American Soundex
 * (US‑English) as described in the original Apache library.  The class
 * can be instantiated with a custom mapping table, but the default
 * mapping (US_ENGLISH) is provided for convenience.</p>
 *
 * @author  OpenAI ChatGPT
 * @since   1.0
 */
public class Soundex implements StringEncoder {

    /** Default mapping string for US‑English Soundex. */
    public static final String US_ENGLISH_MAPPING_STRING = "0123012#02245501262301#202";

    /** Internal char[] representation of the default mapping. */
    private static final char[] US_ENGLISH_MAPPING = US_ENGLISH_MAPPING_STRING.toCharArray();

    /** A ready‑to‑use instance that follows the US‑English mapping. */
    public static final Soundex US_ENGLISH = new Soundex();

    /** Default length of a Soundex code (4).  Kept for backward compatibility. */
    @Deprecated
    private int maxLength = 4;

    /** Mapping table used by this instance – one entry per letter A‑Z. */
    private final char[] soundexMapping;

    /* ------------------------------------------------------------ *
     *  Constructors
     * ------------------------------------------------------------ */

    /** Default constructor – uses the US‑English mapping. */
    public Soundex() {
        this.soundexMapping = US_ENGLISH_MAPPING.clone();
    }

    /**
     * Construct a Soundex instance with a custom mapping table.
     *
     * @param mapping a 26‑character array that maps ‘A’‑‘Z’ to Soundex digits.
     * @throws IllegalArgumentException if the supplied array is not exactly 26 chars.
     */
    public Soundex(final char[] mapping) {
        if (mapping == null || mapping.length != 26) {
            throw new IllegalArgumentException("Mapping must be a 26‑character array");
        }
        this.soundexMapping = mapping.clone();
    }

    /**
     * Construct a Soundex instance with a custom mapping supplied as a String.
     *
     * @param mapping a 26‑character string that maps ‘A’‑‘Z’ to Soundex digits.
     * @throws IllegalArgumentException if the supplied string is not exactly 26 chars.
     */
    public Soundex(final String mapping) {
        if (mapping == null || mapping.length() != 26) {
            throw new IllegalArgumentException("Mapping must be a 26‑character string");
        }
        this.soundexMapping = mapping.toCharArray();
    }

    /* ------------------------------------------------------------ *
     *  Public API
     * ------------------------------------------------------------ */

    /**
     * Returns the Soundex code for the supplied string.
     *
     * @param str String to encode using the Soundex algorithm
     * @return a Soundex code (always {@code maxLength} characters long)
     * @throws IllegalArgumentException if {@code str} contains a character that cannot be mapped
     */
    public String soundex(String str) {
        if (str == null) {
            return null;
        }

        // Normalise – Soundex works on upper‑case English letters only
        String upper = str.toUpperCase(Locale.ENGLISH);
        if (upper.length() == 0) {
            return "";
        }

        // First character is kept verbatim (must be a letter)
        char first = upper.charAt(0);
        if (!Character.isLetter(first)) {
            throw new IllegalArgumentException("First character must be a letter: " + str);
        }

        StringBuilder result = new StringBuilder();
        result.append(first);

        // Previous encoded digit – initialise with the code of the first letter
        char prevCode = map(first);

        // Encode the rest of the characters
        for (int i = 1; i < upper.length() && result.length() < maxLength; i++) {
            char ch = upper.charAt(i);
            char code = map(ch);

            // Skip characters that map to '0' (vowels, H, W, Y) – they do not appear in the output
            if (code == '0') {
                prevCode = code; // still update prevCode to suppress duplicates across a vowel
                continue;
            }

            // Suppress consecutive duplicate codes
            if (code != prevCode) {
                result.append(code);
            }
            prevCode = code;
        }

        // Pad with '0' to reach the required length
        while (result.length() < maxLength) {
            result.append('0');
        }

        // Truncate if we somehow exceeded the length (should not happen because of the loop guard)
        if (result.length() > maxLength) {
            return result.substring(0, maxLength);
        }
        return result.toString();
    }

    /**
     * Computes the difference between two strings as the number of matching
     * characters in their Soundex codes (0‑4).
     *
     * @param s1 first string
     * @param s2 second string
     * @return an integer between 0 and {@code maxLength}
     * @throws EncoderException if either argument cannot be encoded
     */
    public int difference(final String s1, final String s2) throws EncoderException {
        String code1 = soundex(s1);
        String code2 = soundex(s2);
        if (code1 == null || code2 == null) {
            throw new EncoderException("Unable to encode one of the strings");
        }
        int matches = 0;
        for (int i = 0; i < maxLength; i++) {
            if (code1.charAt(i) == code2.charAt(i)) {
                matches++;
            }
        }
        return matches;
    }

    /** {@inheritDoc} */
    @Override
    public Object encode(final Object obj) throws EncoderException {
        if (obj == null) {
            return null;
        }
        if (obj instanceof String) {
            return encode((String) obj);
        }
        throw new EncoderException("Parameter supplied to Soundex encode is not of type String");
    }

    /** {@inheritDoc} */
    @Override
    public String encode(final String str) {
        return soundex(str);
    }

    /** @deprecated use the constructor that accepts a mapping instead */
    @Deprecated
    public int getMaxLength() {
        return maxLength;
    }

    /** @deprecated use the constructor that accepts a mapping instead */
    @Deprecated
    public void setMaxLength(final int maxLength) {
        if (maxLength <= 0) {
            throw new IllegalArgumentException("maxLength must be positive");
        }
        this.maxLength = maxLength;
    }

    /** Returns a copy of the mapping table used by this instance. */
    private char[] getSoundexMapping() {
        return soundexMapping.clone();
    }

    /**
     * Maps a single upper‑case letter to its Soundex digit.
     *
     * @param ch character to map (must be A‑Z)
     * @return the corresponding digit character, or '0' for vowels/H/W/Y
     * @throws IllegalArgumentException if {@code ch} is not a letter A‑Z
     */
    private char map(final char ch) {
        if (ch < 'A' || ch > 'Z') {
            throw new IllegalArgumentException("Character '" + ch + "' is not a valid upper‑case letter");
        }
        return soundexMapping[ch - 'A'];
    }
}
```

### How the `soundex` method works

| Step | Description |
|------|-------------|
| **1** | Convert the input to upper‑case (Locale.ENGLISH). |
| **2** | Keep the first character unchanged (it must be a letter). |
| **3** | For each subsequent character, obtain its digit via `map`. |
| **4** | Skip digits equal to `'0'` (vowels, `H`, `W`, `Y`). |
| **5** | Suppress a digit if it is the same as the previous non‑zero digit. |
| **6** | Append digits until the result reaches `maxLength` (default 4). |
| **7** | Pad with `'0'` if the result is shorter than `maxLength`. |
| **8** | Return the final string. |
