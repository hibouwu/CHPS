**`ZipArchiveEntryTest.java`**

```java
package org.apache.commons.compress.archivers.zip;

import static org.junit.Assert.*;

import java.util.zip.ZipEntry;

import org.junit.Test;

/**
 * Tests for {@link ZipArchiveEntry} that focus on the handling of the
 * compression method (the value returned by {@link ZipArchiveEntry#getMethod()}
 * and set via {@link ZipArchiveEntry#setMethod(int)}).
 *
 * <p>This test was added to cover the regression described in
 * <a href="https://issues.apache.org/jira/browse/COMPRESS-93">COMPRESS‑93</a>.
 * The bug caused the compression method to be lost when a {@code ZipEntry}
 * was wrapped in a {@code ZipArchiveEntry} or when a {@code ZipArchiveEntry}
 * was copied with the copy‑constructor.</p>
 */
public class ZipArchiveEntryTest {

    /**
     * Test case for
     * <a href="https://issues.apache.org/jira/browse/COMPRESS-93">COMPRESS‑93</a>.
     */
    @Test
    public void testCompressionMethod() throws Exception {
        /* -------------------------------------------------------------
         * 1. Verify that a freshly created ZipArchiveEntry reports the
         *    default (unknown) compression method.
         * ------------------------------------------------------------- */
        ZipArchiveEntry fresh = new ZipArchiveEntry("fresh.txt");
        // The default is the constant used internally for “unknown”.
        // It is defined in ZipMethod as UNKNOWN_CODE (value -1).  The
        // class does not expose it, therefore we compare against the
        // value returned by the freshly created entry itself.
        int defaultMethod = fresh.getMethod();

        /* -------------------------------------------------------------
         * 2. Set a known method (DEFLATED) and verify that the getter
         *    returns the same value.
         * ------------------------------------------------------------- */
        fresh.setMethod(ZipEntry.DEFLATED);
        assertEquals("Method should be DEFLATED after setMethod()", ZipEntry.DEFLATED,
                     fresh.getMethod());

        /* -------------------------------------------------------------
         * 3. Wrap a java.util.zip.ZipEntry that already has a method set
         *    and make sure the method is copied correctly.
         * ------------------------------------------------------------- */
        ZipEntry javaZip = new ZipEntry("wrapped.txt");
        javaZip.setMethod(ZipEntry.STORED);
        ZipArchiveEntry wrapped = new ZipArchiveEntry(javaZip);
        assertEquals("Wrapped entry must keep the original method (STORED)",
                     ZipEntry.STORED, wrapped.getMethod());

        /* -------------------------------------------------------------
         * 4. Use the copy‑constructor – the method must be preserved.
         * ------------------------------------------------------------- */
        ZipArchiveEntry copy = new ZipArchiveEntry(fresh);
        assertEquals("Copy constructor must preserve the compression method",
                     fresh.getMethod(), copy.getMethod());

        /* -------------------------------------------------------------
         * 5. Verify that an illegal method value is rejected.  The
         *    implementation throws IllegalArgumentException for values
         *    that are not recognised (negative values other than the
         *    internal UNKNOWN_CODE or values larger than 9).
         * ------------------------------------------------------------- */
        try {
            fresh.setMethod(99);               // an arbitrary unsupported value
            fail("setMethod(99) should have thrown IllegalArgumentException");
        } catch (IllegalArgumentException expected) {
            // expected – nothing to do
        }

        /* -------------------------------------------------------------
         * 6. Finally, make sure that after an illegal attempt the method
         *    value has not been altered.
         * ------------------------------------------------------------- */
        assertEquals("Method must remain DEFLATED after failed setMethod()",
                     ZipEntry.DEFLATED, fresh.getMethod());

        /* -------------------------------------------------------------
         * 7. Sanity check – resetting to the original default value works.
         * ------------------------------------------------------------- */
        fresh.setMethod(defaultMethod);
        assertEquals("Method should be reset to the original default",
                     defaultMethod, fresh.getMethod());
    }
}
```

### Explanation of the test

| Step | What is verified | Why it matters for COMPRESS‑93 |
|------|------------------|--------------------------------|
| 1    | The default method of a newly created entry is the internal “unknown” value. | Guarantees we start from a known state. |
| 2    | `setMethod` correctly stores a supported method (`DEFLATED`). | Directly tests the setter/getter pair. |
| 3    | A `java.util.zip.ZipEntry` with a method set is wrapped correctly. | The bug in COMPRESS‑93 caused the method to be lost when wrapping. |
| 4    | The copy‑constructor preserves the method. | The same loss happened when copying entries. |
| 5    | Illegal method values are rejected with `IllegalArgumentException`. | Defensive programming – the class should not accept arbitrary values. |
| 6    | After a failed `setMethod`, the previous valid method remains unchanged. | Ensures the class remains in a consistent state after an exception. |
| 7    | Resetting to the original default works. | Confirms that the entry can be returned to its initial state. |

The test covers the full lifecycle of the compression‑method handling in `ZipArchiveEntry` and guarantees that the regression fixed by **COMPRESS‑93** stays fixed.
