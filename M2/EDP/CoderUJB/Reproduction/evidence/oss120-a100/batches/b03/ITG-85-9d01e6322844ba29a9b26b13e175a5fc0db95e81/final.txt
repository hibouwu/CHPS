**JUnit test (JFreeChart 1.0.7)**  

```java
package org.jfree.chart.junit;

import static org.junit.Assert.*;

import java.text.ParseException;

import org.jfree.data.time.Day;
import org.jfree.data.time.TimeSeries;
import org.junit.Test;

/**
 * Test for Chart‑818 – TimeSeries.createCopy() should return an empty series
 * when the requested period does not intersect the data, instead of throwing
 * IllegalArgumentException.
 */
public class TimeSeriesCreateCopyTest {

    /**
     * Reproduces the bug reported as Chart‑818 (bug 1864222).  
     * The source series contains a gap between 19‑Aug‑2005 and 31‑Jan‑2006.
     * The copy request (01‑Dec‑2005 … 18‑Jan‑2006) therefore matches **no**
     * items. The expected result is an empty TimeSeries; an exception is a
     * test failure.
     */
    @Test
    public void testBug1864222() throws CloneNotSupportedException {
        // -----------------------------------------------------------------
        // 1. Build the original series (the same data as in the issue report)
        // -----------------------------------------------------------------
        TimeSeries foo = new TimeSeries("foo", Day.class);

        foo.add(new Day(19, 4, 2005), 1);
        foo.add(new Day(25, 5, 2005), 1);
        foo.add(new Day(28, 5, 2005), 1);
        foo.add(new Day(30, 5, 2005), 1);
        foo.add(new Day(1, 6, 2005), 1);
        foo.add(new Day(3, 6, 2005), 1);
        foo.add(new Day(19, 8, 2005), 1);
        foo.add(new Day(31, 1, 2006), 1);

        // ---------------------------------------------------------------
        // 2. Request a copy for a period that does NOT intersect the data
        // ---------------------------------------------------------------
        Day start = new Day(1, 12, 2005);   // 1‑Dec‑2005
        Day end   = new Day(18, 1, 2006);   // 18‑Jan‑2006

        TimeSeries bar = foo.createCopy(start, end);

        // ---------------------------------------------------------------
        // 3. Verify the result – it must be an **empty** series
        // ---------------------------------------------------------------
        assertNotNull("Returned series must not be null", bar);
        assertEquals("Series key must be preserved", foo.getKey(), bar.getKey());
        assertTrue("Series should be empty when the requested period has no data",
                   bar.isEmpty());
    }
}
```

### What the test does

1. **Creates** a `TimeSeries` named *foo* and populates it with the same dates
   that appear in the original bug report.
2. **Calls** `createCopy(start, end)` with a period (`01‑Dec‑2005 … 18‑Jan‑2006`)
   that does not contain any of the added observations.
3. **Asserts** that:
   * No exception is thrown (`createCopy` may throw `CloneNotSupportedException`,
     which is declared on the test method).
   * The returned series is not `null`.
   * The series key is preserved (optional sanity check).
   * The returned series is **empty** (`bar.isEmpty()` returns `true`).

If JFreeChart still throws `IllegalArgumentException`, the test will fail,
exposing the regression described in **Chart‑818** (bug 1864222).
