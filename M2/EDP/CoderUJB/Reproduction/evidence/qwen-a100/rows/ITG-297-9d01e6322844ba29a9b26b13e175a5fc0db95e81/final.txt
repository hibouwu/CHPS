To create a test case for the issue `JacksonXml-180`, we need to define the POJO classes that represent the structure described in the issue report. Then, we can write a test case that serializes and deserializes an instance of these classes, ensuring that the deserialization process handles empty or missing inner lists correctly.

Here's how you can implement the test case:

```java
import com.fasterxml.jackson.dataformat.xml.XmlMapper;
import com.fasterxml.jackson.dataformat.xml.annotation.JacksonXmlElementWrapper;
import com.fasterxml.jackson.dataformat.xml.annotation.JacksonXmlProperty;
import org.junit.Test;

import java.util.ArrayList;
import java.util.List;

import static org.junit.Assert.assertEquals;

public class JacksonXmlTest {

    @Test
    public void testNestedUnwrappedLists180() throws Exception {
        // Create an instance of Definition with an empty inner list
        Definition definition = new Definition();
        Record record = new Record();
        record.setFields(new ArrayList<>()); // Empty list of fields
        definition.getRecords().add(record);

        // Serialize the Definition object to XML
        XmlMapper xmlMapper = new XmlMapper();
        String xml = xmlMapper.writeValueAsString(definition);
        System.out.println("Serialized XML:\n" + xml);

        // Deserialize the XML back to a Definition object
        Definition deserializedDefinition = xmlMapper.readValue(xml, Definition.class);

        // Verify that the deserialized object matches the original
        assertEquals(1, deserializedDefinition.getRecords().size());
        assertEquals(0, deserializedDefinition.getRecords().get(0).getFields().size());
    }

    // POJO classes

    static class Definition {
        private List<Record> records = new ArrayList<>();

        @JacksonXmlElementWrapper(useWrapping = false)
        @JacksonXmlProperty(localName = "record")
        public List<Record> getRecords() {
            return records;
        }

        public void setRecords(List<Record> records) {
            this.records = records;
        }
    }

    static class Record {
        private List<Field> fields = new ArrayList<>();

        @JacksonXmlElementWrapper(useWrapping = false)
        @JacksonXmlProperty(localName = "field")
        public List<Field> getFields() {
            return fields;
        }

        public void setFields(List<Field> fields) {
            this.fields = fields;
        }
    }

    static class Field {
        private String name;

        @JacksonXmlProperty(localName = "name")
        public String getName() {
            return name;
        }

        public void setName(String name) {
            this.name = name;
        }
    }
}
```

### Explanation:

1. **POJO Classes**:
   - `Definition`: Contains a list of `Record` objects. The `@JacksonXmlElementWrapper(useWrapping = false)` annotation indicates that the list should not be wrapped in an additional XML element.
   - `Record`: Contains a list of `Field` objects. Similar to `Definition`, the list is not wrapped.
   - `Field`: Represents a simple field with a `name` property.

2. **Test Case**:
   - We create an instance of `Definition` with a single `Record` that has an empty list of `Field` objects.
   - We serialize this instance to XML using `XmlMapper`.
   - We then deserialize the XML back into a `Definition` object.
   - Finally, we verify that the deserialized object matches the original, specifically checking that the inner list of `Field` objects is empty.

This test case ensures that the deserialization process correctly handles empty inner lists without causing issues with the outer list.
