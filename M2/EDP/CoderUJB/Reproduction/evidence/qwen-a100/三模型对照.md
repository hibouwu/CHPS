Qwen 的 APR 第 410 行两次在测试类初始化时报告 Europe/London 时区不可识别，目标断言尚未执行。该题保留未决，APR 的全 20 题通过数范围为 2–3，对 gpt-oss 的差值范围为 -20 至 -15 个百分点。对应版本的参考对照此前通过。

Qwen 的 DD 官方判分为 9/20。按独立诊断规则，20 条在首行有清晰的 A/Yes 或 B/No 选项，其中 0 条与官方解析的类别不同。[Qwen 的 DD 首行复核](dd-first-choice.json)

区间按项目整体抽样 10,000 次（种子 20261105）；同项目的题、DD 的缺陷/修复配对一起移动。每类 20 行中，一题相差 5 个百分点。FCG 与 CodeLlama 比较时一题因目标测试超时未决，逐行文件另给全分母差值上下界。这些区间反映选中项目上的波动。

Qwen 使用 BF16 权重与固定 revision 的原生 chat 模板，温度 0.2，最多新生成 4,096 个回答 tokens。gpt-oss 使用 MXFP4，推理与回答共用 4,096 tokens；CodeLlama 使用 completion 提示，输出上限 256 tokens。相同题单上的差异，同时包含模型、提示形式、解码和预算的差异。

评分时保留每题原始输出。CodeLlama 的 APR 有 5 道提交只剩未完注释；DD 的回复可能继续生成下一题，官方解析器对肯定关键词的优先级会改变判定。首选项分析只列为离线诊断。

Qwen 正式批次生成 100/100 个回答，正式输入 80,825 tokens、输出 60,606 tokens。ROMEO 单卡作业合计 24 分 3 秒（含暂存、独立调试和等待本地放行），付费 API 支出 $0。
