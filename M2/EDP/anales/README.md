# Annales d'évaluation de performances EDP 历年试题

[Sommaire du module 课程目录](../README.md)

Ce dossier regroupe deux sujets, de deux pages chacun, transcrits à partir de quatre photographies. Chaque sujet dispose d'une transcription française et d'une version bilingue français-chinois, avec les mêmes numéros de questions, données, unités et liens vers les photographies. Les transcriptions ci-dessous ne contiennent pas de corrigé ; les solutions classées sont proposées dans le sous-dossier indiqué en fin de page. Les dates, durées et consignes concernent uniquement les épreuves historiques correspondantes. 本目录根据四张试卷照片整理，收录两套试题，每套两页。法语版为原题转录，中文版为法语在前、中文在后的同行对照版，均保留题号、数据、单位和原图链接，原题转录不含解答；分类题解入口见本页末尾。考试日期、时长和允许携带的材料仅对应各自历史试卷。

## Nommage et provenance 图片命名与来源

Les photographies sont conservées sans modification dans `Images/`, sous la forme `edp_examen_YYYY-MM-DD_pNN.png`. Leur classement suit les dates et les numéros de page visibles. 图片移入 `Images/`，文件名采用 `edp_examen_YYYY-MM-DD_pNN.png`。只移动和重命名，图像内容保持原样；顺序依据照片上的日期和页码确定。

La transcription harmonise la présentation, les accents, les espaces et les notations. La table statistique annoncée dans le sujet de 2023 ne figure pas parmi les quatre photographies. L'harmonisation de la notation de la formule de 2025 est signalée dans l'exercice concerné. Le fond des photographies, les autres feuilles et les annotations manuscrites isolées ne sont pas transcrits. 转录统一了排版、重音、空格和符号写法。2023 年题面提到的附带统计表不在这四张照片中；2025 年公式的大小写统一说明见对应题目校注。原图中不属于试卷正文的背景、其他纸张及零散手写痕迹不作转录。
