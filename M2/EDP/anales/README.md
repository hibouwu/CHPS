# EDP 历年试题 · Annales d’évaluation de performances

[课程目录 · Sommaire du module](../README.md)

本目录根据四张试卷照片整理，收录两套试题，每套两页。法语版为原题转录，中文版为对应译文，均保留题号、数据、单位和原图链接，不含解答。考试日期、时长和允许携带的材料仅对应各自历史试卷。

Ce dossier regroupe deux sujets, de deux pages chacun, transcrits à partir de quatre photographies. Chaque sujet dispose d’une transcription française et d’une traduction chinoise, avec les mêmes numéros de questions, données, unités et liens vers les photographies. Aucun corrigé n’est inclus. Les dates, durées et consignes concernent uniquement les épreuves historiques correspondantes.
