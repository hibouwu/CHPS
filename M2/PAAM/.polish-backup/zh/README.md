## 怎样阅读

第一次读，先跟着每篇开头的路线建立主线。遇到代码，先找共享状态和一次操作的完成位置，再分析线程交错；遇到性能图，先确认机器、横纵轴、基准与单位。正文中的补充解释与原课件勘误均已标注。

锁讲义的内存模型是后续阅读的关键：课件在后面的伪代码中省略很多显式原子操作，却假设顺序一致语义。不能把它们按普通 C 变量照抄。事务内存的并发原子性与最后一讲的持久性也是不同要求，学习时要分别判断。

所有正文图片已在本地，原文稿还可按页展开原图，核对箭头、颜色与逐步动画。中文稿合并重复的展示页，但注明完整页码范围；完整原页没有删除。长篇 NUMA 可以分为硬件与放置、策略预测、GC、虚拟化四次阅读。

每篇末尾链接对应实验。自检题用于检查概念，不等同于原课件题目或考试范围；本轮没有代写全部实验答案。

## 校对说明

原始 MinerU 内容可用于辅助阅读，但在多栏代码、覆盖注释、图中数字及表格上存在明显失真。PDF 本身带文字层，因此原文稿改为逐页按文本块重建，保留原图作准确对照；它保留课件已有的代码疑点，并在相应页加校对注，不能当作一套可直接编译的程序。

值得优先查看的勘误包括：Bakery 中空 `if` 并不会等待；顺序一致性例子的“不可能结果”有合法交错反例；事务内存的递归退避重置了窗口；NVMM 的字段名、刷新范围和平台持久域需要区分。完整记录在[审查与勘误](OCR/ERRATA.md)，逐页记录及校验结果位于 [OCR 目录](OCR/README.md)。
