# PAAM 课程讲义

这组讲义沿着一个问题展开：多个线程怎样共同完成工作，并得到正确、可靠的结果？先从线程与同步学起，再进入锁的实现、非阻塞数据结构和事务内存；最后把视线转向数据的位置，以及崩溃后留下的状态。

初读可以直接进入中文教程，按例子和执行步骤理解机制。需要核对术语、代码或原图时，再打开同一行的原文与 PDF。三种材料按课件页码对应。

课程介绍和第一讲已将课堂转录中的解释、例子与注意事项放入对应小节，结构沿用 DA 讲义的阅读方式：按课件顺序学习，末尾用转录对应表和英文标题索引回查。原始记录见[第一段](01-transcript-part1.md)与[第二段](01-transcript-part2.md)。课程安排同时标明课件内容与这次录音中的口头调整。

## 怎样阅读

读代码时，先画出几个线程共同访问的状态，再跟踪一次操作从准备到生效的过程。能说清成功路径后，试着在中间暂停一个线程，看看别人继续运行会发生什么。教程中的余额、队列和事务例子都可以用这种方式检查。

读性能图时，先找到横纵轴、单位和比较基准，再看曲线变化。增加核数后总时间是否下降，与某个局部操作是否更快，可能是两个不同的问题。图旁说明保留了原实验的机器与工作负载条件。

锁讲义的内存模型是后续阅读的关键：课件在后面的伪代码中省略很多显式原子操作，却假设顺序一致语义。不能把它们按普通 C 变量照抄。事务内存的并发原子性与最后一讲的持久性也是不同要求，学习时要分别判断。

每篇开头有阅读路线，可以按概念单元分次读。NUMA 尤其适合分成硬件与放置、策略预测、GC、虚拟化四段。合并讲解的动画标有完整页码范围，需要追踪某一步时，可在原文稿中逐页展开原图。所有正文图片都已保存在本地。

每篇末尾有自检题及判断要点，先尝试独立解释，再对照答案补上遗漏的条件。随后可进入对应实验，把共享状态、同步关系或内存放置落实到代码中。这些自检题是学习辅助，不代表原课件题目或考试范围；实验入口链接到教师提供的材料。

## 校对说明

原始 MinerU 内容可用于辅助阅读，但在多栏代码、覆盖注释、图中数字及表格上存在明显失真。PDF 本身带文字层，因此原文稿改为逐页按文本块重建，保留原图作准确对照；它保留课件已有的代码疑点，并在相应页加校对注，不能当作一套可直接编译的程序。

值得优先查看的勘误包括：Bakery 中空 `if` 并不会等待；顺序一致性例子的“不可能结果”有合法交错反例；事务内存的递归退避重置了窗口；NVMM 的字段名、刷新范围和平台持久域需要区分。完整说明见[课件勘误](ERRATA.md)。
