## Exercice I: Task Stealing (17 points)

In this exercise, you will implement a small task scheduler using a task-stealing mechanism. To do so, we consider threads called workers in the following. Each worker has a task queue to execute. A task is represented by a function and an argument.

A worker runs an infinite loop. In this loop, if the worker's queue is not empty, it removes a task and executes it. To execute it, it calls the function associated with the task using its argument. If the worker's queue is empty, it tries to steal tasks from other workers.

### Question 1 (1 point, easy)

Give the definition of the `task_t` structure that represents a task. In addition to the function and the argument, a task has a `next` field of type `struct task_t*` used to implement the queues.

### Question 2 (1 point, easy)

Inspired by the lock-free queue studied in class, give the definition of the `queue_t` structure that implements a queue. A queue is a linked list of `task_t`. It must follow a first-in-first-out (FIFO) semantics, meaning that the first element removed is the oldest one added.

### Question 3 (1.5 points, easy)

Write the code of the function `void enqueue(struct queue_t* queue, struct task_t* task)` that adds the task `task` to the queue `queue`.

### Question 4 (1.5 points, easy)

Write the code of the function `struct task_t* dequeue(struct queue_t* queue)` that removes the oldest element from the queue. This function should return a null pointer when the queue is empty.

### Question 5 (3 points, easy)

We now consider the following global variables:

```c
size_t nb_threads;
struct queue_t* queues;
```

The variable `nb_threads` gives the number of threads. The variable `queues` is a pointer to an array of `nb_threads` queues.

Write the code of the `main` function. This function receives the number of threads to create as an argument. It initializes `nb_threads` and `queues`. Then it creates `nb_threads` workers, each receiving a pointer to its queue as an argument. You may assume that the function `void* worker(void* arg)` is provided. Finally, the `main` function waits for the `nb_threads` workers to terminate.

### Question 6 (4 points, medium)

Write the code of the function `void* worker(void* arg)`. The algorithm of this function is given at the beginning of the exercise. For this function, you do not have to handle termination: as long as a worker finds no task in its queue, it keeps trying to steal tasks from other workers' queues.

### Question 7 (5 points, difficult)

We now want to handle termination. Modify the `worker` function so that all workers exit when all queues are empty and all tasks have completed execution. You can implement termination by considering three modes:

- **normal mode**: the thread executes tasks from its own queue,
- **steal mode**: the thread attempts to steal tasks from other thread queues,
- **termination mode**: the thread attempts to terminate.

The algorithm relies on two variables:

- **nb_stealers**: the number of threads currently in steal mode,
- **nb_terminates**: the number of threads currently in termination mode.

The system can terminate once `nb_terminates` is equal to `nb_threads`. More precisely:

- **normal mode**: if a thread finds no work in its queue, it increments `nb_stealers` and switches to steal mode.
- **steal mode**: the thread attempts to steal from other queues. If it successfully steals a task, it decrements `nb_stealers` and returns to normal mode. Otherwise, if it has attempted all queues without finding any task to steal, it increments `nb_terminates` and switches to termination mode.
- **termination mode**: the thread waits until `nb_terminates == nb_threads`. If it observes that `nb_stealers` is no longer zero, it decrements `nb_terminates` and returns to steal mode. If it observes that `nb_terminates == nb_threads`, then all threads have reached termination mode, meaning that all threads can safely exit.

You must implement this algorithm without using locks.
