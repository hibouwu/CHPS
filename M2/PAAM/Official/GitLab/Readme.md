# Presentation

The course CSC5101 (Advanced Programming of Multicore Architectures) lasts 30h.
It is included in both the CHPS master's at Université Paris-Saclay and the PDS track of the master's in Computer Science at IP Paris.
This course presents system programming techniques for multicore architectures with a focus on recent advances in the field: lock-free algorithms, transactional memory, non-volatile memory, or tiered memory systems.
This course presents the theoretical concepts underlying these systems and their practical implementation.
It gives solid skills in system and parallel programming in order to be able to pursue a PhD thesis or work in a company.   

The final grade is determined by a final exam at the end of the course.
You can find past exams [here](exams).
