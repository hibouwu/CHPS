# Page 3 - AI Is Already Changing Work

AI is already part of real work. It helps people write, code, search, and plan. So the fact that AI is powerful is not really the main point anymore. The more interesting question is, what changes once part of the thinking is handed to a tool. That is why I want to focus less on AI itself, and more on how it changes the division of labor between the tool and the learner.

中文：AI 已经是现实工作的一部分了。
它帮助人们写作、编程、搜索和规划。

所以，AI 很强这件事，本身已经不再是最主要的问题了。
更有意思的问题是，当一部分思考被交给工具之后，到底发生了什么变化。

这也是为什么我想少谈一点 AI 本身，多谈一点它怎样改变工具和学习者之间的分工。

## Page 5 - Capability vs. Exposure

The key point here is simple: what AI can do is not the same as what organizations will actually use it for. Technical capability usually moves faster than actual use. Even when something is possible, companies may still move slowly because of trust, regulation, habits, review costs, or responsibility. So the technical limit and the real limit are often not the same. In compute science and math, this gap is also clear: AI may help generate code or optimize parts of a workflow, but adoption is slower because correctness, reproducibility, and integration into existing pipelines still matter.

中文：这里最关键的一点其实很简单：AI 在能做什么并不等于组织在现实中真的会拿它来做什么。

技术能力通常跑得比真实使用更快。

即使一件事在技术上已经可行，公司也还是可能因为信任、监管、习惯、复核成本或者责任问题而推进得很慢。

所以，技术上的限制和现实中的限制，往往不是一回事。

在计算机科学和数学里，这个差距也很明显：AI 也许可以帮忙生成代码，或者优化工作流程中的某些部分，但真正采用它通常还是更慢。

因为正确性、可复现性，以及能不能接入现有流程，这些问题仍然很重要。

## Page 6 - Why Some Tasks Are Affected Earlier

So the next question is why some tasks are affected by AI earlier than others. Usually, AI moves faster in tasks that are easy to describe, easy to check, and not too costly when something goes wrong. In those cases, the risk is lower and the workflow is easier to change. By contrast, work that depends on human contact, trust, physical action, or unclear judgment usually changes more slowly. So exposure is uneven because work itself is uneven.

中文：接下来的问题是，为什么有些任务会比另一些任务更早受到 AI 的影响。

通常来说，AI 会更快进入那些容易描述、容易检查，而且一旦出错代价也不太高的任务。

在这些情况下，风险更低，工作流程也更容易改变。

相反，那些依赖人际接触、信任关系、身体行动，或者模糊判断的工作，变化通常更慢。

所以，AI 的影响并不平均，因为工作本身就不是平均的。

## Page 7 - 1. Retrieval Gets Cheaper; Interpretation Does Not

The first change is about answers and understanding. AI makes answers easier to get, but it does not remove the need to understand them. So what becomes cheaper is getting an answer, not really making sense of it. A summary can sound clear and still hide uncertainty, contradiction, or missing assumptions.

中文：第一个变化和答案与理解之间的关系有关。

AI 让答案变得更容易得到，但它并没有取消我们去理解这些答案的需要。

所以，真正变便宜的是拿到一个答案，而不是真正把它弄明白。

一段总结听起来可能很清楚，但它仍然可能隐藏着不确定性、矛盾，或者缺失的前提。

## Page 9 - 3. What Stays Useful When Tools Keep Changing

The third change is about what stays useful when tools keep changing. If you only know one interface, that knowledge can lose value very quickly. But more general knowledge usually transfers better across tools and contexts, so it lasts longer. In that sense, AI does not reduce the value of all knowledge in the same way. It changes which kinds of knowledge stay useful as tools change.

中文：第三个变化和这样一个问题有关：当工具不断变化的时候，什么东西还能继续有用？

如果你只会一个界面，那这种知识可能很快就会贬值。

但更一般性的知识通常更容易在不同工具和情境之间迁移，所以它会持续得更久。

从这个意义上说，AI 并不是用同一种方式降低所有知识的价值，而是在改变哪一种知识会在工具变化中继续保持有用。

## Page 10 - A Real Tension

There is also a real tension here. In many workplaces, speed, output, and being fluent with the tool are rewarded more clearly than deep understanding. So in the short term, shallow AI use can look very efficient. But once production depends heavily on AI, other things start to matter more: finding mistakes, handling exceptions, and taking responsibility for the final result. In other words, AI can compress routine production, but it cannot remove the need to decide when an output is wrong, risky, or just unusable.

中文：这里也有一个真实的张力。

在很多工作场景里，速度、产出和对工具的熟练使用，往往比深层理解更容易被直接奖励。

所以在短期内，浅层地使用 AI 可能看起来非常高效。

但一旦生产过程开始高度依赖 AI，另外一些事情就会变得更重要：发现错误、处理例外，以及对最终结果负责。

换句话说，AI 可以压缩常规性的产出，但它并不能取消这样一种需要。

那就是判断一个输出什么时候是错的、有风险的，或者根本不能用。

## Page 11 - Conclusion

So in the end, AI does not make learning disappear. It changes where the value lies. Getting information and producing a first draft are now much easier. But understanding, checking, and using ideas well in new situations still matter a lot. So the question is no longer whether learning matters. The question is what kind of understanding we still cannot do without.

中文：所以到最后，AI 并不会让学习消失。它改变的是价值所在的位置。

获取信息和写出第一稿，现在都容易得多了。

但理解、检查，以及把想法很好地用到新的情境里，仍然非常重要。

所以，问题已经不再是学习还重不重要。
真正的问题是，我们仍然离不开的是哪一种理解。
