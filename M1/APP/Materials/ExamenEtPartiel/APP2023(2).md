# Exercice V (2023): Semaphore / 练习 V（2023）：信号量

Soit le programme OpenMP suivant, exécuté avec la variable d'environnement `OMP_NUM_THREAD` affectée à 4.  设有如下 OpenMP 程序，并假设环境变量 `OMP_NUM_THREAD` 被设为 4。

On fait l'hypothèse que les threads OpenMP de la région parallèle sont compatibles POSIX. Par conséquent, il est possible de faire appel à la bibliothèque pthread dans la région parallèle OpenMP.  我们假设该并行区中的 OpenMP 线程与 POSIX 兼容，因此可以在 OpenMP 并行区中调用 pthread 库。

```c
#include <stdio.h>
#include <omp.h>
#include <semaphore.h>

#define VINI 2

void main() {
    sem_t sem;
    sem_t *sem_ptr = &sem;
    sem_init(&sem, 0, VINI);

    #pragma omp parallel
    {
        int nt = omp_get_num_threads();

        sem_wait(sem_ptr);
        {
            int myrank = omp_get_thread_num();
            printf("%d\n", myrank);
        }
        sem_post(sem_ptr);
    }
}
```

### Questions 1-* / 问题 1-*

1. a) La variable `sem_ptr` est-elle locale à chaque thread de la région parallèle ou bien partagée entre ses threads ? Justifiez.  变量 `sem_ptr` 是并行区中每个线程私有的，还是在线程之间共享的？请说明理由。  
2. b) La variable `nt` est-elle locale à chaque thread de la région parallèle ou bien partagée entre ses threads ? Justifiez.  变量 `nt` 是并行区中每个线程私有的，还是在线程之间共享的？请说明理由。  
3. c) La valeur de `nt` est-elle identique à tous les threads ou bien différente par thread ? Justifiez.  `nt` 的值对所有线程都相同，还是因线程不同而不同？请说明理由。  
4. d) Combien de threads au plus vont exécuter `printf("%d\n", myrank)` ? Justifiez.  最多有多少个线程会同时执行 `printf("%d\n", myrank)`？请说明理由。  
5. e) L'ordre d'affichage des valeurs de `myrank` est-il identique d'une exécution à une autre ? Justifiez.  `myrank` 的输出顺序在不同执行中是否总是相同？请说明理由。

**Réponse** / 答案

- 1-a) `sem_ptr` est partagée entre les threads.  `sem_ptr` 在线程之间是共享的。  
  Justification : `sem_ptr` est déclarée avant la région `#pragma omp parallel`. Par défaut, une variable définie à l'extérieur de la région parallèle est partagée par les threads. De plus, `sem_ptr` pointe vers l'unique objet `sem`, lui aussi déclaré hors de la région parallèle : tous les threads manipulent donc le même sémaphore.  理由：`sem_ptr` 定义在 `#pragma omp parallel` 并行区之外。默认情况下，在并行区外定义的变量会被线程共享。此外，`sem_ptr` 指向的 `sem` 也定义在并行区外，因此所有线程操作的是同一个信号量对象。
- 1-b) `nt` est locale à chaque thread.  `nt` 对每个线程来说都是局部变量。  
  Justification : `nt` est déclarée à l'intérieur du bloc de la région parallèle. Chaque thread possède donc sa propre instance de cette variable.  理由：`nt` 在并行区内部声明，因此每个线程都有自己的一份副本。
- 1-c) La valeur de `nt` est identique pour tous les threads.  `nt` 的值对所有线程都相同。  
  Justification : `omp_get_num_threads()` renvoie le nombre total de threads de la région parallèle, qui est le même pour tous les threads de cette région. Si l'on suit l'intention de l'énoncé, cette valeur est `4`. Remarque : le nom standard de la variable d'environnement est `OMP_NUM_THREADS` ; `OMP_NUM_THREAD` est donc vraisemblablement une coquille dans l'énoncé.  理由：`omp_get_num_threads()` 返回的是当前并行区中的线程总数，而不是线程编号，因此同一并行区中的所有线程读到的值都相同。若按题目本意理解，这个值应为 `4`。补充说明：标准环境变量名应为 `OMP_NUM_THREADS`，题目中的 `OMP_NUM_THREAD` 很可能是笔误。
- 1-d) Au plus `2` threads peuvent exécuter simultanément `printf("%d\n", myrank)`.  最多有 `2` 个线程可以同时执行 `printf("%d\n", myrank)`。  
  Justification : le sémaphore est initialisé à `VINI = 2`. Donc au plus 2 threads peuvent franchir `sem_wait(sem_ptr)` en même temps et entrer dans la section protégée.  理由：信号量初值为 `VINI = 2`，因此最多只有 2 个线程能同时通过 `sem_wait(sem_ptr)` 并进入受保护的代码段。
- 1-e) Non, l'ordre d'affichage n'est pas identique d'une exécution à une autre.  不同执行中输出顺序不一定相同。  
  Justification : l'ordonnancement des threads n'est pas déterministe. Le sémaphore limite seulement le nombre de threads admis simultanément, mais n'impose pas un ordre fixe entre eux.  理由：线程调度本身是非确定性的。信号量只限制同时进入的线程数量，并不保证固定的执行先后顺序。

Pour les questions suivantes, on fait l'hypothèse que `VINI` est définie à 1 :  对于下面的问题，假设 `VINI` 被定义为 1：

```c
#define VINI 1
```

### Question 2 / 问题 2

Combien de threads au plus vont exécuter `printf("%d\n", myrank)` ? Justifiez.  最多有多少个线程会同时执行 `printf("%d\n", myrank)`？请说明理由。

**Réponse** / 答案

- Au plus `1` thread peut exécuter simultanément `printf("%d\n", myrank)`.  最多只有 `1` 个线程可以同时执行 `printf("%d\n", myrank)`。  
- Justification : avec `VINI = 1`, le sémaphore assure une exclusion mutuelle ; un seul thread à la fois peut entrer dans la section protégée.  理由：当 `VINI = 1` 时，信号量起到互斥访问的作用，因此任意时刻只能有一个线程进入受保护区。

### Question 3 / 问题 3

On désire avoir le même comportement du programme (avec `VINI = 1`) sans utilisation du sémaphore.  我们希望在不使用信号量的前提下，得到与原程序相同的行为（此时 `VINI = 1`）。

Réécrivez le programme en remplaçant le sémaphore par une autre construction pthread (tout en conservant la région parallèle OpenMP).  请重写该程序，用另一种 pthread 机制替代信号量，同时保留 OpenMP 并行区。

**Réponse** / 答案

Avec `VINI = 1`, on veut une exclusion mutuelle. On peut donc remplacer le sémaphore par un mutex pthread.  当 `VINI = 1` 时，我们需要实现互斥访问。因此可以用 pthread 的 mutex 来替代信号量。

```c
#include <stdio.h>
#include <omp.h>
#include <pthread.h>

int main(void) {
    pthread_mutex_t mutex;
    pthread_mutex_init(&mutex, NULL);

    #pragma omp parallel
    {
        int nt = omp_get_num_threads();

        pthread_mutex_lock(&mutex);
        {
            int myrank = omp_get_thread_num();
            printf("%d\n", myrank);
        }
        pthread_mutex_unlock(&mutex);
    }

    pthread_mutex_destroy(&mutex);
    return 0;
}
```

### Question 4 / 问题 4

On désire avoir le même comportement du programme (avec `VINI = 1`) sans aucune fonction pthread.  我们希望在完全不使用 pthread 函数的情况下，得到与原程序相同的行为（此时 `VINI = 1`）。

Réécrivez le programme en utilisant uniquement OpenMP.  请仅使用 OpenMP 重写该程序。

**Réponse** / 答案

Sans fonction pthread, on utilise directement une construction OpenMP d'exclusion mutuelle, par exemple `critical`.  如果不使用 pthread，可以直接使用 OpenMP 提供的互斥结构，例如 `critical`。

```c
#include <stdio.h>
#include <omp.h>

int main(void) {
    #pragma omp parallel
    {
        int nt = omp_get_num_threads();

        #pragma omp critical
        {
            int myrank = omp_get_thread_num();
            printf("%d\n", myrank);
        }
    }

    return 0;
}
```
