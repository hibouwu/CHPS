### 2. Processus et fils d'exécution 进程与执行线程

#### 2.1. Exercice 1 练习 1
Écrivez un programme qui affiche la taille du terminal courant et qui supporte le redimensionnement de la fenêtre, en affichant dynamiquement la nouvelle taille.
编写程序显示当前终端窗口大小，并在窗口尺寸变化时实时输出最新尺寸。

Le programme suivant montre comment lire la taille actuelle du terminal。
下列程序演示如何读取终端的当前行列数：

```c
#include <sys/ioctl.h>
#include <stdio.h>

int main(void) {
  struct winsize w;
  ioctl(0, TIOCGWINSZ, &w); // 读取终端尺寸，文件描述符 0 代表标准输入
                            // 也可使用 1（标准输出）或 2（标准错误）
                            // ioctl 函数用于设备控制
  printf("Lignes : %d\n", w.ws_row);
  printf("Colonnes : %d\n", w.ws_col);
  return 0;
}
```

Exemple de sortie standard：标准输出示例：

```txt
Lignes : 18848
Colonnes : 22290
```

> **Éléments de correction 纠错信息**
>
> L'un des paramètres d'un terminal est sa taille exprimée en nombre de lignes et de colonnes. Par exemple, si un terminal a 20 lignes et 80 colonnes, la fenêtre, dans le cas d'un pseudo-terminal—PTY, ou l'écran, dans le cas d'un terminal réel ou virtuel—TTY, ne pourra afficher plus que 80 caractères par ligne et 1600 caractères au total à la fois.
> 终端的参数之一是其尺寸，以行数和列数表示。例如，如果终端有 20 行和 80 列，那么在伪终端（PTY）的情况下，窗口最多只能显示 80 个字符/行，总共 1600 个字符；而在真实或虚拟终端（TTY）的情况下，屏幕最多只能显示 80 个字符/行，总共 1600 个字符。
>
> Pour les applications en mode texte telles que nano、vim、htop 等，终端尺寸是确保显示正确可读的关键参数。当终端窗口或屏幕尺寸变化时，这些应用必须能够调整显示效果。因此每次终端大小变化时都会向所有关联进程发送信号 SIGWINCH（编号 28），进程可在收到该信号时触发更新显示等操作。这正是本练习的目标。
>
> Ce programme ne fait rien d'autre qu'attendre dans une boucle infinie；l'intérêt est de gérer SIGWINCH。函数 `report_size` 在收到信号时读取并显示终端尺寸，我们用 `sigaction` 将它注册为 SIGWINCH 的处理函数。

```c
#include <stdio.h>
#include <signal.h>
#include <sys/ioctl.h>
#include <string.h>
#include <unistd.h>

void report_size(int signal) {
  struct winsize w;
  ioctl(0, TIOCGWINSZ, &w);
  printf("Taille actuelle : %d x %d\n", w.ws_row, w.ws_col);
}

int main(int argc, char **argv) {
  struct sigaction action = {
    .sa_handler = &report_size,
    .sa_flags = 0,
  };
  sigemptyset(&action.sa_mask);
  sigaction(SIGWINCH, &action, NULL);

  while (1) { }
  return 0;
}
```

#### 2.2. Exercice 2 练习 2
Écrivez un programme qui lance un processus fils et lui envoie un signal toutes les 3 secondes. Le fils devra capturer ce signal, incrémenter un compteur et afficher sa valeur. En cas d'interruption (`SIGINT`) du parent, le fils recevra également `SIGINT`。
编写程序创建子进程并每 3 秒向其发送信号，子进程收到后递增计数并打印；若父进程收到 `SIGINT`，也需向子进程转发同一信号。

> **Éléments de correction 纠错信息**
>
> En plus de `main`, le programme définit trois gestionnaires：`increment`（递增全局计数器 `counter` 并打印）、`poke`（向子进程 `child` 发送 `SIGUSR1` 并重新设置 3 秒定时器）以及 `interrupt`（向子进程发送 `SIGINT` 后调用 `exit` 终止父进程）。
> 父进程通过 `fork` 创建子进程、调用 `alarm` 设置初始定时器、将 `SIGALRM` 关联到 `poke`，并将 `SIGINT` 关联到 `interrupt`。子进程保持休眠并响应来自父进程的 `SIGUSR1`。
> `wait` 可能会被信号打断，因此我们在 `a_poke` 中设置了 `SA_RESTART` 保证自动恢复。可以试着移除该标记观察区别。

```c
#include <stdlib.h>
#include <sys/types.h>
#include <unistd.h>
#include <stdio.h>
#include <signal.h>
#include <sys/wait.h>
#include <string.h>

int counter = 0;
pid_t child;

void increment(int signal) {
  counter++;
  printf("Compteur du processus fils : %d\n", counter);
}

void poke(int signal) {
  kill(child, SIGUSR1);
  alarm(3);
}

void interrupt(int signal) {
  printf("Interruption du processus fils.\n");
  kill(child, SIGINT);
  printf("Interruption du processus parent.\n");
  exit(EXIT_SUCCESS);
}

int main(int argc, char **argv) {
  child = fork();
  if (child == 0) {
    printf("Démarrage du processus fils.\n");
    struct sigaction a_increment = {
      .sa_handler = increment,
      .sa_flags = 0
    };
    sigemptyset(&a_increment.sa_mask);
    sigaction(SIGUSR1, &a_increment, NULL);
    while (1) { sleep(10); }
  } else {
    struct sigaction a_poke = {
      .sa_handler = poke,
      .sa_flags = SA_RESTART
    };
    sigemptyset(&a_poke.sa_mask);

    struct sigaction a_interrupt = {
      .sa_handler = interrupt,
      .sa_flags = 0
    };
    sigemptyset(&a_interrupt.sa_mask);

    sigaction(SIGINT, &a_interrupt, NULL);
    sigaction(SIGALRM, &a_poke, NULL);
    alarm(3);
    wait(NULL);
  }
  return 0;
}
```

#### 2.3. Exercice 3 练习 3
Écrivez un programme qui lance un processus fils. Le parent enverra aléatoirement `SIGCONT` ou `SIGPIPE` pendant 30 secondes et le fils comptera le nombre de signaux reçus de chaque type. À la fin (ou si le parent est interrompu prématurément), celui-ci terminera son fils, qui affichera ses compteurs avant de se terminer。
编写程序创建子进程，父进程在 30 秒内随机发送 `SIGCONT` 或 `SIGPIPE` 并让子进程分别统计数量；周期结束或父进程提前中断时，父进程终止子进程，子进程在退出前输出两个信号的计数。

> **Éléments de correction 纠错信息**
>
> Nous utilisons deux gestionnaires：`h_child`（子进程侧管理 `SIGCONT`、`SIGPIPE`、`SIGUSR1`）与 `h_parent`（父进程侧管理 `SIGINT`）。
> 子进程设置信号处理后，在 `run` 变量控制的循环中等待。父进程注册 `SIGINT` 处理器后，在 ~30 秒的循环中随机发送 `SIGCONT` 或 `SIGPIPE`。
> 发送阶段结束后，父进程向子进程发送 `SIGUSR1`，子进程输出两个计数并将 `run` 设为 0 退出循环，随后双方依次结束。若父进程在此之前收到 `SIGINT`，会把该信号转发给子进程并一同退出。子进程无需专门处理 SIGINT，因为默认行为即为终止。

```c
#include <stdio.h>
#include <signal.h>
#include <time.h>
#include <stdlib.h>
#include <unistd.h>
#include <sys/wait.h>

int sigcont = 0, sigpipe = 0;
int run = 1;
pid_t child;

void h_child(int signal) {
  switch(signal) {
    case SIGCONT:
      sigcont++;
      break;
    case SIGPIPE:
      sigpipe++;
      break;
    case SIGUSR1:
      printf(
        "Signaux reçus : %d fois SIGCONT et %d fois SIGPIPE.\n",
        sigcont, sigpipe
      );
      run = 0;
    default:
      break;
  }
}

void h_parent(int signal) {
  kill(child, SIGINT);
  exit(EXIT_SUCCESS);
}

int main(int argc, char **argv) {
  srand(time(NULL));
  child = fork();
  if(child == 0) {
    struct sigaction action = { .sa_handler = &h_child, .sa_flags = 0 };
    sigemptyset(&action.sa_mask);
    sigaction(SIGCONT, &action, NULL);
    sigaction(SIGPIPE, &action, NULL);
    sigaction(SIGUSR1, &action, NULL);
    while(run) { }
  } else {
    struct sigaction action = { .sa_handler = &h_parent, .sa_flags = 0 };
    sigemptyset(&action.sa_mask);
    sigaction(SIGINT, &action, NULL);
    for(int i = 0; i < 30; i++) {
      printf("Envoi du signal %d sur 30...\r", i + 1);
      fflush(stdout);
      kill(child, (rand() % 2) ? SIGCONT : SIGPIPE);
      sleep(1);
    }
    kill(child, SIGUSR1);
    wait(NULL);
  }
  return 0;
}
```

### 3. Fichiers 3. 文件

#### 3.1. Exercice 1 练习 1
Écrivez un programme capable d'écrire une structure de données telle que：
编写一个程序，能够写入如下数据结构：

```c
struct {
  char nom[256];
  int age;
};
```

dans un fichier, puis de la relire et d'afficher son contenu sur la sortie standard selon le modèle suivant。
将其写入文件，再读出并以如下格式打印：

> Je m'appelle Marek Felsoci et j'ai 29 ans.

#### Éléments de correction 修正要素
Nous commençons par définir un type `Me` correspondant à cette structure；若程序无参数运行就将自身信息写入当前目录的 `me` 文件，否则读取指定文件并根据内容打印句子。

```c
#include <stdio.h>
#include <string.h>

typedef struct {
  char name[256];
  int age;
} Me;

int main(int argc, char **argv) {
  Me me;
  memset(me.name, '\0', 256);
  if(argc < 2) {
    FILE *output = fopen("me", "w");
    strcpy(me.name, "Marek Felsoci");
    me.age = 29;
    fwrite(me.name, 1, 256, output);
    fwrite(&me.age, sizeof(int), 1, output);
    fclose(output);
  } else {
    FILE *input = fopen(argv[1], "r");
    fread(me.name, 1, 256, input);
    fread(&me.age, sizeof(int), 1, input);
    fclose(input);
    printf("Je m'appelle %s et j'ai %d ans.\n", me.name, me.age);
  }
  return 0;
}
```

Le fichier binaire produit contient beaucoup de `\0` inutiles（字符串固定 256 字节）。为避免浪费，可记录名称真实长度：

```c
#include <stdio.h>
#include <string.h>

typedef struct {
  char name[256];
  int age;
} Me;

int main(int argc, char **argv) {
  Me me;
  size_t length;
  if(argc < 2) {
    FILE *output = fopen("me", "w");
    length = 14;
    fwrite(&length, 1, sizeof(size_t), output);
    strcpy(me.name, "Marek Felsoci");
    me.age = 29;
    fwrite(me.name, 1, length, output);
    fwrite(&me.age, sizeof(int), 1, output);
    fclose(output);
  } else {
    FILE *input = fopen(argv[1], "r");
    fread(&length, 1, sizeof(size_t), input);
    fread(me.name, 1, length, input);
    fread(&me.age, sizeof(int), 1, input);
    fclose(input);
    printf("Je m'appelle %s et j'ai %d ans.\n", me.name, me.age);
  }
  return 0;
}
```

