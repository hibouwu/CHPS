## 收录范围与缺口

教师原版包含 Lecture 1–5 和 Lab 1–7；Materials 中保留个人版本与作业材料。两者内容可能不同，不应当作相同版本。

下面按实际文件列出可阅读的正文、试卷和演示稿。配图随正文保留，不逐张列出；源码与实验数据通过相应目录访问。课程名称或文件编号不代表内容已经覆盖整门课。
